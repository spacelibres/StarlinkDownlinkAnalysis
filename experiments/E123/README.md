# E123 · 交叉 32QAM 码字的额外标号位

沿用 E122 的 16,384 位校验坐标与 E030 冻结标号。总计 3,277 个符号有 16,385 个标号位。测量末位的零偏，并比较逐字取整与连续拼接预测的末符号位置。

- 移除任一侧擦除后成对评分。对照为前一符号同一标号位、上一 OFDM 槽同子载波同位，以及连续拼接的候选位置。最后一项只对两种预测分歧的位置评分。
- Qin 使用 E077 整组划分，从留出集中整组排除 E034 与原始 250 MS/s 录波重叠的组。原录波沿用 E030 的五帧留出。固定第 5 位的最近 0、1 星座子集，保留平方距离差和 0.08 的既有裕量阈值。已通过 E030 的 PN15 区间两端各留 128 位保护，比较同一位通道的已知零。
- E034 已匹配帧按格式、资源起点与数量重新对齐，从 Qin 缓存解调同一波形的所有重叠码字。两种处理的实收结果及擦除并列。LEO 用已登记的窗口和频偏，把实测 Qin 起点投影为理想可见性。

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
python tools/run_experiment.py audit_cross32_spare_lane --run-id <新编号>
```

结果保留各组及各码字坐标、实际缓存页指纹、全部输入摘要和对照。无需 RF 采集。
