# E120 · MCS 70 的准循环校验搜索

使用 E070/E081 已冻结的末字 PN15 停止判据和归档整组划分，从公开 Qin 归档重新提取全部符合条件的 MCS 70 末字。保持实收位、擦除与已知 PN 条件互相可追溯。对照分别使用同档案的 MCS 66 及冻结的部分校验。

1. 在码字末端候选校验区、512 位块假设下，用接近全填充的校准末字组成差分位签名。每次登记使用不同档案组的四个字和八个块内旋转。遍历互斥的 16 位旋转窗。在三个或四个不同块中搜索签名异或为零的形状。校准提名每次只用本登记窗。留出组不能提议、选择或修改关系。
2. 对在至少两个窗重复出现的形状，用近全填充校准字确认仿射常量和其旋转覆盖。再由全部末字的填充开始位置估计系统项，并用完全未填入 PN 的留出位、非末字及 MCS 66 错格式评分。对已知 MCS 66 三项族复算同一搜索流程。弱帧的目标样点和已知首项标签不参与发现。

另设弱帧直接比较。MCS 66 与 70 的候选系统区分别到 3,072 与 3,200 个 16QAM 资源。在两者共有的末 128 资源分组拟合指定 PN15 预测的复增益和噪声。互换后，在相同的 128 个分歧资源上检验 PN15 相对均匀星座混合的优势，以及通过 3,200 后是否衰减。保留真实 66、70 控制、±1 PN 位错移和 63 个整 16 资源的模板置乱。第 14 时隙候选的末字只用于评分。

若获得通过原 IQ、档案未填充留出及错格式门槛的实际校验行，冻结后再测弱帧。增益和噪声仅由每侧边缘导频估计，互换导频组。计算每个校验在观察其余符号后的最后一个校验符号预测；它自身只参与评分。分别按连续五字的整组及两份互补组测试，比较 63 个同族校验目标旋转。第 14 时隙用冻结 H2 路径提供坐标；第 1、11、27 时隙用于同录波控制。弱转移通过要求两套定时、导频互换及所有可用字组均获正分并超过换位对照。

另用冻结校验对留出末字做实际单擦除推断。仅有一位擦除的整条校验提出补值，冲突保留。PN15 和已在 E081 比较的重复码字只用于事后核验补值，补值另外归档。

离线缓存使用公开 Qin HDF5 的固定版本，记录实际读取范围及指纹。继续沿用 E077 的档案组分配。发现种子为 `20261121125`，局部 PN 试验为 `20261121126`，弱校验转移为 `20261121127`。近全填充登记限制为起点上界至多 512 位、候选校验区可见率至少 98%。仿射校准常量至少需四组见证且等权一致度达到预定水平。至少 128 个旋转满足仿射常量条件才估系统项，至多评分 32 个预先排序的形状。两条实际进入全行验证的形状和其余只有一次的形状计数均归档。
