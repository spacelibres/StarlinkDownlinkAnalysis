# E012 · Code5 系统/校验关系

先从 IQ 作分数网格、频率、SSS 信道和交替 8 个导频校正，另 8 个导频保留验证。使用 E010 已验证头部，取 r=228 开始的第一载荷和后续 code5 区域，每字2048位，前1024/后1024为候选系统/校验划分。

只用旧 frame −1/1/2 的14字、QC128扩展方程恢复二元生成矩阵；其余77首段字及后续字段只检验冻结关系。报告秩、矛盾、错位/排列/取反/翻转及无CFO消融，不根据保留组结果选相位/边界。不构造稀疏完整校验阵，因此本阶段最多确认系统/校验关系，不冒称完整LDPC解码器或应用明文。

计划：`docs/plans/2026-11-20-code5-parity.md`。入口：`python tools/run_experiment.py audit_code5_parity --run-id <新编号>`。同捕获继承模型的阶段实验，不是新RF采集。

结果：训练秩1024、零矛盾；77保留首段字的78848校验位及2个后续码字全部一致，共93/93字通过。错位和无CFO消融均失败；整字取反仍通过，符合全一码字简并。前缀复数尺度跟进使校验重调制NMSE从0.607降至0.0278，原误差保留。详见 [阶段报告](../../reports/E012/2026-11-20-Code5校验关系与接收校正.md)，主记录 `runs/v010-code5-parity-02/`。
