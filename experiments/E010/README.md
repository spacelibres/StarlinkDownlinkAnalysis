# E010 · 捕获边界与条件双头部资源布局

在 E009 已验证的第一头部接收后端基础上，检查每个请求的资源窗口是否完整，而不是要求整帧/PSS 都完整。第一头部条件描述符决定第二头部位置；第二头部前缀决定码块数。CRC 从不用于搜索位置、块数或极性。

位置规则 `228 + quantity×2048`、块数位 8–10（低位权重）、条目数位 12–15 与条件 19/20 位模型来自已读取的原论文/旧研究。波形参数已经历史拟合，不能称独立新数据发现。前端参数继承 E009；H1 使用已知前16位，H2 使用已知首字节 0x34。

控制：固定四种资源错位、512 个随机资源排列；所有未准入/失败保留在分母。旧存档只在当前解完之后读取，作为事后比较。完整实验计划在 docs/plans/2026-11-20-complete-header-layout.md。

结果：18 组双头部全部通过 CRC 和精确硬重编码；18 个 H2 的块数为 13×2、3×3、2×4。全部 72 错位/512 排列均未准入，不能计算条件 CRC 偶合率。19/20 位条目模型均满足零填充，仍未消歧。报告见 [双头部与捕获边界](../../reports/E010/2026-11-20-双头部与捕获边界.md)，封存运行 `runs/v008-complete-header-layout-02/`；这是同一旧捕获的条件复现。
