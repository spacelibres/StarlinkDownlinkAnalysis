# E009 · 旧研究恢复与宽带实测头部对照

来源：用户指定的文档目录旧研究和 ../leo-tracker-reduxredux-main。二者只读。必要来源与代码快照在 references/legacy_research；旧公开宽带 CSV 的哈希已校验，其 complex64 NPY 转换逐样点与 11,520,180 行原记录一致。

目的：从宽带 IQ 重新恢复第一 PDU 头部，为窄带研究建立有实测输入的协议层正对照。不是重新宣称发现旧工程已经得到的结果，也不是用户 WAV 的成功译码。

方法冻结旧采样/帧/PN/卷积码与 CRC 约定；盲 BPSK 相位拟合后只用预先已知的 16 位前缀对应的前 48 个编码资源消歧。CRC 仅检验，不用于选择相位、配置或符号。存档头字在全部实测与对照解完后才读取比较。

旧研究曾在该捕获上用 CRC 选择参数，当前冻结重放无法消除历史选择。当前 4/13 个随机帧分组仅是条件性软件回归标签，不能冒充未打开的新数据。

执行入口：`python tools/run_experiment.py replay_legacy_wideband`。生成逐帧头字、软符号、重编码误差、512 次打乱资源顺序的对照以及全资源 PN 约定对账。原旧工程不运行、不写回；全部新结果进入 runs。
