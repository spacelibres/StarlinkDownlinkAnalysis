# E117 · 尾段相位的分配含义与原 WAV 起始槽

E067 给出宽带数据的逐字分配终点与周期相位，E097 给出实收时钟。E116 给出原 WAV 的负频侧相位。用这三条已冻结证据检验相位归因及窄带可观测性。

1. 按完整帧键连接 Qin 宽带尾段和 Code 5 帧号。统计 0、8、16 三个 WAV 主相位在宽带档案中的精确分配终点与描述符碰撞。将档案页和同一时钟标签的重复帧作为不可拆开的组。比较全局众数、帧号模 4、15、60、750 和模 60 仿射时钟模型在整组留出时的正确数。
2. 在原 WAV 只保留 E116 的两信道阶数和两频组均由负侧选出同一主相位的帧。用负侧估公共相位后，每个窗和相位分别相干平均。正频侧只用 +2、+3 两个载波，在每个已冻结相位上枚举相差 60 个资源的终点。按两根载波的首个可见尾段槽把完全等价的终点合并。
3. 用 E116 原有时间块的随机互补半组、正侧频点的互换留出，比较受约束的逐相位起点和固定第 9 槽模型。校准时间组与频点选择起点，留出窗只在校准频点重估复增益。用终止后背景上的已知起点注入检验灵敏度。起点分支须同时满足两方向留出及已知位置对照才能用于原 WAV 的精确边界主张。

首轮精确槽号注入存在误差，追加粗起点检验，保留首轮。用第 2 至 51 槽定义前 50 个数据槽，分别在早起点与其余起点族中只按校准误差选最优候选，然后比较对应的留出样点。该阈值用于区分起点的大区段。

宽带时钟组由连续四个 13 帧档案页组成，并合并共享完整时钟标签的组。随机四折用种子 `20261121120`，原 WAV 的 11 个时间块按种子 `20261121121` 随机互补分组。每个相位和窗口至少有六帧才计算相干平均。注入直接加入已对齐频谱，使用原 WAV 终止后的三个背景窗，每背景读取 24 帧平均。已知首槽 26、124、239 使用同一份 12.80 秒参考复增益，全幅、半幅共用背景。
