# E101 · Code 5 后续记录的嵌套长度与帧计数

沿用 E100 已冻结的记录边界、E097 的首记录帧计数和该实验登记的信道判决规则。复算秦档案 106 个缓存页哈希，保留所有缺失记录。数值产物记每条记录的坐标、实收位数、帧计数和匹配结果。

对第二条记录核对其内长、8 字节项和末尾定值。对第三条及之后的记录按首字节进行实证分组。`01` 和 `03` 取后四字节小端整数右移 11 位，与同帧首记录的 14 位计数对照。配对以同一 15 秒锚和计数为索引，重号优先取最早可读 `01` 记录。固定错位为 ±1、±2、±3、±4、±8 帧，保留各分母；任何配对都不跨录波。

沿用 E077 整组划分，分别保留同为校准、同为留出和跨组配对。探索读取过完整档案，组标签用于可追溯汇总。第三条之后的候选 CRC 用同一类型、同长度且至少八个不同实例的差分做 GF(2) 最大公因式，预先验证的目录 CRC24 作为阳性对照。投影到 LEO 收发坐标时给定宽带测出的记录起点，只数目标系统位的直接覆盖。
