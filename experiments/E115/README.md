# E115 · LEO 双路 IQ 中的 WAV 对应循环位置

目标是检验 E114 的三处共同状态是否也出现在 LEO 双路实测数据。先区分原 WAV 的物理载波与循环字里的等价位置，再在双路同时覆盖的帧中检验样点预测。若样本不足或方向不稳定，则保留覆盖和反例。

1. 冻结 E025 参考和 E114 位置。WAV 的资源模 60 位置 50、34、42 扣除固定相位 8 后，得到模板位置 42、26、34。LEO 用 E065 预存的每帧供体相位，将同一模板位置映射回实际可见的载波及 OFDM 槽。校验原工程 `selection.json` 中的边缘标识，封存外部输入摘要。
2. 由原工程 `FrameClock`、E064 校准槽和保护样点重建时域回归。以其它槽估计各载波复增益，三个目标槽按同一待估复系数拟合。供体只在自己的校准块生成共同相对符号。目标在自己的校准块拟合复增益，用相反的 OFDM 块计算留出投影和误差。互换两路并保留两种保护量。目标留出不参与定时、选择相位、增益或符号。
3. 保留逐帧覆盖、擦除和定标量。比较真实配对、固定正号、固定负号，以及符合覆盖和幅度门限的整帧符号全部非零循环移位。目标正向响应只是相对固定相位下的预测证据。通过同一 WAV 物理载波的重复或通过帧间变号的复验需要相应覆盖，并须胜过固定符号基线。

主分析是三个确切模板位置。另将位置共同平移 1、2、3 格，记录其它三个载波余数组上的同间隔位置作为覆盖和比较对照。每路相同留出规则。若任一符号不足两帧，或两种保护量以及双向评分未同时胜过零、两种固定极性和全部错帧，则保留为未建立的逐帧转移结果。

设计沿用 E064 冻结的整 OFDM 块划分和 E065 含相邻导频泄漏分支的供体相位，见运行结果。没有用待测数据重选时间窗或目标槽类。错帧穷举为条件对照，无法把相邻帧或重复保护量计作独立采集。

首轮完整重放的信道矩阵秩亏，因为一个全同号余数组的未调制原子已被 E066 背景回归吸收。修正时从设计矩阵移除其它载波上已被吸收的常数列，保留目标本身不可辨识的擦除。对照测试验证了已知翻转能从非恒定载波恢复且不受目标留出样点改写影响。
