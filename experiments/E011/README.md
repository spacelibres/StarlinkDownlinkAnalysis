# E011 · 资源端点与可辨识性

在同一宽带捕获上检查 E010 条件分配模型。完整计划见 `docs/plans/2026-11-20-allocation-observability.md`。信号端点诊断不接受头部或预测位置；全部信号及负参照完成后才读入已封存头部作比较。固定 32 资源相干量、主阈值 0.45、512 资源分块和至少两个连续好块；保留阈值敏感性和单变点最小二乘诊断。

预测单位从公开原论文/旧研究继承，不以本轮端点重新拟合后宣称预测成功。19 位模型的未知单位和数量/尺度简并单列。信号候选过渡不自动等于载荷终点；不去 PN、错误 PN 和窗口排列的对照也不能当独立采集。

入口：`python tools/run_experiment.py audit_allocation_observability --run-id <新编号>`。

结果：主方法 16/18 检出，端点 RMSE 11.93 资源、最大绝对差 35；两帧短尾未检出。19/20 位模型存在正单位解且相同最大拟合残差，尚不能唯一辨识。全部控制和阈值失败保留。报告见 [资源端点与可辨识性](../../reports/E011/2026-11-20-资源端点与可辨识性.md)，主运行 `runs/v009-allocation-observability-02/`。
