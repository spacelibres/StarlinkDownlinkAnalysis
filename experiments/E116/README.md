# E116 · 原 WAV 整字移位与三位置共同反转

本实验检验 E114 的三个相对符号是否可由整个 E025 循环字逐帧移位解释。沿用 E113 的 43 窗和分数定时、E114 的逐帧 FFT、E042 的整谐波块分组。每帧只在校准频点选模型和拟合复增益，再在互斥的留出频点评分并交换两组。

1. 固定 E025 相位 8 作基线。比较仅翻转三个位置、搜索全部 60 个移位、同时搜索移位和三个位置反转。每个候选都用相同数目的复增益。比较常数及随频率一次响应。
2. 另外只由负频侧选择移位，再固定此移位，使用校准频点拟合增益。检验正侧 +2 载波附近的留出样点及已冻结的 E114 相对判决。记录固定相位下和全局候选下的预测误差、相位分布、同帧符号一致数及错帧相位对照。
3. 在无原重复波形的终止后背景中加入已知性质的对齐频谱，确认同样的估计器能分别识别整字移位与固定相位下的三位置反转。强度为终止前拟合信道规模的一倍和一半。对照是频域注入，不构成新的观测或重新捕获实验。

两种频率划分均保留完整先前定义的谐波块；重采样沿用 E114 的四窗块，帧级判断与时间块统计不作独立采集计数。若整体与局部模型互有输赢，按全带和目标频窗分别报告。负频侧结果只能约束所检验的整字参考族。

两次主结果冻结后，在 E114 已判的 1,258 个三位置共同可读帧上复核。负频侧逐帧预测必须在两个信道阶数和互换的频率划分中均有相同的三位置形状，才保留其三符号。计数含擦除，并与固定正、固定负和完整帧循环错位比较。此步骤沿用原 WAV，回答对已观测变化的解释能力。

注入种子为 `20261121118`，时间块重采样种子为 `20261121119`。原始输入的逐项 SHA-256 和各窗口帧序号见数值结果。相等的校准投影使用数值容差，保留并列数并以编号最小者评分。
