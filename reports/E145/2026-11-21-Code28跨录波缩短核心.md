# Code 28 缩短核心的跨录波复验

Liu 等及 E021 在旧 480 MS/s 录波中验证了 Code 28 的 8,960 个系统位与 7,168 个校验位。每字中间还有 256 个实收位。E145 固定旧版生成器和位序，在另一份 Qin 捕获中寻找同一编码的实收证据。Qin 星座页为均衡后的硬符号档案，接收误差已受原作者判决处理。[Liu 等 §VI-G](https://arxiv.org/html/2610.29387v2#S6.SS7) · [Qin 数据与方法](https://www.nature.com/articles/s44459-026-00075-6) · [E021](../../experiments/E021/README.md)

从两级头部 CRC 通过的档案选择全部 67 个 Code 28 帧，共 19 个归档块、1,088 个码字。每字按 5,462 个调制资源切片。66 帧的总分配终点有独立尾段实收证据，均与预测相同。帧 595 缺 E067 尾段终点。先去参考相位，使用 H1 校相，并从首个 Code 5 字的 1,024 个系统位的星座实轴估计复尺度。八点字母表沿用 E021，星座平方距离误差达到 $10^{-10}$ 时擦除整个符号。后一分支再擦除 +511 载波。擦除规则和旧码参数在逐字测试中固定，无 Qin 拟合组。[E067](../../experiments/E067/README.md) · [全字结果](../../runs/v143-code28-archive-transfer/artifacts/experiments/E145/results/code28_archive_transfer.json)

| 输入及判据 | 通过码字 |
|---|---:|
| 旧录波 E021 已纠正字，重编码 | 189／189 |
| 同一旧录波，按传输坐标每 29 位擦除一个核心位 | 189／189 唯一恢复 |
| Qin 硬判／整体反相 | 0／1,088 · 0／1,088 |
| Qin 只擦除离开八点星座的符号 | 0／1,088 |
| Qin 再擦除 +511 | 1／1,088 唯一恢复 |

按固定 PN15 扫描 1,088 个字，43 个末字通过既有区间判据，未通过者包括所有 1,021 个非末字。在 67 个末字中，42 个的区间终点距 8,960 位不超过 8 位。剩余正例帧 554 的候选终点为 8,977，长匹配区包含 248 位差异。错 PN 相位加一后零通过。该边界证据可单独复算，适用范围为带有足够填充的末字。[E030](../../experiments/E030/README.md)

## 唯一恢复字的实收校验预测

Qin 帧 595 的 Code 28 分配第二字（零基字 1，起始资源 18,434）在第二种擦除下有 387 个未知核心位，系数秩同为 387。逐次将七个 1,024 位段中仍可判的校验位全部屏蔽，每轮仅用其余数据恢复，再和屏蔽位比较。七轮都得到同一核心，共 **7,015／7,015** 个保留实收校验位吻合。结果来自全体测试后选出的唯一字，七轮共享该字，提供跨录波编码兼容证据，1,087 个失败字仍保留。[逐块验证](../../runs/v143-code28-witness/artifacts/experiments/E145/results/code28_witness.json)

把中间的 256 个实收位代入原母码前缀的缩短零位，保持其余已恢复系统位后重编码，7,015 个可判校验位中出现 **3,537** 个差异。数据保留了独立的系统、核心校验、未知中段和额外标号位的掩码。这个中段的位置及其不参与所测缩短核心得到跨录波支持，其生成规则或业务含义仍待验证。[波形与掩码档案](../../runs/v143-code28-witness/artifacts/experiments/E145/results/code28_witness.npz)

四个运行退出 0，未改写原证据。全档案 JSON、逐块 JSON、见证 NPZ 的两次运行分别逐字节一致。[全档案复跑](../../runs/v143-code28-archive-transfer-confirm/manifest.json) · [逐块复跑](../../runs/v143-code28-witness-confirm/manifest.json)
