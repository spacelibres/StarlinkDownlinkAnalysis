# 三重观测与擦除重建

三帧的高阶近重复提供了 62 个保留擦除的码字候选。用已验证的 Code 5 作对照，成功补全一个三次观测各自都未通过、三路强制多数仍失败的码字。其两处擦除位均位于校验段，其他 1,022 个实收校验位与生成矩阵一致。

## 注册与交叉预测

遍历有至少三帧共享 H1/H2 的七个头部组。对同一码字坐标，只用前 256 位注册三对观测，要求每对至少 90% 共同可见，且差异不超过 2%。按 E075 的结果，在单帧整槽仅见四个外角时，将候选 16QAM 的两条幅度通道视为擦除。候选系统区、字长与星座沿用 E070。后段未参与注册。七个头部组中仅 692/693/694 帧得到高阶三重注册，涉及 MCS 57、66、70、75、78 各 25、12、23、1、1 个位置。同组轮换的比较存在相关。 [E070](../../experiments/E070/README.md) · [E075](../../experiments/E075/README.md) · [Chase 的多次观测合并](https://doi.org/10.1109/TCOM.1985.1096314)

三路合并时至少两路可见且无异议，合计保留 98.58% 的位。62 个字仍各有 107–528 处擦除。五个位置用固定 PN15 做额外对照：以候选系统区结束前 1,536 至 1,024 位作为注册窗，末尾 512 位作为另一比较窗。单路为 188/7,680 个差异，两路一致的位为 126/7,556 个差异。一致观测降低了与 PN15 的差异，但共同误判或固定参考偏差仍可保留。一致率无需假设三次观测独立。

## 冻结 Code 5 的校验对照

从相同头部组的 H1 之后提取首段 BPSK，沿用相同注册规则，允许每路至少 90% 的真实 BPSK 格点。用 E012 生成矩阵对至少两路支持且无异议的坐标验证。若需要恢复系统位，用按 128 位分块的校验列，两折互换验证。种子 2026112176 固定选取零基块 0、2、3、6 为首折训练，剩余四块验证。两折都必须有足够秩、留出零差异且恢复一致。若系统位完整，用全体实收校验位直接比较，擦除的校验位事后重编码。 [E012](../../experiments/E012/README.md) · [Liu 等的 Code 5 结果](https://arxiv.org/html/2610.29387v2#S6.SS1)

1,573 个三重组合中，强制多数判决通过 670 个，擦除重建通过 1,316 个。重叠的组合按验证后码字内容去重，只得到五个不同的位串，一个位串在所有已登记的单独接收观测中均未精确通过。该位串为帧 692/693/694 的第四个 Code 5 字。三个强制硬判的校验差异分别为 1、477、1；强制多数结果为 1。保守掩码保留全部 1,024 个系统位及 1,022 个接收校验位，两处零基校验坐标 635 和 639 按冻结矩阵补全。实测和补全的位置可从归档分别识别。
