# E016 · Code 21 循环编码与单比特校验

## 接收模型与数据

使用旧 480 MS/s 实测录波、E010 的 CRC 头部和 E011 的资源布局。在六个可见帧组中提取 284 个 Code 21 字，每字 4,096 个 QPSK 资源。沿用 E015 的导频相位时间展开和已知 H1 前缀复增益。8,192 位码字的前 5,120 位为系统坐标，后 3,072 位为校验坐标。分块长度 512，依据 [Liu 等的公开模型](https://arxiv.org/html/2610.29387v2#S6.SS5)。

## 标号与生成矩阵

生成关系写成 GF(2)[x]/(x^512+1) 中的 10×6 多项式矩阵，系数索引沿接收位序递增。由于在 GF(2) 中 x^512+1=(x+1)^512，一个多项式能在此环中求逆的条件是系数之和为奇数。用可逆主元消元，主元完整且多余方程一致才给出矩阵。展开得到的 5,120×3,072 二进制矩阵与多项式预测进行了抽样逐位对照。[循环矩阵与多项式环的定义](https://arxiv.org/abs/0901.4129)

从 π/4 逆时针使用初始整数标号 3、1、0、2，高位在先。首次拟合失败，两个训练组分别出现 6 和 3 条非零多项式矛盾行。跟进分别在各自的拟合字中检验四种旋转与两种方向，均唯一支持偏移半周的标号 0、2、3、1，并恢复逐项相同的矩阵。选择只读取拟合字，首次不通过的记录独立保存。

| 划分 | 拟合字 | 保留帧（旧索引） | 保留字直接满足全部校验 | 校验差异 |
|---|---:|---|---:|---:|
| 论文对应 | 帧 −1 的 7 字与帧 3 的前 13 字 | 7、11、15、16 | 207 / 208 | 1,568 / 638,976 |
| 随机整帧 | 帧 15、16 中按决策裕量选 20 字 | −1、3、7、11 | 215 / 215 | 0 / 660,480 |

论文对应组中，拟合帧里的其余 56 字也满足校验。随机种子 2026112115，组排列为 16、15、3、7、−1、11，前两帧作拟合帧，选到帧 15 的 19 字及帧 16 的 1 字。拟合字按星座到实轴和虚轴的最小距离排序，未依校验结果筛字。两种划分来自同一次捕获，且保留帧集合重合，位数不能相加。

## 区分两种 5/8 编码

在同一接收位序下，将冻结的 Code 9 多项式保留原指数，或把每个指数乘四，分别作为长度 512 的候选。两种候选对 284 字均失败，每字差 1,444–1,624 位、1,462–1,628 位。实际 Code 21 多项式逐块模 x^128+1 后，与 Code 9 对应位置的 60 个多项式无一相同。这个结论只针对测试的位序、块对应和指数变换。

冻结 Code 21 的两种 ±1 资源错位以及全字取反对照均逐字失败。论文对应保留组的校验预测重调制 NMSE 为 0.03961，固定翻转每 16 个校验位中的第一位后为 0.28818。预测 NMSE 包含预纠错的失配字。

## 单比特修正

284 字的唯一非零综合出现在帧 15 的第 51 号字，均采用从零开始的编号。基于两种拟合得到的同一个冻结生成矩阵，查找其完整综合向量与校验阵 [Pᵀ | I] 的哪一列一致。遍历的 8,192 个位置中，仅系统坐标 2,313 一处匹配。翻转后 3,072 位重新编码完全一致。对应星座点为 −1.09142−0.05797i，靠近实轴，翻转造成的平方误差增量为 0.16396，在该字的所有单比特翻转中最小。

此项是实测录波中符合一位变化模型的修正，真值没有外部记录。一位匹配的唯一性不能排除多位错误，也不能用于估计真实信道 BER。更高层字段与稀疏校验图仍待确定。
