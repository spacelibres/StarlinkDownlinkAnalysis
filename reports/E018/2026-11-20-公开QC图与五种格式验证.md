# E018 · 公开 QC 图与五种格式验证

## 矩阵与方法

逐行转录 Liu 等图 12 的三个数值表。对每个循环块，编号为 b、移位量为 d 的边在旋转 r 下读取位 bZ+(r+d) mod Z。Z128 的全部校验行与 E013 从录波恢复的 Code 5 校验行集合完全一致。Z512 和 Z1024 的非零位置分别与 Z128 一致，数值移位有别。[论文图 12](https://arxiv.org/pdf/2610.29387v2#page=17)

把三个表分别放入对应的二进制循环多项式环，校验侧均取得八个可逆主元。因此整个校验阵和校验侧的秩分别为 1,024、4,096、8,192。求逆导出系统生成关系，再用相同录波分别检验综合和重编码。数值矩阵来自图 12。E010 的头部决定资源位置，E015 的导频修正与 H1 前缀决定接收相位和增益。

## 五种格式的观测

| 格式 | 资源上的调制 | 字数 | 初始非零综合 | 修正后校验差异 |
|---|---|---:|---:|---:|
| Code 3 | BPSK | 3 | 0 | 0 / 12,288 |
| Code 12 | QPSK | 1 | 0 | 0 / 4,096 |
| Code 27 | 八点星座 | 1 | 15 | 0 / 4,096 |
| Code 10 | QPSK | 10 | 0 | 0 / 81,920 |
| Code 39 | 16QAM | 1 | 165 | 0 / 8,192 |

Code 27 和 Code 39 采用公开标号与探索阶段已检查的相位约定。使用星座点距离差构造 max-log 度量，归一化 min-sum 固定缩放 0.8，两字均在一次迭代后通过。Code 27 改变 5 位，Code 39 改变 55 位。两者的重调制 NMSE 分别为 0.03306 和 0.02586。与原论文不同的初始综合和改位数保留为本地接收器结果。Code 27 的 NMSE 使用前 2,730 个完整标签，末尾额外标号位的硬判决为 1，证据不足以确认该位的发送规则。

16 个字的全字取反均通过同一校验阵。两种 ±1 资源错位的初始硬判决逐字失配。将 Z128 的公开移位直接保留或按比例乘以四或八，生成的对照矩阵也逐字失配。此结果确认测试的数值不能通过这两种规则迁移。

## Code 10 输入仍缺一个方向

Code 10 的十个系统字都满足按零计数第 0、1、2、3、5、7 块的位异或和为零。枚举全部 255 种非空块组合后，仅找到这一条块奇偶约束。

在长度 1,024 的循环多项式环内，将十个系统字分解为七个可逆主元和一个剩余方向。剩余列的多项式与 x^1024+1 的最大公共因子为 x+1，所以该列贡献 1,023 个二进制维度。总秩为 7×1,024+1,023=8,191。对 10,240 个循环移位直接进行二进制消元，得到相同的秩。

Code 39 的初始硬判决和修正字也落在同一个子空间。加入修正字后，秩仍为 8,191。公开校验阵的校验侧可逆，与这些输入尚未覆盖一个系统方向是两件事。当前录波可以检验公开矩阵对该子空间的预测，缺失方向及其对应完成选择还需要额外实测输入辨别。
