# E038 · MCS 6 扩展记录与跨区相位

使用 E036 的 21 个档案帧及 48 个 MCS 6 候选字，沿用 E037 的整档案段划分。本轮新增的 79 个 Code 5 复数切片来自同一份 Qin 接收处理档案，均位于该帧的第二头部之前。读取的 22 个缓存区段全部复现 E036 的 SHA-256，源站证书信任限制随来源保留。无新增 RF 采集。 [Qin 作者数据与代码](https://rnl-data.ae.utexas.edu/datastore/supplementaryMaterial/qin-starlink-pilots/) · [Liu 等的 Code 5 验证](https://arxiv.org/html/2610.29387v2#S6.SS1) · [论文作者复现仓库](https://github.com/misaka666/Starlink-Downlink-Analysis)

## 只用先行 Code 5 估计相位

在每个 Code 5 字中擦除 `k=+511` 上的位，保留其余符号的实部硬判。枚举擦除值，以 E013 冻结的 H 判断是否唯一解，再用 E012 冻结的 P 独立重编码。79 字中 68 字有唯一解，11 字在固定其余位时无解。辅助分支用同一 H 和归一化 min-sum，把边缘位的 LLR 设为零，79 字均收敛，累计改动 11 个其他坐标。两个分支均由各自通过重编码的 Code 5 符号估计该边缘载波在同帧的四分之一圈旋转，选实部相关的唯一最大者。投影不超过 Code 5 参考幅度中位数一半时保留擦除。校验通过支持代数补全，符号比较用于检验实际转移。 [Liu 等 §V 的软判与重调制](https://arxiv.org/html/2610.29387v2#S5)

8 个保留帧均能从 Code 5 唯一估计旋转。两条 Code 5 分支对这 8 帧选中相同旋转，在 66 个已知 MCS 6 PN 填充位上给出相同结果。

| 同一批 66 个位置 | 一致 | 差异 | 擦除 |
|---|---:|---:|---:|
| 原实部硬判 | 10 | 56 | 0 |
| 固定零旋转，使用擦除门槛 | 4 | 30 | 32 |
| 前置 Code 5 估计旋转 | 59 | 0 | 7 |
| 在估计旋转上加半圈 | 0 | 59 | 7 |

保留的 67 个填充区外边缘位置中，修正后得到 60 个候选判决和 7 个擦除。60 个判决有 50 个与原硬判不同，逐位保存。在校准组，精确擦除分支有 3 帧旋转并列，辅助分支有 2 帧并列。将帧末尾独立模板的旋转直接转移到前段的探索对照也出现不一致，例如帧 18 和 108。相位可以随帧内区域变化，套用单一全帧相位的解释仍有歧义。

## 字节记录和固定锚

在 E037 的 9 个校准命中字中，41 条 `E` 的末位均为零，并且每条 `E` 后紧跟一条 `C`。7 个保留命中字的 37 条 `E` 全部符合两项约束。证据支持把 `E` 视为可选前缀的解释。实际位的业务含义尚未识别。SpaceX 的调度专利描述了按用户分配资源与复用扩展头部，可作为未来对照；其中未找到与本实验字节布局直接对应的表。 [SpaceX 调度专利图 4 与图 7](https://patents.google.com/patent/US20250358839A1/en)

校准时发现固定的 12 字节锚 `BC 6B 50 ED 00 D6 A2 CC E0 CD FF 0B`。在候选系统区按字节查找，8 个保留字全部含此锚，原硬判合计 12 处，且锚前字节的低三位均为二进制 `010`。7 个通过原分段的保留字中，6 个首锚出现在停止标签之后 17–20 字节，帧 30 在第 21 字节，保留为位置范围的反例。帧 3 未通过原分段，但仍包含三个完整锚。错相位 ±1 和等组成字节乱序对照无精确命中。

为检查填充区之外的相位转移，遍历只有一位落在 `k=+511`、且该位没有填充参考的字节对齐锚窗口。完全不读取这一位来选择位置。校准与保留分别有 3,665 和 193 个窗口，唯一通过出现在保留帧 99 的字节 246，另外 95 位完全相同。同一码字未经修正已在字节 100 和 170 读到两处完整锚。第三处屏蔽位的接收顺序坐标为 2053，原判为 0。锚与 PN15 给出的期望为 1，前置 Code 5 独立提供的相位也判为 1，错半圈为 0。错 PN 相位和反向锚均无通过。该单个模板参考验证支持对一个填充区外符号的修正，尚无对其余未知位的真值。

## 复现与范围

结果限于同一次观测。MCS 6 的整字纠错码、数据完整性机制、各字段语义及用户窄带录波里的相应结构仍待验证。报告采用原硬判来评估字节规则，避免相位修正后的标签参与规则选择。
