# LEO 上边缘限带与相位

用现有 250 MS/s 实测 IQ 检验 E071 给出的 LEO 25 MS/s 频窗。+511 相对调谐中心为 +12.3828125 MHz，距奈奎斯特边界 117.1875 kHz。四根通带内的已知导频全部保留时，+511 的观测仍可能因滤波和频偏显著衰减。所测滤波器为数字模型，真实接收机的带边响应待测。[E071](../../experiments/E071/README.md) · [原工程 0181](https://github.com/misko/leo-tracker-reduxredux/blob/main/reports/2026_09_03_0181_native25_fractional_glrt.md)

## 输入和对照

输入 CI16 的 SHA-256 是 `c69e82022d45173cdcaf1a5fdc8a2b864e2d61e85ae819af54b16002044adae3`。冻结 E014 的帧时刻、频偏、采样时钟和 38 个 Code 5 字的边界。逐字擦除 +511，用 E013 的矩阵从其余实测硬判唯一恢复参考位，并复核全部约束。上边缘导频 488、490、492、494 与 +511 使用同一 OFDM 有效区间内的复数投影。投影按冻结频偏、时钟和 PN 旋转对齐。种子 2026112172 将完整帧组分到校准索引 2、3、7、8、9 和留出索引 0、1、4、5、6。两组均取自同一 50 ms 捕获。[Qin 等 §V–VII](https://arxiv.org/html/2602.02627#S6) · [实测宽带输入](../../experiments/E014/README.md)

逐帧取包含 Code 5 目标位置的实测样点，评价区间前后各留约 160 µs。变频移入目标窗口后应用对称的频域矩形或升余弦低通，再十倍抽取。以傅里叶插值恢复评价网格，不恢复带外频率。对全部五档额外频偏重复。正频偏将目标向上侧截止频率移动。幅度转移定义为复互积模除以宽带投影能量，两组投影按相同位置计算。合成双音只用于测试抽取和带外抑制。

## 幅度及位一致性

| 额外频偏 | 矩形幅度转移 | 250 kHz 滚降 | 1 MHz 滚降 |
|---|---:|---:|---:|
| −250 kHz | 0.970 | 0.957 | 0.321 |
| −100 kHz | 0.959 | 0.809 | 0.146 |
| 0 | 0.905 | 0.501 | 0.069 |
| +100 kHz | 0.594 | 0.196 | 0.027 |
| +250 kHz | 0.107 | 0.032 | 0.010 |

四导频的合并幅度转移在所有条件下为 0.9969–0.9983，相关均超过 0.9987。+250 kHz 时目标的标称中心已出带，有限时长 OFDM 投影仍可从剩余频率成分得到非零系数。此时矩形模型的 +511 相关仅 0.407。

首轮跨帧固定相位在宽带留出只匹配 26/40 位，因此保留该失败并追加帧内检验。每帧仅取最早两个参考位校相，留出共 30 个后续位置。宽带帧内相位命中 30/30，错帧相位命中 17/30。零额外频偏下，三个数字模型各用自身前两个锚点估相，依次命中 30/30、30/30、23/30，错帧分别为 18/30、9/30、18/30。+250 kHz 三个模型分别只命中 22/30、15/30、17/30。位一致性依赖宽带擦除恢复的锚点；该实验没有测量 LEO 录波的误码率。

先前依据 25 MHz 标称带宽列出的六条 LEO 归档录波，可在导频锁定后检验带边频偏、幅度和相位，再决定是否纳入码字复验。导频锁定本身不能证明 +511 可用。
