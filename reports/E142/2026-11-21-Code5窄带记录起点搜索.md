# Code 5 在窄带中的记录起点与长度

E141 给出记录起点，再从内部字段读长度。E142 撤去起点和类型，检验长度字段能否反过来定位记录。波形坐标、资源起点 228 与 PN 扰码沿用此前复验。位偏移以记录首位为零，字节内低位优先。[E141](../../experiments/E141/README.md) · [Qin 波形研究](https://arxiv.org/abs/2602.02627) · [Liu 等的分配与 Code 5](https://arxiv.org/abs/2610.29387v2)

## 新版从 Qin 实测位找回边界

从宽带档案提供的连续首批 Code 5 系统字出发，只保留 LEO 标称频窗与原始硬判观测掩码同时覆盖的位置。逐字节搜索，要求计数位段、`0x100` 终止标记、尾部长度值均可直接读取。计数为 $n>0$ 时，终止标记从位 $p=161+60n$ 开始，尾部的 8 位长度值 $q$ 从位 $p+16$ 开始，记录跨度为 $\lceil(p+24)/8\rceil+q$ 字节。[频窗和布局输入](../../experiments/E100/README.md)

| 标称 25 MS/s 频窗 | 起点和长度吻合 | 其余候选 | 布局筛查后保留 |
|---|---:|---:|---:|
| 下边缘 | 20 | 0 | 20 |
| 上边缘 | 2 | 1 | 2 |

上边缘误候选在档案帧 923，从字节 66 开始，跨度 282 字节。此前布局给出最短前置跨度 $20+135+13=168$ 字节，该候选落在前置记录区。使用 `0x200` 错标记或反转可见解扰位时，两个频窗均无候选。22 条正确候选的类型和 14 位帧计数均没有直接观察位。这一判据恢复的是边界，仍依赖已知 Code 5 分配、载波资源和解扰方式。Qin 这条路径从档案的均衡判决开始。[布局上下限](../../experiments/E101/README.md) · [候选与对照](../../runs/v141-code5-blind-extents-final/artifacts/experiments/E142/results/code5_blind_extents.json)

## 旧版从限带样点找回边界

把 Liu 论文的 480 MS/s 实录混频到三个内部位置，采用 25 MS/s 和 250 kHz 过渡频带。从限带样点检测 PSS／SSS，联合相关得分至少 1.0 才接纳帧机会，并拟合采样率。用同帧 SSS 估计带内信道，在偶数与奇数载波上分别拟合每个 OFDM 符号的 BPSK 相轴，要求单位复数二次方的平均模长至少 0.65。对首八个已知位置的系统字搜索同一符号内的 24 个局部位。字节 14 的低半字节为 5，高半字节为计数 $m>0$，字节 17、18 为 `60 00`，跨度 $16+7m$ 字节。每个相轴分别允许两种极性，两组都提出相同候选才保留。两组相轴用不同载波估计，候选评分可共享目标样点。[限带同步方法](../../experiments/E102/README.md)

| 相对零号载波的调谐 | 通过同步／机会 | 起点和长度吻合 | 其余候选 | `60 01` 对照 |
|---|---:|---:|---:|---:|
| −80 MHz | 15／18 | 9 | 0 | 0 |
| −63 MHz | 13／18 | 3 | 0 | 0 |
| +55 MHz | 13／18 | 2 | 0 | 0 |

合并找回 **14／18** 条互异记录，覆盖已知的四种字节起点。调谐根据此前宽带布局选定，14 条来自同一次录波，未逐条验证记录类型或有效 CRC。表中调谐属于信道内部，LEO 原工程的 25 MS/s 参数是信道边缘。原先的宽带帧时间和记录表在候选产生后用于比对。三次内部投影从同一实测波形生成。[源录波论文](https://arxiv.org/abs/2610.29387v2) · [宽带边界基线](../../experiments/E141/README.md)

## LEO 原工程现有材料支持到哪一步

将 1,354 条冻结的新版记录及 18 条旧版记录投影到 E130 已审计的 205 个 LEO 频窗。下表的覆盖数是按载波中心算出的直接观测上限，仍需要样点、正确的分配与信道估计。`0181` 的 178 项来自 89 个窗各两种频偏估计。[E130](../../experiments/E130/README.md) · [原生 0181 报告](https://github.com/misko/leo-tracker-reduxredux/blob/main/reports/2026_09_03_0181_native25_fractional_glrt.md)

| LEO 材料 | 新版单条覆盖上限 | 完整新版足迹 | 旧版单条覆盖上限 |
|---|---:|---:|---:|
| 10 个 2.5 MS/s 原始短窗 | 3／27 位 | 0 | 0／24 位 |
| 12 个 7.5 MS/s 导频档案对应频窗 | 20／27 位 | 0 | 0／24 位 |
| 3 个 10 MS/s 导出的数据频点组 | 19／27 位 | 0 | 0／24 位 |
| 25 MS/s 标称下／上边缘 | 27／27 位 | 20／2 条 | 0／24 位 |
| 原生 25 MS/s `0181` 的 178 项频偏几何 | 27／27 位 | 每项 2 条 | 0／24 位 |

LEO 的 2.5 MS/s 原始短窗可以复验导频获取，27 位的边界检测需要更宽的实录。`0181` 已有覆盖新版足迹的几何条件，原生 CI16 和实际记录布局仍待核验。初跑误用了旧字段名 `units`，在生成几何收据时中止。修正为 E141 保存的 `marker_bit` 后，两次运行均成功，结果 SHA-256 为 `d75d385369d2777fc71b32f3156046f38fcc7755b7ce96a55c6b3ec8e0cf6ddd`。[原工程实录入口](../E143/2026-11-21-LEO原工程检测器重放.md) · [初跑](../../runs/v141-code5-blind-extents/manifest.json) · [最终运行](../../runs/v141-code5-blind-extents-final/manifest.json) · [复跑](../../runs/v141-code5-blind-extents-confirm/manifest.json)
