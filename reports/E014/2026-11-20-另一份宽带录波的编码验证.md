# E014 · 另一份宽带录波的编码验证

## 输入与假设

用 v0.0.11 冻结的 Code 5 生成矩阵 (P) 和稀疏校验矩阵 (H) 检验另一份实测录波。输入为作者 [v2.0.0 发布文件](https://github.com/misaka666/Starlink-Downlink-Analysis/releases/tag/v2.0.0)，作者注明其来源为 [Qin 等的补充录波](https://doi.org/10.1038/s44459-026-00075-6)。本地 50,000,000 字节的 SHA-256 与 GitHub 发布资产摘要一致。发布方归属说明和 RF 中频信息未做独立认证。

录波为 250 MS/s、50 ms、12,500,000 个小端有符号 int16 交错 I/Q 复样点。E012 的矩阵拟合只使用旧 480 MS/s 录波中的 14 个码字。本轮不划分新拟合组，不抽样或重估编码参数，按接收器固定门限检查全部检出的候选。Qin 的导频模型和 Liu 等的头部与编码工作作为方法依据。后者的 [v2 预印本](https://arxiv.org/html/2610.29387v2) 分析旧捕获，作者的 [新版仓库说明](https://github.com/misaka666/Starlink-Downlink-Analysis) 已报告此次录波的九帧和 Code 5 转移。

## 接收与对照

以 48/25 及 6145 抽头 Kaiser FIR 将数据重采样到 480 MS/s，沿用 FFT2048 和 CP64 的处理坐标。以重复相关提出候选，再按已知 PSS 的匹配分数选择时间和频偏别名。用 SSS 估计信道。每隔一根边缘导频用于估计频偏、采样伸缩和相位，其余八根用于验证。各帧的已知 H1 前缀固定星座标号。H1 的数量字段给出 H2 的资源位置，H2 前缀给出块数。CRC 用于验证头部，未用于择选搜索候选、头部位置或块数。

对首段 2048 位码字 $c=[u,v]$，逐字比较 $v$ 与 $uP$，并计算 $Hc^{\mathsf T}$，运算均在 GF(2) 上。负对照将同样长度的资源窗口前移或后移一个资源，或恢复 PN 相位旋转后判决。所有对照位置固定，无随机种子。

## 实测结果

| 检查 | 九个完整帧 | 一个末尾截断帧 |
|---|---:|---:|
| 保留导频标号差异 | 0 / 21,600 | 0 / 280 |
| 第一头部 CRC 通过 | 9 / 9 | 1 / 1 |
| 第二头部 CRC 通过 | 9 / 9 | 1 / 1 |
| 头部重编码硬判决差异 | 0 / 6,270 | 0 / 684 |
| Code 5 校验位差异 | 0 / 35,840 | 0 / 3,072 |
| 初始综合全零的完整码字 | 35 / 35 | 3 / 3 |

- 九个完整帧的每帧保留导频 EVM 均值为 0.24184，范围 0.22689–0.27559。有一帧的 H2 为五个编码块和六个候选描述字段，同一前缀规则可处理该形式。
- 末尾候选具有 SSS 与编号 2–36 的完整数据时隙，可覆盖两个头部及三个完整首段码字。用于伸缩及残余频偏拟合的训练窗口在编号 50–289 的时隙，故该候选使用 PSS 频偏与标称采样尺度，训练窗口缺失记录在案。其余帧体没有结论。
- 将全字取反视为同一码字后，新录波的 38 个码字仍互不相同，也与 E012 的 93 个码字无重合。这是两份录波，帧和码字共享各自接收链路。
- 三组负对照每组均为 38 字，全部出现校验差异。前移每字差 495–546 位，后移差 487–533 位，恢复 PN 旋转差 483–554 位。
- 归一化 min-sum 在所有真实观测上以零次迭代退出，重编码无差异。实测字已经满足校验，真实信道纠错能力和 BER 尚未测定。

## 复现与证据范围

运行 `python tools/run_experiment.py validate_ut_capture --run-id <新编号>`。主运行 [v012-ut-transfer](../../runs/v012-ut-transfer/manifest.json) 和同数据复跑 [v012-ut-transfer-repeat](../../runs/v012-ut-transfer-repeat/manifest.json) 均返回 0，封存证据改动为 0，JSON 和 NPZ 文件 SHA-256 完全一致。再次从封存 NPZ 独立计算 38 字的生成校验及稀疏综合并比较 33 个数组，均一致。报告表格来自 [逐候选、逐码字数值结果](../../runs/v012-ut-transfer/artifacts/experiments/E014/results/ut_transfer.json)。52 项单元测试通过。

九个完整帧复现作者公开结果，并增加了对截断帧已采全资源的本地检查。该次跨录波验证支持冻结 Code 5 关系在不同接收条件下适用。两份捕获无法给出应用字节语义、全局位极性、所有 MCS 的编码关系或原用户窄带录波中的消息。
