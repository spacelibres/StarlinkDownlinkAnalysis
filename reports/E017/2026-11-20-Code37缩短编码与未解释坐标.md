# E017 · Code 37 缩短编码与未解释坐标

## 模型与分组

用 E016 冻结的 Code 21 生成矩阵，处理旧 480 MS/s 录波中的 7 个 Code 37 字。沿用 E015 的导频相位修正。每字 2,731 个八点星座符号，对应 8,193 个标号位。每字的前 4,736 位放入母码编号 384–5,119 的系统坐标，前 384 个母码坐标置零，预测 3,072 个校验位。[Liu 等 §VI-E](https://arxiv.org/html/2610.29387v2#S6.SS5)

| 接收坐标，从零计数 | 数量 | 当前证据 |
|---|---:|---|
| 0–4,735 | 4,736 | 缩短核心的系统位 |
| 4,736–5,119 | 384 | 保留接收判决，校验关系未解释这一段 |
| 5,120–8,191 | 3,072 | 冻结生成矩阵预测的校验位 |
| 8,192 | 1 | 末尾符号额外标号位，未纳入核心 |

随机种子 2026112017 给出帧组顺序 15、3、11、1，拟合帧为 15 与 3，共四字。对基准八点集合枚举八种平面对称和两种二进制极性。校验选择只在拟合字上运行。探索阶段已经查看全组星座和部分初始校验，保留组只评估固定标号的转移。

## 搜索与结果

首轮枚举所有单符号替换，并在额外欧氏代价最小的 64 个替换中检查两处组合。16 种标号均未通过四个拟合字，最高只有两个通过。跟进将组合范围扩大到前 256 个替换、最多四个不同符号，继续枚举全部单符号替换。两两合并的综合通过异或匹配。若有多个不同的核心解，保留未决状态。按观测可靠度筛选搜索集合的思路参考 Chase 的原始研究，这里的搜索对象是八点符号替换。[Chase，1972](https://ieeexplore.ieee.org/document/1054746/)

跟进只接受一个训练标号，基准旋转 180° 并反转三位。4 个拟合字与 3 个保留字的修正后综合均为零。每个非零综合字在搜索范围内只有一个核心解，共改变 17 个核心判决，其中保留组改变 7 位。一个拟合字的初始综合已经为零。全组 21,504 个校验坐标与重新编码一致。这是接收码字的一致性，缺少发送比特真值。

## 省略段与负对照

- 母码省略段对应的 384 个生成矩阵行，其 GF(2) 秩为 384。用无需修正的字反求省略段，只有全零解。其余六个原始硬判决与该线性补全问题不相容，失败记录保留。
- 把接收中段直接送入母码，每字出现 1,484–1,597 个校验差异。把虚拟零移至系统段末尾，每字出现 1,485–1,562 个差异。两种错位的原始硬判决每字均有逾 1,500 条非零综合。
- 每个字只将三位均属于核心的 2,601 个符号用于重调制。NMSE 为 0.02258–0.03207，固定翻转校验对照为 0.12467–0.17744。
- 384 位未知中段的任意两字相差 177–205 位，共有 8 个位置在这 7 字的硬判决中恒定，末尾额外标号位的硬判决均为 0。这些是这份录波的描述量。未解释中段及额外标号位均按原硬判决保留，掩码不将其标记为核心。它们的编码和语义待查。
