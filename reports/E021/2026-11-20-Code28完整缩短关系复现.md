# E021 · Code 28 完整缩短关系复现

## 接收对照

沿用 E010 的资源分配和 E019 的 189 字。依据论文先用导频估计采样漂移，再在 FFT 前调整分数采样。用第 50–289 时隙的八根已知导频展开跨带相位差，线性拟合其随时隙的变化，转换为每帧采样网格修正。以 SSS 的 FFT 起点为锚，保持每帧原点。四个帧的网格增量约为 −30.750 至 −30.788 ppm，重复估计后残差为 0.0028–0.0054 ppm。另八根导频只参与评估，在四帧的 9,600 个标号上零差异。[论文 §II-B](https://arxiv.org/html/2610.29387v2#S2.SS2)

仅重采样没有解除编码拟合的矛盾。另一路使用最近八点星座点作目标，两步校正复增益。时隙增益取相反奇偶载波的观测，载波增益取相反奇偶时隙的观测。校正没有使用校验位，但用到了同一帧的其他目标信号。这与论文公开的导频接收器并非同一实现。交叉标定方案是在同一录波上的接收探索中选定。[GNU Radio 判决辅助均衡参考](https://github.com/gnuradio/gnuradio/blob/main/gr-digital/lib/ofdm_equalizer_simpledfe.cc)

| 接收方法 | 论文分组前 20 个高裕量字的矛盾方程 | 随机分组的矛盾方程 |
|---|---:|---:|
| E019 接收器 | 11 | 11 |
| 仅调整 FFT 网格 | 11 | 11 |
| 仅交叉标定 | 0 | 1 |
| 调整网格加交叉标定 | 0 | 11 |

四组均有九个可逆主元。标定与重采样并非任一质量指标上都单调改善。交叉标定前，原始接收器最近点的每帧均方差为 0.02276–0.03622，两步修正后为 0.01674–0.01781。

## 生成矩阵恢复与实测重编码

使用联合修正的观测，在两个固定拟合组各抽 300 个九字子集。模 x^16+1 的候选仅在各自拟合组评分，要求唯一多数一致。再用通过该筛查的子集在 QC1024 下独立求矩阵，且要求完整拟合帧同样多数一致。生成多项式为 9×7，每块 1,024 位，两个分组逐项相同。事后核对，论文对应分组的 20 个高裕量字也给出完全相同的矩阵。E020 的常数和一次项共 126 个二进制系数与新矩阵逐位相同。

| 拟合组旧帧索引 | 拟合帧硬判决直接通过 | 保留帧初始通过 | 保留帧有限修正后通过 |
|---|---:|---:|---:|
| 1、5 | 85 / 100 | 60 / 89 | 89 / 89 |
| 1、9 | 67 / 91 | 78 / 98 | 98 / 98 |

189 字中有 145 字直接通过。其余 44 字使用 E019 事先限定的符号替换搜索，一共改动 55 个核心硬判决，所有字通过。另以基于 FFT 的循环卷积逐位重编码，全部 **1,354,752 个校验坐标**一致。原 E019 硬判决代入这个后来冻结的矩阵，65 字直接通过。原始拟合的失败与部分观测字本身正确可以同时成立。

恢复结果支持论文的 Code 28 缩短关系。论文使用其校验阵做软译码，本轮使用有限符号搜索。变动数也有差异，论文为 80，本地为 55。两组共用一个捕获，且有重叠。重编码检验的是接收结果和冻结矩阵的一致性，发送真值及跨录波表现仍未知。[论文 §VI-G](https://arxiv.org/html/2610.29387v2#S6.SS7)

## 仍未知的坐标与负对照

缩短核心为 8,960 系统位和 7,168 校验位。母码前 256 个省略位在首个原始零综合字上可唯一反求为全零，系数秩为 256。每字中间的 256 个实际接收位和末尾两个额外星座标号位按原硬判决保留。省略位的全零解不解释这些空口值。

把中段接收值直接送到母码，或把虚拟零移至系统段末尾，两种对照均在全部 189 字上失败。全字取反后每字产生 3,548 个校验差异，排除了该接收标号下的全字对称。核心内三位都经验证的 5,375 个符号提供重调制比较。NMSE 为 0.01561–0.01852，固定翻转校验位后为 0.13276–0.16760。

本轮验证了完整系统生成矩阵与缩短核心，未重建论文的稀疏校验图。中间 256 位的编码和系统位内容仍待研究。
