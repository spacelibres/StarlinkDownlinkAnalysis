# E019 · Code 28 字界与块奇偶验证

## 接收范围

用 E010 的资源位置和 E015 的导频修正处理旧 480 MS/s 宽带录波。四个帧组（旧索引 1、5、9、13）分别含 50、50、41、48 个候选字。沿用 E017 的八点标号，保留按每字 5,462 个符号抽取的完整复数观测和 16,386 个硬判决。

采用 [Liu 等 §VI-G](https://arxiv.org/html/2610.29387v2#S6.SS7) 给出的缩短假设，将接收前 8,960 位映射到 9,216 位母码输入的编号 256–9,215。前 256 个输入补零，接收编号 9,216–16,383 用作校验。接收中间 256 位及最后两个额外标号位不送入校验假设。这个掩码描述待检验的坐标划分。

## 每字单独打包的边界

用拟合帧的最后一个符号选出最常见的两个星座点并冻结。两种划分均选中标号 0 和 4。冻结后，论文对应划分的保留帧为 9、13，全部 89 个末尾符号落在这两个点上。随机划分种子 2026112019，顺序 1、9、5、13，保留帧 5、13 的 98 个末尾符号也全部命中。四帧的最小距离差均大于 0.1719，以最近的非配对点与最近配对点的平方距离之差计。

| 模型 | 论文对应划分保留组 | 随机整帧划分保留组 |
|---|---:|---:|
| 每字单独打包，每 5,462 符号 | 89 / 89 | 98 / 98 |
| 16,384 位连续打包，沿用冻结点对 | 21 / 89 | 23 / 98 |
| 连续打包，允许重新在拟合帧选点对 | 25 / 89 | 20 / 98 |
| 扫描 5,400–5,500 间隔，去掉最后两个字，5,462 | 85 / 85 | 94 / 94 |
| 同一间隔扫描中最好的其他间隔 | 32 / 85 | 38 / 94 |

固定 5,462 间隔后，−8 至 +8 资源偏移中仅零偏移全命中。两种分组共享同一录波和部分帧。结果支持逐字占用独立末尾符号的安排，与原文图 11 的点对一致性相符。这套标号下，两个额外位置的 189 个硬判决均为 0，物理点对本身不能决定全局位极性及额外位生成规则。[原论文 §IV-B](https://arxiv.org/html/2610.29387v2#S4.SS2)

## 矩阵恢复的边界

在两个拟合组各按最小判决距离差选择 20 字，完整 QC1024 方程均有九个可逆主元与 11 条矛盾多项式方程，未得到局部生成矩阵。跟进把每个块折叠到模 x^16+1，在各自拟合帧内分别运行 300 次九字随机采样。两个组有 89、100 次得到可逆子样本，最佳精确一致集合均只有拟合用的九字。这个有限搜索的失败无法排除真实编码关系。

进一步把每块压缩为一个全部位的奇偶值。对七个校验块分别穷举 512 种输入块奇偶组合，按训练错误数选择。两个划分在每列均得到唯一最优，掩码也逐项相同。按最低位对应输入块 0 表示，十进制掩码为 434、358、236、489、497、482、485。

| 划分 | 保留块奇偶预测 | 199 次帧内整字校验置换的最高命中数 |
|---|---:|---:|
| 论文对应 | 482 / 623（77.4%） | 347 / 623 |
| 随机整帧 | 527 / 686（76.8%） | 384 / 686 |

置换在每个帧内交换完整七列校验奇偶向量，每次重新拟合。种子 2026112220。该对照提供拟合强度的参照，录波内各帧和字存在相关性。该关系对应循环多项式在 x=1 的取值，只检验每个块的奇偶，不能定位簇内移位、证明完整校验关系或确定省略位在块内的位置。
