# E023 · Code 68 资源边界与标号约束

## 信号与资源

使用旧宽带捕获中帧 1、5、9、13 的四段条件分配。按头部给定的数量和 2,048 资源的假设，共提取 1+3+2+1=7 个候选字。论文 §VI-H 对同一捕获未给出生成矩阵、位速率或编码参数。[Liu 等 §VI-H](https://arxiv.org/html/2610.29387v2#S6.SS8)

用户提供的 v2 PDF 已登记哈希。论文 §III 用八进制抽头 `(155, 123, 137)` 的终止卷积码和组级 CRC-8 验证头部。§IV 从条件 MCS 布局读出格式和数量，其中 `68 = 2² + 2⁶`，早期六位读法得到 `4`。§VI-H 单独讨论七个候选字，由同一份 IQ 复现，适用于同捕获方法对照。[附件登记](../../references/research_register.json)

沿用 E021 的逐帧采样网格修正。用同帧较早 Code 28 星座学习剩余的各载波增益，再用相反奇偶载波的判决标定 Code 68 时隙增益。每帧均观察到全部 16 个候选星座点。最近星座点均方差从 0.02131–0.03556 降至 0.01690–0.01741。受检 Code 68 码的校验结果未参与接收标定。

从每帧最末 512 个参考资源估计填充的复常量。在预测边界前后各 64 个资源的区间，用四阶方格 16 点模型和参考常量模型比较局部拟合代价。四个分配末端的实测最小代价位置均与预测一致。以八点和十六点模型比较起始点时，最优位置在预测之后 2–4 个资源。前后星座点部分重合，这个局部检测支持区间切换，对绝对起始位置只有有限分辨能力。它也不单独证明每个 2,048 资源单位的内部编码边界。

## 精确标号方程

把 16 个已判决星座点各自的四位标号作为 64 个二进制变量。把已知校验对每个变量的贡献累加，得到齐次方程。冻结算子分别为图 12 的 Code 3 稀疏校验和 E016 的 Code 21 系统生成关系。两点的标号若对整个零空间都相同，就没有任何满足所有方程的双射标号。该条件不需要逐一枚举全部置换。

| 冻结算子 | 拟合帧 5、9 的秩 / 零空间维数 | 保留帧 1、13 的秩 / 零空间维数 | 必然碰撞的不同点对数 |
|---|---:|---:|---:|
| Code 3 | 63 / 1 | 63 / 1 | 120 / 120 |
| Code 21 | 64 / 0 | 64 / 0 | 120 / 120 |

Code 3 的精确解仅有全零和全一，Code 21 仅有全零。在固定 Code 39 Gray 约定下，两者的每字非零校验分别为 1,986–2,072 和 1,519–1,568。

## 符号错误对排除能力的影响

给七个合成 Code 3 码字使用相同的 16 点标号。无噪声时，方程零空间包含生成使用的双射，秩为 62。以 1% 概率替换星座点后实际改动 131 个符号，秩升至 63，正确码也表现为所有点对迫使碰撞。因此精确方程的失败不能直接推断发送端采用不同编码。[Valembois 的含错线性码辨识模型](https://doi.org/10.1016/S0166-218X(00)00353-X)

跟进按每字最近两点的平方距离差去掉低裕量符号，丢弃触及这些符号的所有 Code 3 校验。去掉 20% 后，实测拟合帧仍有 4,904 条校验、保留帧仍有 2,222 条，两者秩均为 63。合成复高斯方差 0.02 的输入有 43 个误判，舍弃 5% 低裕量符号后恢复秩 62。用原双射逐条复算，拟合和保留组的有效校验均无差异。方差 0.04 的输入有 531 个误判，舍弃至 20% 时原双射仍分别有 29、16 条校验差异。两个方差是明确的模拟条件，实际误判可能具有不同的相关性。

## 未冻结的系统模型

固定物理点上的 Code 39 Gray 序列，检验七组系统块分割，均在拟合帧使用五字并至少留有一个额外方程。其中四组得到全部可逆主元，模 x^16+1 和完整多项式方程均有矛盾。另三组未得到足够可逆主元。没有候选达到预设的完整拟合门，未进入保留帧重编码。由此缩小了固定标号、固定资源及无擦除假设下的候选范围。Code 68 的系统位数、具体编码及字段意义仍待确定。
