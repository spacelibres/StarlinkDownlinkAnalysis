# E020 · Code 28 论文对照与逐阶复现

## 论文给出的基准

核对用户提供的 30 页 arXiv v2 PDF。§VI-G 在印刷页第 18 页，明确给出了 Code 28 的母码尺寸 (16,384, 9,216)、循环长度 1,024 和缩短核心 (16,128, 8,960)。论文从 100 个拟合字恢复生成关系，在另外 89 字上预测 637,952 个校验位，并报告全部 189 字经过软纠错后重编码一致。在似然尺度 0.02 下共改变 80 个硬判决。以上是论文报告的结果。[论文 §VI-G](https://arxiv.org/html/2610.29387v2#S6.SS7)

PDF 的 SHA-256 为 f4ebd27e22951577a16c73c7ec0ffae54532c6c1d326c5884e88fb8897db0e1f。PDF 无嵌入附件。与图 12 给出 Code 3、12、10 的移位表不同，Code 28 小节给出参数、坐标和验证统计，本轮未在 PDF 或核对到的作者 GitHub 主分支数据目录获得 Code 28 的具体生成矩阵。本地仍以论文数值和既有录波作复现依据。[作者数据目录](https://github.com/misaka666/Starlink-Downlink-Analysis/tree/main/data)

## 降低本地拟合问题的维度

E019 已确认字界，完整 QC1024 硬判决拟合有矛盾。对候选生成多项式先令 t=x+1。每个块在 t 的常数项是总奇偶，t 的一次项是原块所有奇数索引位的异或。逐阶把已拟合的低阶贡献从接收校验中扣除，枚举下一阶的九个输入系数，对每个校验块共有 512 种可能。这是重根多项式的系数变换，保持论文的位序和缩短假设。[Castagnoli 等重根循环码](https://www.isiweb.ee.ethz.ch/papers/arch/gcasta-mass-inspec-1991-1.pdf)

沿用 E019 的两种分组，论文对应分组保留帧 9、13，随机分组保留帧 5、13。两组共享部分帧和同一次录波。每阶只在拟合帧选系数。E016 的 Code 21 正对照从硬判决重新拟合出全部 960 个预设低阶系数，与冻结矩阵逐位一致。

## 本地结果

| 观察 | 论文对应分组保留组 | 随机分组保留组 | 两种拟合的一致性 |
|---|---:|---:|---|
| 常数项硬判决 | 482 / 623 | 527 / 686 | 7 / 7 列 |
| 一次项硬判决 | 500 / 623 | 509 / 686 | 5 / 7 列 |
| 一次项逐符号似然，尺度 0.01、0.02、0.04 | 500 / 623 | 537 / 686 | 6 / 7 列 |
| 一次项按字加权，12 种权重 | 500 / 623 | 563 / 686 | 7 / 7 列 |

逐符号方法根据星座点距离形成八点联合概率，对同一符号内涉及的多个位用联合奇偶计算。符号之间使用独立近似。按字加权方法以八点概率估计每字判决风险 e，然后对每字的硬判决方程乘以 (1+e)^−p。测试了三个似然尺度和四个权重指数，完整保存全部 12 种组合。这两种方法是看过硬判决分歧后开展的探索。按字加权的同一个常数和一次项在所有 12 种组合及两个划分中反复出现。两组的一次项预测分别超过 199 次帧内固定预测置换的最高值 362 和 385。硬判决的 99 次置换则每次重新拟合，两个对照的含义有别。

按照最低位对应第 0 个系统块，常数掩码保持为 434、358、236、489、497、482、485。一次项七列为 479、237、148、144、84、57、68。二次项在加权分组之间仅有 4 或 5 列一致。估计达到模 (x+1)^2 的一致前缀，更高阶仍随样本组和权重变化。完整矩阵、全部码字重编码与未知位的语义仍未本地复现。
