旧模型使用种子 0x0270、`b[n+15]=b[n]^b[n+1]`、半周期移位 16383。当前模型使用解析 PN/相位约定。对 300×1020 = **306,000** 个全部 loaded 资源逐点比较：

`R_old = −R_current`，最大复数差异 `1.225e−16`。

差别仅是全局 π 相位，不需要再搜索另一个扰码器。该负号与 BPSK 全局极性/相位消歧属于同一约定问题，不能当成新的空口信息。

## 4. 从 IQ 重解第一头部

E009 在当前目录实现并运行了：固定帧几何 → FFT → 跳过边缘导频的 228 资源 → PN 去旋转 → 盲 BPSK 相位/斜率 → 前缀极性 → 软 Viterbi → CRC → 重编码。

与旧脚本的实质区别：旧方法曾尝试两种极性并用 CRC 选中结果；当前实现只用预先已有的 16 位前缀 0x3048 对应的前 48 个编码资源确定极性。**CRC 不参加相位、参数、符号分支的选择**。全部接收与对照执行完，才打开旧存档头字比较。

| 第一头部两个保留字 | 次数 | 当前 CRC | 当前硬重编码差异 |
|---|---:|---|---:|
| `0x3048A060 / 0x00000029` | 8 | 全通过 | 0 |
| `0x3048A0A0 / 0x000000E8` | 5 | 全通过 | 0 |
| `0x3048A0C0 / 0x0000002E` | 4 | 全通过 | 0 |

合计 **17/17**，与旧存档逐位相同。当前最小前缀编码相关为 0.9642。强制初末状态 0 是译码器假设，尾部零不是一项独立的空口证明。

这是本项目从“合成编码演示”推进到“真实宽带 IQ 的协议后端正对照”。它继承了旧工程已知方法，不是重新发现协议。当前 4/13 帧随机分组只是条件性软件回归展示：历史参数曾在相同捕获上选择，不能伪装成全程未打开的新数据。

## 5. 负对照揭示 CRC 的局限

用同一接收/相位/极性/译码链处理 **512** 个资源顺序打乱的控制：

- **1/512** 偶然 CRC 通过。
- 该假阳性仍有 **58/228** 个编码硬判决与重编码不一致，前缀相关只有 0.1699。
- **CRC 且硬重编码完全一致**：实测 17/17；这组有限对照为 0/512。

这不是普遍误报率为零的证明，也不构成身份认证。资源排列只是一种空假设，重复帧及相同捕获不能当作独立物理实验。

## 6. 哪些旧结论不自动继承

1. 原 WAV 的编号/地点拟合属于轨道归因支路。本轮没有验证，更不能把推断地点当采集真值、把候选编号当信标字段。
2. 旧报告的“载荷无离散星座/算术上不能译码”依赖接收校正、有限星座零假设及 SNR 模型。本轮只复现第一头部，没有复现其 payload 否定结论。
3. 旧文列出的 Gaussian 容量 6.24 bit/symbol 高于所比较的 6.00，本身不是容量不足证明；实际编码率还改变净信息速率要求。这不证明 payload 一定能译码，但足以要求重审“已经不可能”的措辞与前向模型。
4. LEO Tracker 的已知导频高准确率只针对已知序列，不能直接作为未知载荷的 BER 或完整头部能力。
