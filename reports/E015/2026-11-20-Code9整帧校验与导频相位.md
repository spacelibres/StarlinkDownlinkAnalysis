# E015 · Code 9 整帧校验与导频相位

## 假设和输入

使用 E009 的 480 MS/s 宽带实测 IQ、E010 的 CRC 头部记录和 E011 的条件资源布局。五帧（旧索引 0、4、8、12、16）给出 31 个候选 Code 9 码字。每字 2,048 个非导频资源。以接收实轴符号判决，前 1,280 位作为系统位，后 768 位作为校验位，QC 块长 128。这些参数来自已发表模型，参见 [Liu 等 §VI-D](https://arxiv.org/html/2610.29387v2#S6.SS4)。

论文对应划分用帧 0、4、8 拟合，保留帧 12、16。第二种划分以种子 2026112015 排列整帧，顺序为 16、8、12、4、0，前三帧拟合、后两帧保留。两种划分共享同一录波和部分帧，保留位数不相加。矩阵拟合只读取各自训练组。

## 首次失败与导频校正

以 E012 的接收前端运行，两组输入秩都达到 1,280，但增广消元分别出现 1,024 和 1,664 条非零矛盾行，无法生成矩阵。检查逐时隙相位时，发现负边缘与正边缘导频的拟合相位差在时隙 17–19 跨过半周。导频集中在两端，错一整周时两端仍近似对齐，而中间频带会得到随载波编号变化的错误相位校正。旧前端在 12,000 个保留导频上仍为零标号差异。

第二次运行保留相同的训练组和码字位置。把两个训练导频组的中心记为 $k_L,k_U$，斜率为 $\beta$。计算每时隙的边缘相位差 $\beta(k_U-k_L)$，以 SSS 附近的零差作为起始分支，沿时间展开。若展开补了 $2\pi m$，则从载波 $k$ 的相位中扣除 $2\pi m(k-k_L)/(k_U-k_L)$。这一操作依赖相邻时隙的有效相位差变化小于半周。分支由导频确定。规则在看到首次失败之后提出，保留组仅相对矩阵拟合保留。

以判决点为参考，31 字合计 NMSE 从 0.59591 降至 0.02547。实部绝对值小于 0.2 的资源由 6,781 降为 0，在相同资源上有 24,756 个硬判决变化。校正后的 12,000 个保留导频也保持零标号差异。变化量衡量两种接收结果的差别，传输真值未知。

## 冻结校验结果

| 整帧划分 | 拟合字 | 保留字 | QC 方程 | 输入秩 | 矛盾行 | 保留校验位差异 |
|---|---:|---:|---:|---:|---:|---:|
| 论文对应 | 18 | 13 | 2,304 | 1,280 | 0 | 0 / 9,984 |
| 固定种子 | 23 | 8 | 2,944 | 1,280 | 0 | 0 / 6,144 |

两个 1,280×768 生成矩阵逐项一致，均与 QC128 移位交换。全部 31 个接收码字的 768 个校验位均与预测一致。由 $H=[P^{\mathsf T}\mid I]$ 直接构造的 768×2,048 校验阵因含单位阵而满秩，所有字的综合为零。该矩阵每行权重 627–668，稀疏等价表示尚未本地重建。

- 两个资源错位对照各 31 字全部失败，前移每字差 348–410 位，后移差 358–402 位。
- 冻结 Code 5 用于这 31 个 Code 9 字，每字差 469–547 位。反向用 Code 9 检验 E012 的 93 个 Code 5 字，每字差 351–419 位。同为 BPSK 和 2,048 位码长的两组观测由校验关系区分。
- 全字取反使每个 Code 9 字产生 256 个校验差异，在此次接收标号下可排除取反分支。E012 已见的 Code 5 全字取反简并不能移用于此。
- 论文划分中，保留校验的预测重调制 NMSE 为 0.02545。固定翻转每隔 16 个校验坐标中的第一个后为 0.27733。随机划分对应 0.02360 和 0.27032。

## 复现

`python tools/run_experiment.py validate_code9 --run-id <新编号> -- --unwrap-slope`。原始失败和修正运行分别保存在 [v013-code9](../../runs/v013-code9/manifest.json) 和 [v013-code9-time-unwrapped](../../runs/v013-code9-time-unwrapped/manifest.json)，退出码分别为 2 和 0，封存证据改动均为零。[同一份现行代码关闭校正的对照](../../runs/v013-code9-wrap-control/manifest.json) 复现了初次拟合失败和全部初次观测数组。已按相同资源重算判决点误差，并直接核验矩阵、单位阵和码字综合。55 项单元测试通过。

本轮确认旧宽带录波中 Code 9 的系统编码结构。Code 9 的跨录波转移、稀疏矩阵、真实 BER 和系统位承载的字段含义仍待验证。
