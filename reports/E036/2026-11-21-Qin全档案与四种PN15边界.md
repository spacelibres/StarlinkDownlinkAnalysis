# E036 · Qin 全档案与四种 PN15 边界

使用 Qin、Psiaki、Bowman 和 Humphreys 公布的 2025-01-21 同次观测中全部 1,009 帧频域符号。作者档案的硬判复数点已经历其接收处理。保存每个被检验的头部原复数切片和按字拆分的目标观测。HTTP 分段沿用 E034 的固定 ETag 与本地哈希。源站 TLS 验证限制沿用 E034 来源记录，未以 Zenodo 分卷对整个 MAT 文件做校验。源数据 CC BY 4.0。[作者数据及许可](https://rnl-data.ae.utexas.edu/datastore/supplementaryMaterial/qin-starlink-pilots/)

## 头部清点

用 E034 已冻结的已知前缀、频域参考和卷积码验证两级头部。1,009 帧的两级 CRC 和第二头部 20 位分配打包均通过。117 个旧档案结果逐项一致。独立复算 2,018 个头部 CRC，并复算出重编码与原硬判共 112 个编码位差异。共看见 19 种条件格式标签。未见 Code 68，该范围仅限作者筛选后的一个档案捕获。MCS 6、35、42、93 分别在 21、79、15、4 帧出现，所有头部与原始切片可离线复算。[Liu 等头部与条件分配](https://arxiv.org/html/2610.29387v2#S4)

## 字长验证

冻结 E035 的资源字长。对全部 119 个含目标 MCS 的档案帧检验 60 位尾段。117 帧检测到尾段且与资源模型完全一致。帧 515 和 516 的 MCS 35 分配未获终点通过，因此不进入后续字级检验。原拟合段以外有 64 个 MCS 35 帧支持 5,462 资源每字。MCS 93 用帧 54 的剩余资源获得 3,277；保留档案段的帧 66、93、101 全部精确复现终点。MCS 93 的保留证据限于三个字。

## 冻结 PN15 转移

使用 MCS 6 的实部符号、旧 Code 28 的八点标号、旧 Code 39 的方格 16QAM 标号，以及 E030 的交叉 32QAM 标号，分别解调 6、35、42、93。35 和 93 脱去超出 16,384 位候选字的末符号额外位。PN15 相位和位序固定。以 13 帧 HDF5 区块分组，用种子 2026112136 加对应格式号划分。MCS 93 沿用字长拟合所在的一个组。候选系统区右端为拟合区间右端中位数取最近 256 位倍数。沿用最短 512 位、差异率最多 10% 的门限。档案段提供保留约束，同次观测的字和比特相关。

|---:|---:|---:|---:|---:|---:|
| 6 | 16,384 | 10,240 | 8 | 8 | 66,201 / 66,260 |
| 35 | 5,462 | 9,472 | 344 | 32 | 167,869 / 170,525 |
| 42 | 4,096 | 8,704 | 11 | 10 | 54,634 / 55,529 |
| 93 | 3,277 | 13,568 | 3 | 1 | 11,649 / 12,074 |

所有 51 个通过的保留字都是分配末字。以每字相邻 256 位核对转折，MCS 6 的保留差异在候选右端前后分别为 5/2,048 和 981/2,048，MCS 35 为 103/8,192 和 4,150/8,192，MCS 42 为 28/2,560 和 1,306/2,560，MCS 93 为 10/256 和 123/256。PN ±1 相位对照均无命中。35 与 42 的旧物理标号能读出可预测的位坐标，编码关系仍单独验证。

## 校验关系

MCS 6 测试冻结 Code 10 校验，以及 Code 9 和 21 在 1,024 位循环块保持原指数或成比例放大的两个模型。48 字无完整通过。按 10,240 位与 6,144 位切分，在 40 个拟合字上分别用原硬判和固定 PN 修正做 256 次循环环投影搜索。可逆试验为 95 和 37 次，16 阶投影未找到过半共识。MCS 35 套用 Code 28 的原缩短核心，501 字均失败。MCS 42 套用 Code 39 的原矩阵，16 字均失败。相同码率或相同长度可容纳不同循环指数和编码模型；受检变换及硬判质量限制了对未知校验矩阵的结论。[循环块提升方法](https://doi.org/10.1109/LCOMM.2006.06031) · [论文复现仓库](https://github.com/misaka666/Starlink-Downlink-Analysis)
