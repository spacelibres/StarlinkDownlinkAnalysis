**摘要。** 本文利用同一正交频分复用（OFDM）帧内已验证的编码块估计 Starlink Ku 波段下行信号的残余信道。在包含 1,009 帧的公开数据中，四种调制与编码方案（MCS）共包含 43,040 个编码块，通过完整奇偶校验和留出波形检验的编码块由 39,415 个增至 41,169 个。另四种方案只有部分校验关系已知，系统位和高地址校验位均获验证的编码块由 1,648 个增至 2,184 个，总计 2,792 个受检块。MCS 57 新增八个通过 CRC-24 校验的目录。同组重复观测给出擦除位置的候选值，目标波形的较低裕量判决支持 1,145 位，反对 53 位。所有目标仍有擦除。带观测掩码的 512 位投影在全部 28 个高地址正对照上复现已知校验关系。低地址投影缺少有效观测、方程欠定，或方程相互矛盾。另用 137.055 MHz VHF 数据包中的状态向量预测一对包的前导差分多普勒，实测减预测为 +1.08 Hz。结果分别揭示了接收机、未知信道码和有限带宽对恢复的影响。

**关键词。** 信道估计、擦除掩码、正交频分复用、被动观测、准循环码、Starlink。

## 1. 引言与观测资料

先前研究 [1] 从每帧首项分配 Code 5 读取了时间、卫星编号和地固状态，并用相对到达时刻检验了状态解释。本文利用实收 Code 5 符号和帧内其他参考符号，估计后续分配所用资源的信道。波形和导频模型沿用 Humphreys 等 [2] 和 Qin 等 [3] 的研究。两级头部布局和编码模型基于 Liu 等 [4] 的结果。H1 是第一级头部，H2 用 MCS 标签和编码块数描述后续分配。每项分配占用连续的传输资源。

主要数据为 Qin 等 [3] 公开的均衡后频域复数样本。全部 1,009 帧的实测帧尾均与 H2 预测一致。这些样本与 250 MS/s 同相和正交分量（IQ）录波 [4] 共享部分采集数据，因此可用于比对同一观测的两种表示。早期 480 MS/s 录波来自另一份独立采集。原生窄带观测与 21CMA 的 VHF 录波分别用于检验其他测量问题 [6, 7]。不同接收机配置之间的比较均使用同一批样点。

## 3. 信道估计与波形检验

Qin 等 [3] 发布的频域样本已完成初步均衡。本文先移除每个参考时隙的复标量，再估计残余的频率选择性响应。令 x_i 为已知参考符号，y_i 为实测复数值，I_t 为时隙 t 保留的参考符号索引集合，星号表示复共轭。式（1）给出复标量的最小二乘估计。式（2）给出载波 k 的局部残余增益，其中 W_k 是以 k 为中心、宽 17 个数据载波的窗口内样本集合，t(i) 是样本 i 所在时隙。以拟合残差估计噪声方差，并将归一化方差限制在 0.0125 至 0.5 之间。检验目标时隙中的偶数载波时，以奇数载波估计该时隙的复标量，反之亦然。

> (1) $\hat{a}_t=\frac{\sum_{i\in I_t}x_i^{*}y_i}{\sum_{i\in I_t}|x_i|^2}$

> (2) $\hat{g}_k=\frac{\sum_{i\in W_k}x_i^{*}(y_i/\hat{a}_{t(i)})}{\sum_{i\in W_k}|x_i|^2}$

对归一化复数观测 z，分别对比特位置 b 上标为 0 和 1 的星座子集求似然和，以式（3）计算对数似然比。式中方差采用固定值，或由参考符号估计。正值支持比特 0。留出的符号不参与复标量估计，其比特对数似然比置零。将译出的比特重新编码和调制，得到预测复数样本 p_i。式（4）以观测能量归一化，计算预测样本与留出观测 z_i 之间的平方误差。

> (3) $L_b(z)=\log\frac{\sum_{x\in\mathcal{X}_{b,0}}\exp(-|z-x|^2/\hat{\sigma}^{2})}{\sum_{x\in\mathcal{X}_{b,1}}\exp(-|z-x|^2/\hat{\sigma}^{2})}$

> (4) $E(z,p)=\frac{\sum_i|z_i-p_i|^2}{\sum_i|z_i|^2}$

### 算法 1. 用帧内参考估计信道并检验恢复结果

```text
指定参考编码块、星座、编码模型和待估计的位置。
按相应 MCS 将已验证的 QAM 编码块重新调制。
Code 5 仅使用可直接读取的 BPSK 符号。
估计时隙标量、局部载波增益和残余方差。
先按适用的固定擦除位置译码，再分别加入两组互不重叠的整符号擦除。
从该次时隙标量估计中排除擦除符号，并将相应比特对数似然比置零。
要求三次译码结果一致，且均满足适用的奇偶校验方程。
重新编码和调制，分别比较系统符号与校验符号的预测波形和留出观测。
每组留出样本的归一化误差均须低于 1，且低于块内错位对照的误差。

```

每组留出样本包含 32 个系统符号和 32 个校验符号。对编码模型只知一部分的方案，低地址校验位及跨越区段边界的完整符号均排除在三次估计之外。对分配末块，先用实测样点定位填充边界，再使用 PN15 填充序列作为先验。两组留出位置即使落在 PN15 已知位置也保持擦除。三次译码在最终恢复的 83 个末块上逐位一致。移除 PN15 先验后，其中 69 个块在三次译码中均未复现完整结果。

| --- | ---: | ---: | --- |
| 同一分配中已验证的相邻编码块 | 298 | 222 | 平坦信道估计通过 3 个 |
| 同帧其他 MCS 中已验证的编码块 | 1,709 | 500 | 平坦信道估计通过 2 个 |
| 两个 Code 5 参考块，初次评估 | 347 | 141 | 仅用增益时通过 133 个，仅用方差时 0 个，平坦估计时 0 个 |
| 两个 Code 5 参考块，其余符合条件的目标 | 2,473 | 775 | 仅用增益时仍有 731 个通过 |

## 4. MCS 57 的接收性能与编码辨识

将 Code 5 信道估计应用于 MCS 57 全部 487 项分配中的 14,330 个编码块窗口。两种接收机配置采用相同的 16QAM 比特标号。在判决裕量为 0.08 时，两个 Code 5 块联合估计后，原本擦除的 1,447,124 个位置可以判决，原本可判决的 730,320 个位置变为擦除。两种配置均能判决的 113,705,831 个位置中，有 50,142 位的判决不同。在两种配置均可读的 237,930 个 PN15 填充位上，判错数由 651 降至 612，误码率由 0.274% 降至 0.257%。在已知填充区以外，分歧反映的是判决对接收机配置的敏感性。

采用改进后的接收方法读出 31 个通过 CRC-24 校验的目录，其中八个为新增位置，累计得到 45 个不同位置的目录。另确定了 24 条新增外层记录的边界，合计在头部和正文中读出 69,379 位。每条记录仍有擦除。判决裕量为 0.08 时，所有非末块均有擦除，因而没有完整样本可用于估计秩。对 128 位和 256 位两种假定周期各搜索六次，得到 285 个四项校验关系候选，每个只出现一次。检验方法要求候选至少在两次搜索中出现，才用独立的观测组评估。相同观测掩码下，合成的四项关系在 3,583 次比较中全部通过。将其中一项错位后，通过率为 49.68%。

对可能重复的 MCS 57 编码块，分别按系统位和校验位选择配对，再用未参与筛选的整符号样点做双向比较。各重复参考与其目标均属于同一观测组。采用软合并方法 [5]，把参考集合 D 中各观测在星座点 x 上的对数似然相加。式（5）中，下标 d 指相应的参考观测。合并后按比特标签子集求取比特似然。只考虑此前六种接收机配置均擦除的位置，并要求参考观测在至少 0.08 的判决裕量下相互一致。再用两个 Code 5 参考分别估计目标本身的比特。当目标的两次判决在 0.02 裕量下相同，就可判断目标是支持还是反对候选取值。

> (5) $\ell_{\mathrm{pool}}(x)=\sum_{d\in\mathcal{D}}\ell_d(x)$

## 5. 用带掩码的投影检查缺失校验

按已知编码模型的右缩短约定对齐系统位。低地址区分别从两端划出 512 位窗口，窗口中不可见的位置记为擦除。以高地址区首个已验证的 512 位块作为正对照。折叠模数为 m 时，式（6）的 F 对每个余数 j（0 至 m − 1）所属的各位 b 取异或。观测标记 s 在可见位置为 1，其余为 0。只有各组成位均可见时，掩码 M 的乘积才等于 1。

> (6) $F_m(b)_j=\bigoplus_{r=0}^{512/m-1}b_{j+rm},\qquad M_m(s)_j=\prod_{r=0}^{512/m-1}s_{j+rm}$

对每个可见投影，二元设计矩阵 A 包含依循环位置对齐的系统位折叠和截距项。θ 是未知系数向量，q 是观测到的校验投影。式（7）仅在方程相容且矩阵的列秩等于系数个数时有唯一解。如果消元得到一行全零系数却对应非零校验值，所提模型就无法精确满足这些观测。

> (7) $A\theta=q\quad\mathrm{over}\ \mathrm{GF}(2)$

### 算法 2. 筛查循环校验假设

```text
按右对齐缩短约定补零，对系统区逐块折叠。
用模数 1、2、4、8、16、32、64 折叠候选校验窗。
只纳入所有组成位均为实收的输出投影。
以整组观测为单位划分校准集和检验集。
用二元消元拟合仿射关系，计算秩并统计不相容方程。
在留出观测和系统块错位对照上检验唯一的非常量解。
要求留出观测数充分、对齐时零误差且错位时产生误差。
分别统计方程欠定和方程不相容的情形。
```

排除用于建立已知编码模型的早期观测组，将相关重复观测放在同组，再划分为 30 个校准组和 30 个检验组。按 MCS 分别评估时，28 个高地址正对照均满秩，且在留出数据中没有误差。98 项低地址检验中，70 项缺少完整的校准投影，17 项欠秩且方程相容，11 项出现不相容方程。合并各方案中紧邻高地址区的最后一个 512 位低地址窗口后，32 和 64 两种折叠模数均达到满秩，但都出现不相容方程。出现这类矛盾时，观测值与所提模型无法同时成立。原因可能包括比特判决错误或对编码结构的假设有误。

## 6. 弱头部与原生窄带的观测限制

250 MS/s 录波的主时轴和偏移时轴共包含 51 个不同的同步事件。其中验证了 37 个 H1 和 26 个 H2。两个偏移事件的分配字段得到互补卷积输出子集和实测帧体边界的支持。19.425854 ms 处固定非 CRC 头部信息后，按其与 42 个实收编码资源的一致性对 256 种 CRC 字节取值排序。在合并样本的 24 次比较中，十六进制 EC 均排第一。216 次使用错位资源或错误 PN 序列的对照均未选中 EC。分成互补两组后，各组未能稳定选出同一字节。26.092421 ms 处的两组结果也有冲突。三个此前已验证的对照头部同样未满足这一更严格的分组一致性条件。

| 时间（ms） | 帧体支持的分配 | CRC 证据 |
| ---: | --- | --- |
| 15.425910 | MCS 70 × 40，MCS 92 × 1 | 此前通过 H2 检验，分组比较结果不稳定 |
| 19.425854 | MCS 70 × 43，MCS 78 × 1 | 合并采样得到 `EC`，两半不稳定 |
| 26.092421 | MCS 70 × 3，MCS 85 × 41 | 一半读到 `7D`，两半冲突 |

将 LEO Tracker 的十个原生 2.5 MS/s 短窗 [6] 的实际通带投影到 1,009 个 Qin 帧的 H2 编码位置。计算以 H1、H2 起点、头部前缀、描述符数量和填充均已知为条件，并假设通带内判决正确。结合两个接收机的通带后，175 个 H2 至少有一个编码资源可见，87 个 H2 的可见位置能约束分配描述符。最高秩为五，无法唯一确定任何一份完整分配列表。一对实测 Qin 头部具有相同的 H2 布局和五个相同的可见编码位，但它们的实收分配不同。

## 7. 独立的 VHF 轨道状态检验

21CMA 公开的两段 137.055 MHz 电压数据包含相隔 99.987 s 的两个数据包 [7]。两包的物理层头部和载荷均通过 CRC 校验。第一包含有效的 GPS 历元和地心地固坐标系（ECEF）下的位置及速度，第二包的 GPS 周与状态字段均为零。设 κ 为扫频斜率的绝对值，δt 为定时偏差。上扫频和下扫频去啁啾所得频率峰值分别受符号相反的 κδt 影响。式（8）对两类频率峰值分别取中位数再求平均，以估计载频偏移。

> (8) $\hat{f}_{\mathrm{CFO}}=\frac{\mathrm{median}(f_{\uparrow})+\mathrm{median}(f_{\downarrow})}{2}$

用含 J2 的引力模型从第一包的 GPS 历元传播轨道状态。式（9）中 r 和 v 分别为卫星位置与速度，r_s 是公开的测站位置 [7]，f_0 是载频，c 是光速。第二次前导的预测多普勒减去第一次的预测值即为预测频差。取差可抵消两次观测共有的固定接收机频偏。

> (9) $f_{\mathrm{D}}=-\frac{f_0(\mathbf{r}-\mathbf{r}_s)\cdot\mathbf{v}}{c\Vert\mathbf{r}-\mathbf{r}_s\Vert}$

| 状态或历元解释 | 预测频差（Hz） | 实测减预测（Hz） |
| --- | ---: | ---: |
| GPS、地固速度、含 J2 | −3,525.00 | +1.08 |
| GPS、地固速度、球形引力 | −3,524.86 | +0.94 |
| GPS、速度分量视作惯性分量 | −3,454.92 | −69.00 |
| 把 Unix 字段用作状态历元 | −2,888.22 | −635.69 |

实测频差为 −3,523.92 Hz。用另一种下变频方法得到 +1.11 Hz 残差。对两组互不重叠的前导样点分别采用两种下变频方法，残差范围为 −3.51 至 +6.39 Hz。这个范围描述一对数据包对处理方法和样点选择的敏感性。这对观测支持 GPS 历元和地固状态的解释。光行时、场地影响和时钟偏差尚无独立标定，Unix 字段的含义仍待确定。VHF 测量所用的信号、接收机和包格式均与 Ku 波段观测独立。

## 8. 结论与合作方向

对四种编码模型完整的方案，帧内信道估计增加了完整恢复的编码块数。对其余四种部分已知的方案，同样的方法扩大了可完整读取的系统字节范围，低地址奇偶校验方程仍待辨识。MCS 57 的目录校验和重复波形约束了数据流中的部分位置。由于非末块仍有擦除，且未获得可复现的稀疏校验关系，完整编码尚未确定。512 位投影能够区分观测不足与方程不相容。所读出的记录边界、通过的 CRC 和留出波形比较支持上述传输层结论。应用层业务消息的内容尚未得到验证。

后续可用独立观测组检验 MCS 57 的候选校验关系，寻找与高地址正对照相容的低地址校验模型，并用公开 IQ 录波进一步检验弱 H2。对 VHF 差分多普勒进行独立分析，可评估定时和下变频处理的影响。欢迎与作者联系交流。
