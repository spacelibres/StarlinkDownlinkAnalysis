# Code 5 首条记录中的时变位段

从已经验证的 Code 5 记录里，找到七组稳定依随相对帧时刻变化的位段。其中六组用二次式估计，在 422 个主时轴留出帧上的最大误差小于 0.57 个整数单位。七组位段和此前的帧计数位不重合，另在离轴条目上支持内容计数对应的时刻。当前证据给出位段坐标及变化规律，完整位宽、符号、单位及字段语义仍待确认。[E079 帧计数](../../experiments/E079/README.md) · [E091 内部目录](../../experiments/E091/README.md)

## 选择位段与留出评价

只读通过 E091 外层校验和目录 CRC 的字。相对起点 $L$，在首条记录前 66 字节扫描 14 位小端窗口，排除与已知 32 位帧计数重叠的窗口。用 570 个主时轴校准帧的到达时刻编号 $n$，对 $x=(n-5000)/3000$ 拟合 $a+bx+cx^2$。候选需在校准组变化至少 64 个整数单位，且绝对误差的 99% 分位小于 1.10。将相邻通过的位窗合并，每组保留最靠前的 14 位。此规则保留七组，选择不使用留出指标。整组划分继承 E077，本次是在同一档案上进行的探索后验证。[E077 整组划分](../../experiments/E077/README.md) · [Qin 等的帧测时方法](https://radionavlab.ae.utexas.edu/wp-content/uploads/qin_starlink_timing_properties.pdf)

| 首条记录零基位偏移 | 留出二次拟合 RMSE | 留出线性拟合 RMSE | 留出绝对误差 ≤1 |
|---|---:|---:|---:|
| 97 | 0.289 | 0.359 | 422／422 |
| 155 | 0.288 | 6.602 | 422／422 |
| 221 | 0.287 | 2.391 | 422／422 |
| 252 | 0.291 | 29.870 | 422／422 |
| 293 | 0.283 | 0.291 | 422／422 |
| 323 | 0.291 | 0.396 | 422／422 |
| 459 | 0.451 | 8.210 | 413／422 |

以种子 `2026112193`，199 次将留出组之间的平均时刻打乱，同时保持同组内部时差。七组位段的正确时序均胜过全部错时对照。偏移 155、221、252 和 459 的线性误差明显较大，说明二次变化在该观测区间可以分辨。短原始宽带另分连续双帧组校准线性模型。两套采集的保留值都在约一个整数单位内，旧 480 MS/s 的偏移 293 位段在该短段为常量，各字段斜率可以随捕获变化。250 MS/s 与 Qin 档案存在源重叠。

## 离轴与记录边界

保持已经冻结的二次式，分别用 17 个离轴条目的到达编号和载荷计数评估。七组位段的 RMSE 都支持载荷计数时轴。偏移 252 的 RMSE 从 12.84 降至 0.303。E080 的档案帧 956 位于主到达时轴，但载荷计数比到达编号多 5 帧。用这一帧的内容时刻重新代入七个固定模型，每组都改善，最大绝对误差由 10.51 降至 0.41 个单位。该一致性支持同一记录内存在统一的时序状态，无法据此归因到某颗卫星或绝对时钟。[E080 时间例外](../../experiments/E080/README.md)

另以目录预测的边界核对字节。429 个留出档案记录均在首条记录最后一个 04 字节之后有 25 个零字节，且下一条的前 20 个字节匹配校准组的固定前缀。10 个 250 MS/s 原始 IQ 码字也匹配。18 个旧 480 MS/s 码字在这两条规则上均不同，仍支持 E091 的两字节记录标记。下一条的通用长度公式仍待验证。[E091](../../experiments/E091/README.md)

## CRC24 能提供的窄带信息

用冻结 Code 5 生成矩阵计算接收方程，设已知字节 0 的 $L$、加扰相位及字起点。对未知位只施加 E091 目录 CRC 的 24 个 GF(2) 约束。对目标坐标 $T$，取观测和校验堆叠秩减去删掉 $T$ 列后的秩，再扣除 CRC 单独对 $T$ 的约束秩。这给出带完美硬判和已知仿射常数的理想接收信息上界。

| 频窗 | 目录秩最高值 | 首条跨度秩最高值 | 14 位帧计数秩最高值 | 98 位轨迹秩最高值 |
|---|---:|---:|---:|---:|
| 原始 WAV 中心频窗 | 6 | 0 | 0 | 0 |
| LEO 两份 NPZ 的十个唯一窗口 | 0 | 0 | 0 | 3 |
| LEO 清单的 26 条 25 MS/s 录波 | 0 | 0 | 14 | 33 |

覆盖 8 种目录长度与 13 种频窗，共 104 种组合。加入 CRC 后这四个指标均无新增可辨识维度。25 MS/s 结果使用目录频窗，实际录波的原始 IQ 和对应格式仍需核对。时间模型可用于对照已观测字段，未经检验的时变模型没有参与秩计算。[E079 频窗证据](../../experiments/E079/README.md) · [逐配置清单](../../runs/v090-code5-trajectories/manifest.json)
