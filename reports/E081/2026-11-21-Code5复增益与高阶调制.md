# Code 5 复增益与高阶调制

用已通过码字校验的首段 Code 5 实收位估计复增益，能够修正同帧高阶调制区的星座尺度。在 1,009 帧中，该方法把 12 种候选格式的精确格点判决从 167,655,458 个提高到 210,953,429 个。197 帧的复增益相对 H1 增益偏离 1 超过 `1e-6`。所有原可见格点仍可见，重叠标号逐位一致。 [Qin 等的星座判决模型](https://arxiv.org/html/2602.02627#S6.SS4) · [E080 首字](../../experiments/E080/README.md)

## 增益估计和填充边界

沿用 H1 的初始复尺度和冻结 PN 相位。每帧在资源 228 起的 2,048 个方向上，仅留 E078 或 E080 记录为实收的 Code 5 坐标。按已校验码字的码位，将各复系数乘以它的 BPSK 符号；取实部和虚部中位数作为复增益。将所得复数用于同帧高阶区域。星座形状、标号、格点误差门限 `2e-6`、候选码字边界和 PN15 均固定。校准探索仅查看 E077 校准侧。全档案仍用 E077 种子 `2026112177` 的 22 个校准组和 22 个留出组，帧内估计只使用 Code 5 实收坐标。 [16QAM 标号](../../experiments/E028/README.md) · [交叉 32QAM 标号](../../experiments/E030/README.md) · [PN 停止判据](../../experiments/E070/README.md) · [分组](../../experiments/E077/README.md)

| 结果 | 校准侧 | 留出侧 |
|---|---:|---:|
| 总资源符号 | 122,559,850 | 99,137,682 |
| H1 尺度的精确格点 | 93,188,062 | 74,467,396 |
| Code 5 尺度的精确格点 | 116,752,838 | 94,200,591 |
| H1 尺度，带幅度擦除的 PN 停止字 | 1,382 | 1,103 |
| Code 5 尺度，带幅度擦除的 PN 停止字 | 1,681 | 1,336 |
| 将 PN 相位移一位，带幅度擦除的停止字 | 0 | 0 |

为避免把四角硬判误作 16QAM 幅度证据，整槽只有四外角时擦除两条幅度通道。在此条件下，共新增 532 个通过冻结判据的 PN15 停止字，且原保守判据通过的条目全部保留。格点增量中 MCS 66 有 17,492,884 个符号，70 有 15,638,609 个符号。MCS 93 无新增。格点数量衡量可见性，软件无法从四外角硬判恢复原来丢弃的幅度信息。 [E075 量化对照](../../experiments/E075/README.md)

## 同头部的重复对照

按 E074 的近邻范围比较 47 对同 H1/H2 的条目。再用完整 Code 5 首字逐位比对。17 对首字相同，包括 E080 的 16 个时轴链接以及三重观测中 692/693 的另一条边。30 对同头部而首字不同。只以前 256 位登记候选，两帧共同可见至少 90% 且差异不超过 2%。对候选校验段重复同样的覆盖和差异要求，系统区中段未参与匹配。所有 16QAM 槽保留幅度擦除。 [E074 近重复](../../experiments/E074/README.md) · [E080 时轴链接](../../experiments/E080/README.md) · [Chase 的多观测译码](https://doi.org/10.1109/TCOM.1985.1096314)

| 首字关系 | 所测码字配对 | H1 尺度命中 | Code 5 尺度命中 |
|---|---:|---:|---:|
| 相同 | 1,110 | 674 | 854 |
| 不同 | 1,032 | 0 | 0 |

增加的 180 个配对来自 466/467、515/516、568/569、885/886 四对。覆盖 70 的 96 个位置、66 的 69 个、92 的 12 个、57 的两个和 71 的一个。所有新增配对在未用于匹配的系统区中段也低于 2% 差异，在整字可比较位上的差异约 0.21%–0.88%。共比较 2,855,441 个实收位，其中 13,354 个不同。当前结果没有任何全位可见且零差异的高阶配对。共享帧与三角配对存在相关，结果为配对计数。冻结高阶边界与复增益只将这些字推进到可复验的联合观测，完整高阶纠错关系和剩余差异仍待求证。
