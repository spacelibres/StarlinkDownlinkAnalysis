# Code 28 软符号恢复与实收校验预测

E145 用旧 480 MS/s 的冻结生成器，在 Qin 硬判档案唯一恢复了一个缩短核心。本轮保持生成器、8 点星座标号和分配坐标，检查 Qin 保存的均衡软符号能否支持更多恢复。三个已有完整缓存的档案块 `624`、`637`、`780` 提供六个目标字。块选择取决于缓存可用性，样本来自同一捕获。[Qin 波形论文](https://arxiv.org/abs/2602.02627) · [Liu 等 Code 28](https://arxiv.org/html/2610.29387v2#S6.SS7) · [E145](../../experiments/E145/README.md)

先用 H1 对齐整帧相位，再用第一个 Code 5 字的 BPSK 区估计尺度。对每个标签位，以两组相反标号的最小平方距离之差的绝对值排序。分别擦除 6.25%、12.5% 和 25% 低裕量核心位。第一分支固定复尺度，第二分支复用 E021 在奇偶载波与奇偶时隙间交叉估计增益的方法。通过条件为 GF(2) 约束相容、擦除列满秩，并由 FFT 独立重编码复验。固定增益的 25% 分支恢复 2／6，其余五种设定均未恢复。[全扫描](../../runs/v144-code28-corner/artifacts/experiments/E146/results/code28_corner_constraints.json)

固定这两个扫描成功字，依次屏蔽七个 1,024 位校验块内仍可判的校验位，各轮单独求解。两字分别有 4,032 位初始擦除。屏蔽校验块后的每一轮都唯一恢复同一个核心。PN15 只用于事后复验，两个末字所测区间的端点分别为 8,962 和 8,964，最后 2／4 位落在核心外且保持原判决。[校验块与 PN15 复验](../../runs/v144-code28-soft-witness/artifacts/experiments/E146/results/code28_soft_witnesses.json)

| Qin 帧 | 相对初始硬判修改的核心位 | 屏蔽校验位逐块吻合 | PN15 区间差异 |
|---|---:|---:|---:|
| 625 | 18 | 5,281／5,281 | 7 → 0 |
| 639 | 47 | 5,143／5,143 | 10 → 0 |

两字及不同屏蔽分支来自同份软符号档案，且见证字按全扫描结果选出。累计共有 3 个 Qin 核心通过实收校验块屏蔽，包括 E145 的 595 帧硬判见证。其余软字、每字额外 256 位与更广的接收条件继续保留未决。[保存的软符号、原判决及擦除掩码](../../runs/v144-code28-soft-witness/artifacts/experiments/E146/results/code28_soft_witnesses.npz)

硬判对照用全 67 个 Code 28 帧筛出 40 个全为四角星座的 OFDM 时隙，覆盖 49 个码字。已知八点星座每个象限恰有两个候选，其标号差可写成单个二进制变量控制的一组位翻转。对这些时隙比较全擦除、保留原象限及错误象限，均为 0／49 相容。这限制了「仅整时隙幅度丢失」对这些失败的解释范围。两类实验各有一次复跑，结果 JSON 和见证 NPZ 分别逐字节一致。[硬软扫描复跑](../../runs/v144-code28-corner-confirm/manifest.json) · [见证复跑](../../runs/v144-code28-soft-witness-confirm/manifest.json)
