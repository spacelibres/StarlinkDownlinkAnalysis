# Code 5 尾部七字节中的未来帧时隙状态

把 E137 倒计数后七个字节从低半字节起读成 14 个值。设当前实收帧计数为 $N$，零基第 $i$ 个值对应 $N+4i$。检验从 $i=1$ 起，目标必须早于当前 53 帧周期的下一个边界。重载值 `53` 的帧仍用真实周期边界来定位目标。每个目标在 E036 的 CRC 有效档案独立查找，再以到达时间差复核。同一数值坐标在别的到达时轴出现时，不作为该时隙的成功验证。[E137](../../experiments/E137/README.md) · [Qin 等论文](https://www.nature.com/articles/s44459-026-00075-6)

## 按整周期留出和去重

| 半字节状态 | 比较 72 周期，吻合目标／去重目标 | 留出 35 周期，吻合目标／去重目标 |
|---|---:|---:|
| `0` | 0／250 | 0／54 |
| `1` | 494／655 | 258／368 |
| `2` | 0／6 | 无样本 |
| `4` | 0／2 | 无样本 |
| `8` | 0／33 | 0／3 |

同一目标有多个更早记录指向时，低位在先、间距 4 帧的方案在两个分组中均给出同一个状态。留出组 `1` 的 1,595 次重复或单次预测中，1,138 次获得同到达时轴的档案匹配，另有 18 次只在其他时轴找到同计数。这些重复条目按目标去重后得到表中数字。留出命中的最大同轴相对到达误差为 0.000079 帧，约 105 ns。匹配的 `1` 同时出现在 135 和 163 字节首记录，也对应多种 H1 Code 5 码字数量，状态值本身无法区分这些布局。

共同比较从每个方案都能覆盖的源帧及半字节序号出发。改变半字节顺序也会改变读取的值，所以高位在先的分母随值变化。表中只列最常见的两种状态，分母之和可以低于 842。所有方案的目标重复或重叠，描述性计数不计作样本独立性。

独立 480 MS/s 录波中，使用覆盖区间内的 13 个去重目标；同源 250 MS/s 原样点重放中使用 8 个，目标均为状态 `1` 和已确认的帧。这些录波没有覆盖状态 `0` 或其他状态的可区分例。Qin 的 1,009 帧是经过筛选的高质量样本。档案中没有匹配帧的目标可能源于未发射、强度低或未被选入，现有结果只检验了状态与实际收录帧的相对时间。`2`、`4`、`8` 和其后的第八字节仍未解释。已验证的后续帧坐标不能自动推断业务用途。[Qin 采集和波束时间研究](https://arxiv.org/abs/2501.05302)
