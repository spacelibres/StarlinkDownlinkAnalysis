## 固定假设和相位约定

从原工程的 `header_parity_translation.json` 读取两个零平移九位坐标，从 `rectangle_rank_control.json` 与 `shared_header_coordinates.json` 核对 37 个窗口和 70 条跨符号关系。固定原常数、左右两侧坐标及符号顺序。先用相同哈希的 Qin 参考去旋转，正实轴记为 1。测量的硬轴门槛保留原设置，虚部分量绝对值及实部分量幅度距 1 的差均须小于 0.05。原关系只要有一项缺失就保留擦除。

在 Qin 档案中核对通过 CRC 的两级头部和前两个 Code 5 字的分配。用 0–12 帧复算两条九位关系，并逐帧核对 70 条左侧原回执。随后检查 E034 的八个非重叠后续块，共 104 帧，仍是同一次捕获。另用独立 480 MS/s 捕获中的 18 帧，以 E010 的 H1 软判、CRC 与精确重编码，以及 E012 的原始 IQ 硬判和 Code 5 重编码互核。E010 与 E012 的正负实轴约定分别按原实现处理，经冻结参考转回 Qin 位约定。两组测试都不重估相位、异或常数、载波或位掩码。分组沿用已有档案与录波，固定假设检验没有新训练或随机种子。

## 结果

| 固定关系 | Qin 0–12 | Qin 后续 104 帧 | 独立 480 MS/s 18 帧 |
|---|---:|---:|---:|
| 九位关系 0，符合帧数 | 13／13 | 104／104 | 0／18 |
| 九位关系 1，符合帧数 | 13／13 | 103／104 | 0／18 |
| 70 条跨符号关系，全组无错的条数 | 70 | 5 | 15 |
| 全组无错且左侧奇偶至少出现两种值 | 60 | 5 | 0 |

109 个唯一资源坐标中，5 个落入 H1，104 个落入 Code 5 系统区。70 条跨符号关系中，19 条横跨 H1 与首个 Code 5 字，44 条横跨两个 Code 5 字的系统区，7 条在首字内部。两条九位关系也都在首字系统区，涉及按零基计的第 19–23 字节。由此可用原关系的坐标来确定后续内容分析的位置。

固定极性下，两条九位关系均有跨捕获反例，第二条另有 Qin 同捕获反例。70 条跨符号关系中有四条在两组外推都无错，四条都跨两个 Code 5 字，但各自的左侧奇偶在全部 18 帧独立录波中恒定。这四条保留为候选，仍需另一份录波中两侧都变化的观测。当前数据不能把这些相关关系用作跨捕获 FEC 校验或未知位补全。这项结论限于记录的坐标、参考极性和两个宽带录波布局。
