# 原始 WAV 在 13.635 秒附近的周期分量终止

两侧 750 Hz 周期结构的相干模板在终止附近下降约 17–19 dB，移动细线下降约 4.6–5.5 dB。同一时段，接收机固定中心频带只下降约 0.09 dB。两侧大幅消失的分量可以用之前冻结的四载波、15 槽模型复现，远大于一般的宽谱功率下降。[E040](../../experiments/E040/README.md) · [E042](../../experiments/E042/README.md)

## 逐周期匹配

输入为已核对 E040 哈希的 2.4 MS/s 双通道 int16 IQ 和 E001 细线轨迹。以每 3200 个样点为一箱，在 E042 帧候选锚和三个四分之一周期偏移下分析同一事件。用 E041 的二次相位时轴和已冻结的 749.9967 Hz 网格校正。两侧的频移只用 11–13 秒内五个既有校准块计算，为 −274.72 和 −272.09 Hz。分别计算 E041 校准块平均谱的相干投影，以及 E042 四载波模型冻结系数的投影。另给每侧生成 39 个保持逐频幅度的随机相位对照。没有用终止附近样点更新这些模板。移动细线用去漂之后一周期复均值的平方估计。所有窗口以录波内相对时间标记，绝对空口帧起点仍待认证。[公开帧结构](https://arxiv.org/html/2210.11578#S7)

对每条功率序列，在 13.35–13.95 秒拟合线性背景加单向下降阶跃，只在 13.55–13.72 秒的箱边搜索。阶跃位置由残差平方和确定。降幅单独取 13.45–13.58 和 13.73–13.90 秒两段的平均功率比。下表取四种分箱相位的范围。[Bai 与 Perron 的结构变点方法](https://www.columbia.edu/~jb3064/papers/1998_Estimating_and_testing_linear_models_with_multiple_structural_changes.pdf)

|---|---:|---:|
| 负侧经验模板 | 13.63337–13.63537 | 16.93–17.40 dB |
| 正侧经验模板 | 13.63471–13.63571 | 18.51–18.89 dB |
| 移动细线 | 13.63504–13.63704 | 4.56–5.47 dB |
| 负侧四载波模型 | 与负侧经验模板逐相位一致 | 16.00–16.45 dB |
| 正侧四载波模型 | 与正侧经验模板逐相位一致 | 18.17–18.53 dB |
| 负、正原始宽谱 | 13.63504–13.63771 | 0.71–0.72 dB |
| 固定中心频带 | — | 0.09 dB |
| 固定约 13 kHz 区域 | — | −0.25 至 −0.04 dB |

所有随机相位对照的最大降幅低于 3.57 dB。两片宽谱与背景、细线的响应差异支持可分辨的周期分量在该时段消失，整个接收带的统一幅度阶跃不足以解释所测变化。不同频段的接收响应、信号叠加和硬件位置仍有歧义。

## 对齐精度

点估计中，正侧比负侧晚 0–1 个周期，移动线比负侧晚 0–2 个周期。以种子 `2026112191`，分别在事件前、后抽取成对的 8、16、32 周期残差块，每种设置 499 次。噪声池避开锚点前后 60 ms。结果在四种分箱和三种块长度下的条件区间合计覆盖正侧相对负侧 −1.3 至 +5.3 ms，移动线约 −22.1 至 +14.7 ms。首轮将横跨事件锚的整块按中点归类，16 周期分组把边缘附近的样本划入低噪声的后段，产生退化区间。修正按锚点分开抽样，保留首轮用于核对。这里的区间条件于单事件和拟合模型。两侧接近毫秒量级终止，移动线与两侧同帧关断仍待验证。[E008 历史边缘不确定性](../E008/2026-11-20-稳健性与跨接收机检验.md) · [修正运行](../../runs/v088-wav-frame-cut-stratified/manifest.json)
