说明：原始 WAV 未修改。本报告的测量来源为本地文件，背景资料另列于文末。

一、核心结论

这是一份极可能用于 SDR 的双通道 I/Q 基带录波，而非普通人声或音乐录音。
文件结构完整。除噪声状底谱与近固定窄线外，进一步高分辨率分析确认了一条连续移动的窄带轨迹；
它与两侧较宽信号区域在约 13.635 秒附近一起结束。此前全程平均和图像缩小掩盖了这一关键结构。
用户已补充来源为 Starlink 信标录波。应按 Starlink 接收链路解释频率，不再以 GPS 为目标。
若采用常见的 9.750 GHz 本振 LNB，则 1.575 GHz 为中频，原始射频中心为 11.325 GHz。
该本振值是与背景吻合的条件假设，仍待采集设备说明确认。用户提供的来源与波形独立鉴别应区分。

三、修正后的频率解释：Starlink 下变频录波

用户补充来源为 Starlink 信标。上一版忽略外置下变频链路，将 SDR 调谐频率直接标作原始射频，相关解释现予修正。
在低侧本振 9.750 GHz、频谱不翻转的 LNB 假设下：
原始 RF = LNB 本振 + SDR 中频 + 基带偏移。
11.325 GHz - 9.750 GHz = 1.575 GHz。
理论中频范围为 1573.800–1576.200 MHz，对应原始 RF 11323.800–11326.200 MHz。
+13 kHz 谱线对应约 11325.013 MHz；-600 kHz 谱线对应约 11324.400 MHz。
这些是标称换算，包含未知的 LNB 本振误差、接收机频率误差及可能的多普勒偏移。
因此不能把测得的 +13 kHz 全部当成卫星多普勒，也不能据此直接算卫星速度。
不能仅凭用户给定来源，就把两条谱线都自动认定为卫星载波，仍需移动轨迹及采集链路对照。
GPS 搜索结果仅保留为先前假设下的非目标信号实验，不支持或否定 Starlink 来源。

四、幅度、直流、I/Q 和量化

统一将每个整数样本除以 32768。复数功率定义为 mean(I²+Q²)，0 dBFS 对应该量等于 1。
该定义下，双通道均满幅时复数功率可超过 0 dBFS；与音频工具的单通道表头可能相差约 3 dB。
全文 dBFS 和 dBFS/Hz 均是数字归一化读数，不能直接转换为 dBm、场强或接收机灵敏度。

I 最小/最大整数：-2148 / 2206；Q：-2150 / 2205。
I RMS：0.01234535；Q RMS：0.01234097。
平均复数功率：-35.161 dBFS；最大瞬时复数功率：-22.929 dBFS。
I/Q 标准差比对应幅度差约 0.00309 dB，幅度非常接近。
间隔抽样估计的 I/Q 零延迟相关系数约 -0.000959。
以上不构成对全频段镜像抑制比或正交相位误差的校准测量。

I 均值约 -1.77e-8，Q 均值约 1.12e-7；均值对应的直流功率约为总功率的 4.24e-11。
这说明保存在文件中的长期直流分量很小；不能证明录制前没有进行过直流消除。
16 位最小/最大满幅值命中次数均为 0，未见容器满幅削顶。
由于采集链路未知，不能排除写文件之前的模拟过载、低位宽 ADC 削顶或增益处理。

最值得注意的是量化：虽然容器是 int16，短时间样本却聚集于间隔约 256 的数值簇。
例如最初 1 ms 的 I 样本中可见 -1380、-1124、-868、-612、-356、-100、156、412、668 等簇。
簇内存在约 1 个单位的细分，随时间偏置也有变化。
这符合较低位深（例如 8 位）数据缩放到 16 位并经偏置/浮点处理的特征，但不能证明具体采集设备。
RMS 约为 404 个整数单位，即约 1.58 个上述量化间隔，信号只使用了较少的主要幅度层级。
不能将其解释为原生 16 位有效精度，也不能仅凭这些统计量给出 ADC 的 ENOB。
前一百万帧 I/Q 分别有 114/87 个不同整数值；这个数字受偏置漂移及簇内细分影响，不能直接换算位数。
全文件约 3.594% 相邻复数帧完全相同。这可以由粗量化解释，不能单凭此认定丢包或重复写入。
没有 I/Q 同时为零的帧；但没有采样计数器，不能据此排除接收端丢样。

五、频谱和时间变化

平均功率谱采用 Hann 窗、16384 点 Welch、50% 重叠，频率栅格约 146.484 Hz。
分段覆盖全文件；瀑布图和功率趋势以约 100 ms 为时间粒度，最后一段短于 100 ms。
每段 PSD 等权平均，结果为实用估计，不是经硬件校准的射频测量。

1. 宽带底谱
中部 PSD 多在约 -98 至 -99 dBFS/Hz，约 -750 kHz 附近有轻微隆起。
两端约降至 -103 至 -104 dBFS/Hz；这与接收滤波器/链路频响塑形一致，也可能含环境噪声变化。
无法单凭此文件将接收机本底和外界宽带信号分离。
含噪声在内的累计功率 99% 区间约为 -1.16543 至 +1.16323 MHz。
该数值不是某个发射信号的占用带宽。

2. 约 +13 kHz 的突出窄带谱线
全程粗 PSD 峰位 +13.0371 kHz，峰值约 -83.235 dBFS/Hz。
进一步用 262144 点 Welch 分析约 0.25 秒的分散片段，频率栅格约 9.155 Hz：
0 秒：+13027.95 Hz；2 秒：+13018.80 Hz；6 秒：+13009.64 Hz；12 秒：+13000.49 Hz；15.5 秒：+13000.49 Hz。
因此存在约数十 Hz 的缓慢漂移，不能将 146 Hz 粗栅格峰位当成精密载波频率。
在这些片段，谱线峰比附近 20–50 kHz 局部底谱高约 26.4–27.9 dB。
这一数值依赖分辨率带宽，不能当作全带宽信噪比。
在峰周围 ±1.5 kHz 内扣除局部底谱后，仅累加正差值所得功率约 -59.5 至 -58.8 dBFS。
该方法有正截断偏差，仅作量级估计；约为全带总功率的千分之几。
若中心频率和方向假设正确，对应中频约 1575.013 MHz；若 LNB 本振为 9.750 GHz，则原始射频约 11325.013 MHz。
可能来源包括本机杂散、泄漏或外部窄带发射，现有证据不足以区分。

3. -600 kHz 的较弱谱线
平均 PSD 峰约 -92.465 dBFS/Hz，突出度约 6.35 dB。
对应中频约 1574.400 MHz；若 LNB 本振为 9.750 GHz，则原始射频约 11324.400 MHz。其恰在采样率四分之一处，值得在排查采集杂散时关注，
但这个数值巧合不能证明硬件起因。

4. 功率台阶
100 ms 窗口总功率范围约 -35.638 至 -35.012 dBFS，标准差约 0.189 dB，总跨度 0.626 dB。
13.6 秒附近有清楚的下降；10 ms 分辨率下最大相邻下降出现在约 13.64 秒。
13.0–13.5 秒均值 -35.172 dBFS，13.8–14.0 秒均值 -35.624 dBFS，下降约 0.452 dB。
这更适合描述为接收总功率的状态变化；可能来自环境、增益或录制处理，不能据此判定某颗卫星退出。

六、先前假设下的 GPS L1 C/A 对照实验（不属于 Starlink 识别）

不是仅凭噪声状频谱判断，而是实现了 GPS C/A 本地码与 FFT 循环相关搜索。
范围：PRN 1–32；在第 1 秒、第 8 秒各取 20 ms。
为覆盖频谱方向不明的情况，分别搜索基带 +420 kHz 和 -420 kHz。
每个中心周围残余载频 ±15 kHz，步长 500 Hz；1 ms 相干、20 次功率非相干累加。
每种情况约搜索 32 × 61 × 2400 个码相位/频率/PRN 单元。

四种情况的最强峰/码相位均值：
第 1 秒、+420 kHz：2.553，PRN 25。
第 1 秒、-420 kHz：2.791，PRN 9。
第 8 秒、+420 kHz：2.672，PRN 7。
第 8 秒、-420 kHz：2.567，PRN 2。

按理想白高斯噪声、20 次独立非相干累加及全搜索族 1% 虚警的近似模型，参考门限约为 3.013。
上述峰均未越过该门限；最强 PRN 在不同时刻也不同，没有建立可信捕获。
实际噪声经过滤波且量化较粗，因此该门限只是参考，不是经过标定的实际虚警保证。
对照验证：向真实片段叠加已知 PRN 7、+2500 Hz 残余载频、375 样本码偏移的合成信号，
同一搜索实现正确返回 PRN 7 / +2500 Hz / 375 样本，峰均值比约 62.62。
此验证证明程序能找到该强度的已知信号，不代表已验证弱 GPS 信号的检出概率。

限制：没有逐秒搜索全程、没有尝试更长积分或 ±15 kHz 以外的频偏，
没有进行载波/码环跟踪、导航电文解码、星历恢复或位置解算，也没有搜索 Galileo/北斗等其他码型。
因此严谨表述是“本次搜索未确认 GPS L1 C/A”，而不是“文件里没有 GPS”。

七、后续工作的优先顺序

首先核对下载页面或采集说明中的设备、真实中心频率、I/Q 方向、天线、LNA 和增益。
这些上下文决定频谱标签和后续 GNSS 解码参数，文件本身没有提供。
对 Starlink 信标，应优先分析局部高分辨率瀑布图、多条载波的时频轨迹及可能的共同漂移，
并区分 LNB 本振漂移、接收机误差与卫星多普勒；数字放大当前文件不会恢复已丢失的量化精度。
若目标是确认窄带谱线来源，可比较接假负载、断开天线、改变中心频率和采样率的对照录波。
来自本机固定采样杂散和来自外部固定射频载波，通常会在这些对照中呈现不同移动规律。

九、瀑布图专项复查：移动轨迹与约 13.635 秒的共同终止

用户提供的原始仓库：https://github.com/lixb123/starlink_beacon_iq
通过 GitHub contents API 读取 WAV 的 Git LFS 指针，其 SHA-256 与本地文件完全一致，确认是同一份录波。
复现仓库 Starlink_waterfall_v2.py：65536 点 Nuttall 窗、20 FPS、不做时间平均、频率方向峰值重采样、固定全局色阶。
输出 reference_waterfall.png，保持原脚本 SDR++ Classic 风格；未修改原脚本计算行为。
关键显示机制：65536 个频点缩到约 856 个显示列时，取列内最大值能保留微弱窄线；普通图像缩小会冲淡它们。
本次另外生成局部背景去除图用于检查弱结构。它与原始绝对功率图用途不同，不能用局部归一化图直接读绝对功率。
新图时间从上往下增加，与仓库一致；早先 overview 图时间从下往上增加，不应据图上斜率方向直接判断多普勒符号。

最显著的动态信号：一条窄带轨迹由约 -161.5 kHz 连续漂移至结束前约 -199.7 kHz。
在 13.6 秒附近终止，其此前总频移约 -38.2 kHz。
采用局部谱脊点作近似二次拟合：f(t)≈-161489.35-3020.26t+15.8840t² Hz。
该拟合主要用于描述形状，非精密测频。数据范围内频率下降速率约由 -3.02 变为 -2.59 kHz/s。
其曲率表明这不是简单的固定频点线，也并非完全匀速扫频。
形态和量级符合低轨卫星载波多普勒特征，并与用户给定的 Starlink 信标背景一致。
但 LNB/接收机/发射端频率变化也会进入测量；尚未结合 TLE、位置及准确时刻识别卫星或解算轨道。

沿曲线取样，10–13.5 秒的归一化窄带窗口功率约为局部底噪的 4.93 倍，
13.8–15.8 秒约为 1.05 倍，说明轨迹在后段不再有可辨识的增强。
用交替时间帧拟合和验证，并以偏离轨迹 ±3 kHz 的窗口作对照，增强仍在真实轨迹上成立，
排除了仅凭单个亮点或随意连线得到结论的情形。此为一致性检查，不是经多重搜索校准的虚警率估计。

全带复数总功率按 1 ms 窗口计算，在局部区间拟合两段常值，最佳台阶位置为 13.635 秒。
这是功率台阶的采样栅格估计，不代表窄带轨迹终止时刻已被独立测到 1 ms 精度；
窄带瀑布图的单行平均时长约 109 ms，只能确认它在相同时间附近消失。

比较 10–13.5 秒与 13.8–15.8 秒的固定频带积分功率：
负频侧 -950 至 -650 kHz：下降约 0.747 dB。
正频侧 +500 至 +750 kHz：下降约 0.791 dB。
中心背景 -100 至 +100 kHz：仅下降约 0.069 dB。
+13 kHz 谱线附近 1 kHz 区间：变化约 +0.052 dB，基本保持。
因此该事件具有频率选择性，不符合单纯全带统一缩放或整个记录器静音。
较合理的描述是“一个动态信号分量连同相关宽谱结构在记录中结束”；
发射突发结束、波束/频率切换或接收可见性变化等具体原因，目前无法唯一判定。
不能把它直接宣布为卫星关机、故障、人工干扰或越过地平线。
