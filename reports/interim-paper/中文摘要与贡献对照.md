# 从波形结构到 Starlink Ku 波段下行控制记录解码

## 中文摘要

本研究在公开的 Starlink Ku 波段 OFDM 波形、导频、头部与已知信道码基础上，整合了宽带 IQ、公开频域档案、原始 WAV 与 LEO Tracker 窄带判决的阶段性证据。冻结头部模型在 Qin 档案 1,009 帧、另一次 480 MS/s 采集的 18 帧和 250 MS/s 重放的 10 帧中通过两级 CRC。Qin 与 250 MS/s 有源重叠。对 Code 5，定位了卫星编号、地固位置和速度、GPS 时间、帧计数及冗余时钟字段。在 1,037 个受检码字中，时间重建与空口时间标签相差不超过 1 ns。381 个整组留出帧在固定站点和校准常数下，预测相对到达时刻的残差为 46.89 ns RMS。本项目还建立 MCS 66／85、70／88 的四个完整等价信道码，验证分层记录长度，并由三个跨录波见证字确认 Code 28 缩短核心的可转移性。LEO 原生判决可复现已知 H1 前缀的部分比特，完整未知应用消息仍待验证。

**关键词**　Starlink，信道编码，控制记录，OFDM，低轨卫星，被动测量，可复现研究。

## 公开研究与本项目的贡献

| 公开来源 | 公开研究已经给出的内容 | 本项目新增的证据 |
|---|---|---|
| Humphreys 等 | Ku 波段 OFDM 帧结构、同步序列和资源坐标 | 在原 WAV 上复验周期，量化终止事件和重复结构的频窗约束。 |
| Qin 等 | 750 Hz 时序与 15 秒量级驯服行为、边缘导频、参考模板、60 位重复结构及公开档案 | 补上 1,009 帧的两级头部与分配验证，从 Code 5 实收位读出时间、位置、速度和编号，结合传播与历史轨道反证。 |
| Liu 等及公开仓库 | H1/H2、卷积码、CRC-8、候选 MCS 分配格式、旧码型和 Code 28/37 缩短核心 | 复现并跨录波验证旧模型，新增四个完整等价码、四个部分校验模型，建立 Code 5 内部目录 CRC-24 与多层记录边界；对 Code 28 新增三个独立于旧录波的档案见证字。 |
| Morgan 等与公开专利 | 帧时钟和分配建模、模拟融合式 PNT、可配置下行发送机制 | 从实收记录定位时钟修正和区间锚，验证精确整数关系。 |
| LEO Tracker 与 `starlink_beacon_iq` | 原生接收和导频跟踪流程、派生判决与瀑布图工具 | 重放原检测器并验证窄窗 H1 投影，量化模型可见性、擦除与错位结果。 |

正文第 II 节附全部来源和证据范围。研究增量以所引公开版本为参照，文献比较的范围见正文。

## 阶段性边界

- 25 个已观察的 MCS 标签中有 12 个完整等价模型、2 个缩短核心、4 个部分校验模型，以及 7 个仍缺完整模型或已验证缩短核心。个别旧码型的证据限于单录波或跨格式转移。
- 已读出 1,428 个秦氏档案记录长度。另在 22 个宽带分配中识别 69 个外层记录、499 个子区间。应用层消息数仍为 0 条，正文语义未验证的区间予以保留。
- 31848 与 2472 是两份宽带证据的空口读值，分别对应历史目录中排名首位的 NORAD 59784 与 48130。原 WAV 和 LEO 窄带的身份仍未确定。
- 实收时间标签的 1 ns 一致性检验的是编码关系。实际授时、认证身份和更广泛的码型接收性能仍需独立验证。
