# Code 5 内部目录的 CRC24 与记录跨度

Code 5 系统区去扰后，首字节 $L$ 指向 E078 的内部标记。此次确认标记前的最后三个字节是 **24 位 CRC**，并从第一条目录项读到一个跨码字的记录跨度。新 CRC 规则逐字节复现了 1,009 个档案目录和两份原始宽带的 28 个目录。首条记录的 135 字节和 163 字节两种跨度均准确预测下一标记。[E078](../../experiments/E078/README.md) · [E080](../../experiments/E080/README.md)

## CRC 位序与参数

目录为去扰后零基字节 0 至 $L-1$，最后三个位置 $L-3,L-2,L-1$ 保存校验值。按每字节最低位先进入的顺序，将整个同长度目录视为 GF(2) 多项式。沿用 E077 的整组划分。对长度 24 和 32 的校准目录，各取不同内容与同长度锚目录异或。两个长度分别有 72 和 69 个不同目录，差分的多项式最大公因式均为 **0x11f21c5**。按最高位优先处理，或倒置三个 CRC 字节的顺序，两种对照的最大公因式都降为 0x5。[Gregory Ewing 的 CRC 差分方法](https://www.csse.canterbury.ac.nz/greg.ewing/essays/CRC-Reverse-Engineering.html) · [CRC RevEng](https://reveng.sourceforge.io/readme.htm)

使用这两个长度的固定余数差，解得一组等价参数 $J=\texttt{0xf4cad4}$，$R=\texttt{0x530ac1}$。设 $B$ 是不含校验尾的字节串按上述位序组成的整数，多项式除数 $G=\texttt{0x11f21c5}$，则预测的 24 位值为

$$
T=\operatorname{rem}_G\big((B\ll 24)\oplus(J\ll 8L)\big)\oplus R .
$$

将 $T$ 按高字节到低字节输出并分别反转每字节内部位序，即得三个实收校验字节。线性方程秩 22，等价参数的绝对初始化状态仍有两个自由度。采用相同的仿射模型尝试跳过首字节时，两种训练长度给出相矛盾的方程。

| 验证来源 | CRC 尾逐字节一致 |
|---|---:|
| Qin 档案整组留出，共 22 组 | 429／429 |
| 其中长度未参与参数拟合 | 125／125 |
| 旧 480 MS/s 原始宽带 | 18／18 |
| 250 MS/s 原始宽带 | 10／10 |

全部 1,009 个档案的 24 个 CRC 位置都来自实收硬判，一个档案目录的另一个受保护位由外层校验恢复。两个原始宽带各自从原始 IQ 的已验证外层码字起算，250 MS/s 与 Qin 档案存在源重叠。用种子 `2026112192` 在每个目录受保护区翻转一位，保持原校验尾，档案与原始样本的 1,037 个对照全部被拒绝。[Liu 等的外层 Code 5 校验](https://arxiv.org/html/2610.29387v2#S6.SS1)

## 首条记录跨度与第二个 Code 5 字

目录内第一项的 `00 01 f0 0f` 后两字节按小端读，再右移四位，得到 $B_1$。首条记录从 $L$ 开始，下一记录的 `08 5d` 在 $L+B_1$。档案结果为 163 字节分支 718／718、135 字节分支 291／291。固定使用 163 字节会漏过全部 291 个短分支。相对预测位置错移 ±1 或 ±2 字节均无命中。两份原始宽带的 28 个长分支也逐一命中。已验证的两个跨度差 28 字节，与 E078 的四条可省略 7 字节记录相同。其他目录项和后续记录结构仍需分别验证。

从已登记的 106 个 Qin 缓存页读取第二字。原 E078 已有 153 字，这次新增 856 字，保留各自的外层码字与实收掩码。首轮的唯一例外档案 1003，完整符号窗口在校验区中途截断。它余下 715 个实收校验位，分别用 384 和 331 个方程唯一恢复同一个被擦系统位，并跨折逐位复验。其余 309 个校验位置依然标注未实收。全档案的 1,008 个预测标记的 16 位均有直接观测，余下一处的一位由外层校验补全。恢复第二字时只使用外层 Code 5 约束，完成后才评分下一标记。

这项结果为内部目录和记录边界提供了可重新计算的验证。适用证据限于所测宽带格式。目录项业务含义、发射机身份和原始窄带 WAV 的载荷仍待验证。[最终运行及输入指纹](../../runs/v089-code5-directory-final/manifest.json) · [相同条件复跑](../../runs/v089-code5-directory-confirm/manifest.json)
