# E028 · MCS 66 和 70 冻结编码转移

## 信号与分配

从原始 250 MS/s 宽带 IQ 恢复九帧资源。沿用 E024 的头部、已确认 Code 5 和 E025 的末端。按条件性的每单位 4,096 资源提取 MCS 66 的 376 字及 MCS 70 的 91 字。考虑每符号 4 位时，这对应每候选字 16,384 个标号位。资源长度用于切取候选，并未单独验证每个内部字界或信息维数。[作者 250 MS/s 分配示例](https://github.com/misaka666/Starlink-Downlink-Analysis#6-a-complete-allocation-map-for-f250)

在已知 Code 5 标定后，用 BPSK、方格 16/64QAM、交叉 32QAM 的等权混合代价比较，无需待测校验。18 段中有 17 段以 16QAM 代价最低，候选帧 3 的 MCS 66 中 64QAM 低约 0.00015。进一步按相反奇偶槽估计载波复增益，再按相反奇偶载波估计槽增益，所有段的最近 16QAM 点均方距离从 0.0348–0.0474 降至 0.0269–0.0378。保存基础和细化的复数候选字，包含两侧各一资源。

## 冻结关系与整帧检验

用种子 2026112128 冻结拟合帧 2、3、6、7，保留 0、1、4、5、8。两组 512/1024 提升因子的稀疏校验矩阵采用 E018 图 12 版本。分别考虑 16,384 位完整 Code 39 以及两个 8,192 位 Code 3。对每种接收标定形式和每种已知码，测试 24 个 Gray 位通道排列、16 个逐通道取反、三种候选起点（−1、0、+1 符号），共 1,152 种组合，在拟合帧内选择失败校验最少的一组。Code 21 的两个半字只使用冻结 Gray 标号，直接以 E016 系统关系重编码。文献中的等价编码表示取决于坐标和标号约定。[Liu 等表 IV](https://arxiv.org/html/2610.29387v2#S6.SS8) · [AFF3CT QC 校验输入说明](https://aff3ct.readthedocs.io/en/latest/user/simulation/parameters/codec/ldpc/decoder.html)

| 在细化接收器上检验 | 保留 MCS 66 失败比例 | 保留 MCS 70 失败比例 | 仅保留高裕量校验的失败比例 |
|---|---:|---:|---:|
| Code 39 组合最优 | 49.95% | 49.92% | 49.90%、49.91% |
| 两个 Code 3 半字，组合最优 | 49.93% | 49.89% | 49.97%、49.87% |

保留组含 196 个 MCS 66 候选字、50 个 MCS 70 候选字。所有完整字和半字都有非零综合。高裕量只保留触及的各符号最近两点平方距离差均至少为 0.08 的校验。MCS 66 的两组高裕量子集均超过 106 万条，MCS 70 均超过 27 万条。冻结 Code 21 的全体候选半字共 934 个，逐字都有不一致，平均比例分别为 50.04%、50.02%。两个接收标定形式的失败比例都接近一半。

补充对固定 Gray 计算连续块奇偶向量，并求 GF(2) 秩。对 256、512、1024、2048、4096 位的五种投影，两个格式的合并组均达满列秩。MCS 70 的 256 位投影在拟合时只有 41 个字、64 个投影坐标，23 维零空间全部被保留组消除。投影未给出可转移的整块奇偶关系，其作用范围受硬判决和块布局限制。[Huang 等的循环块秩分析](https://arxiv.org/abs/1202.0702)

## 校验正对照与证据边界

对每个冻结稀疏矩阵生成 16 个独立合成字。无噪声时全部精确通过。复高斯方差 0.032 时，两种码在硬判决上分别有 2.88%、2.78% 的校验错误，高裕量校验只有 0.61%、0.66% 失败；方差 0.06 时高裕量失败仍不超过 6.63%。尽管此时没有任何一个字全综合为零，校验总体仍远离实测的一半失败。合成方差用于定义控制，不提供实测的误码率或其错误相关性。

有限置换和半字模型都没有迁移成功。需要继续检验其它码长、坐标交织、校验结构或局部短化，当前无法为 66/70 确认新的校验矩阵、码率或消息字段。
