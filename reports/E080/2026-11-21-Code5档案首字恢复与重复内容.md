# Code 5 档案首字恢复与重复内容

从 Qin 档案额外恢复了 479 个 Code 5 首字，与 E078 已验证的 530 个字合计 1,009 个。新增码字的校验恢复只用频域星座和冻结矩阵。完成译码后才核对帧时刻。新增的主时轴留出计数命中 203/203，进一步验证了 E079 的字段坐标。 [Qin 等档案和代码](https://rnl-data.ae.utexas.edu/datastore/supplementaryMaterial/qin-starlink-pilots/) · [Liu 等 Code 5 关系](https://arxiv.org/html/2610.29387v2#S6.SS1) · [E079](../../experiments/E079/README.md)

## 恢复方法和对照

沿用 E078 的 H1 增益约定、冻结 PN15、资源 228 的首字起点和 2,048 位重编码关系。校准探索仅查看 E077 的校准组。对于尚未恢复的字，在校准中发现不少字落在两个清晰对称的星座点上，但沿用 H1 的幅相尺度会使整字落在 E078 的星座门限外。因此从每字前 1,024 个复数值的平方估轴，分别取平方实部和虚部的中位数，再取正实部平方根。判决使用相对 H1 的原极性。在 `+511` 处额外擦除，并用两套互补的固定校验块各自求解擦除位。两套求解均要求唯一、跨块预测零差异，最后重编码比较全部实收校验位。矩阵、擦除门限和互补校验块继承 E063/E078。 [E063](../../experiments/E063/README.md) · [E078](../../experiments/E078/README.md)

沿用种子 `2026112177` 得到的 22 个校准组和 22 个留出组。主分支冻结后对五种条件重复运行相同的校验逻辑。以下分母仅包含 E078 未恢复的字。 [分组来源](../../experiments/E077/README.md)

| 条件 | 校准 | 留出 |
|---|---:|---:|
| H1 增益 | 0/273 | 0/206 |
| H1 增益并擦除 `+511` | 159/273 | 123/206 |
| 逐字星座轴 | 83/273 | 52/206 |
| 逐字星座轴并擦除 `−512` | 83/273 | 52/206 |
| 逐字星座轴并擦除 `+511` | 272/273 | 205/206 |

主分支也逐位复现了 E078 的 530 个字。追加两条事后诊断的结果单独记录。档案 399 用 E063 的六个边缘载波擦除，补全 6 个系统位，并分别通过另一半的 505 和 511 个实收校验方程。档案 537 的两半综合分别唯一指向码字第 779 位，从零起算，对应 `−509`。翻转此位后重编码零差异，原判值、替换值与擦除位置均保留。追加前其余 1,007 条记录逐值保持相同。在 479 个新增字上，去扰后的内部标记全部吻合。

## 帧计数与重复内容

E079 主时轴相位、容差 `±0.01` 周期和计数偏置 3283 均冻结。992 个主时轴字中，校准 569/570、留出 422/422 与计数吻合。唯一例外档案 956 的首字通过两套擦除方程，其计数比 TOA 预测多 5。它预测的主时轴位置在档案中缺失，距其最近的同计数观测也未找到。该例仍按实测归档。

17 个离轴字中，16 个计数指向 0.703–16.726 ms 之后的主时轴条目。其中 692 和 693 指向同一条 694。两级头部及 2,048 位首字都逐位相同，每对有 2,044–2,046 个双方都有观测的位，合计 32,725 个配对位比较无差异。既有的 E074 在其中 12 对检出高阶近重复。离轴主检验中，将预测移开 ±1 至 ±16 帧均找不到两级头部吻合的目标。840 预测的主时轴帧号 7043 缺失。结果支持同内容跨不同到达时间重复，也说明计数与接收时刻之间存在例外。重复观测形成于同一档案，其物理来源未确定。 [E074 近重复](../../experiments/E074/README.md)

## 外部录波和时钟模型

Morgan 等 2026 年 11 月预印本将载波、采样和帧时钟分别建模，并描述约 15 秒的波束分配区间。档案 TOA 从约 3.010 到 10.615 秒，未跨越 15 秒的完整观测长度，无法据此判断计数是否按该间隔回卷。作者的公开原始 IQ 入口列出 exemplar 250–257。LEO Tracker 的公开 DS 档案说明明确列出发布的是存档清单，原始 IQ 仍在其归档端。其 25 MS/s 频窗验证条件见 E079。 [Morgan 等 §III–IV](https://arxiv.org/html/2611.13655v1#S4) · [Qin 原始 IQ 索引](https://rnl-data.ae.utexas.edu/datastore/supplementaryMaterial/qin-starlink-pilots/raw-iq-data/) · [LEO Tracker 原工程档案](https://github.com/misko/leo-tracker-reduxredux/blob/main/reports/2026_10_18_dataset_manifest_archive/README.md) · [E079 LEO 频窗](../../experiments/E079/README.md)
