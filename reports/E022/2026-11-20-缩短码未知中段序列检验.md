# E022 · 缩短码未知中段序列检验

## 问题与数据

Code 28 和 Code 37 的缩短核心均已重编码验证。每字仍分别有 256、384 个中段接收位未由核心解释。专利介绍了在 LDPC 输出末尾增加伪随机填充的机制。论文指出，这与录波中位于系统位和校验位之间的中段存在位置差别，尚缺少将两者联系起来的证据。[专利说明](https://patents.google.com/patent/US12074683B1/en) · [论文 §VI-G](https://arxiv.org/html/2610.29387v2#S6.SS7)

从 E021 和 E017 的封存数据提取中段。全部 51,072 位与各自修正前的原始硬判决逐项一致，且均处于核心掩码之外。末尾星座符号的额外标号位单独保留，本轮不并入中段。Code 28 有 189 字、四个帧组，继承两套重叠整帧划分。Code 37 有七字、四个帧组，其中帧 3 和 15 拟合，帧 1 和 11 保留。

## 具体填充模型

先在拟合帧按位选择多数模板。再固定与已知导频有关的 PN15 序列，在每个候选坐标模型中用拟合帧选择相位、方向和整体极性。考察每字重置、只在中段连续、按母码位数连续、按不含导频的资源连续、按含导频的载波序号连续五种模型。

另对每字独立用前半段搜索全部 32,767 相位、两种方向和两种极性，再预测后半段。这一检验允许各字有不同初始状态。

| 检验 | Code 28 | Code 37 |
|---|---:|---:|
| 实测中段重复数 | 0 / 189 | 0 / 7 |
| 固定位置模板在保留帧的命中率 | 49.53%、49.39% | 51.74% |
| 五种共享 PN15 坐标在保留帧的命中率范围 | 49.64%–50.65% | 48.70%–50.09% |
| 逐字估计相位后预测后半段 | 12,211 / 24,192 | 682 / 1,344 |
| 同算法，合成 PN15 独立翻转 5% | 22,945 / 24,192 | 1,287 / 1,344 |

Code 28 的汉明距离为 97–157，中位数 128。Code 37 为 177–205，中位数 189。两组中段的位值为 1 的比例分别为 50.16% 和 49.26%。这些是有限样本的分布量。

星座点距离也提供了另一项诊断。对每个候选位计算两类星座点的最小平方距离之差，其符号与中段硬判决完全相同。Code 28 中段和核心的绝对距离差第 5 百分位分别为 0.540 和 0.539。Code 37 分别为 0.444 和 0.485。在固定假设尺度下，按这些距离分数计算软命中，五种共享模型的保留分数仍接近 50%。距离分数用于比较判决裕量，缺少中段传输真值，无法由此测 BER。

## 未预设反馈多项式的对照

对于每个训练窗口，取前 16 个相邻硬判决构成二进制向量，分桶累加目标位的有符号计数。快速 Walsh 变换同时得到全部 65,536 个线性掩码的相关分数。绝对值最大对应同时选择常数项。训练组选择一次系数，保留组逐位评价，历史窗口始终只在单字内部取样。[O'Donnell，布尔函数的奇偶基](https://www.cs.cmu.edu/~odonnell/papers/Analysis-of-Boolean-Functions-by-Ryan-ODonnell.pdf)

| 整帧划分 | 实测保留命中 | 99 次按字循环移动目标并重新拟合的最高命中 | 置换达到或超过实测 |
|---|---:|---:|---:|
| Code 28 论文对应划分 | 10,715 / 21,360 | 10,833 | 29 / 99 |
| Code 28 随机划分 | 11,638 / 23,520 | 11,915 | 95 / 99 |
| Code 37 随机划分 | 558 / 1,104 | 595 | 26 / 99 |

两种 Code 28 拟合选择了不同掩码。相同方法从 5% 翻转的合成序列复现了已知的反向仿射递推，合成保留预测率为 85.1%–86.2%。合成相位和误差种子已存档。真实数据与合成数据各自统计。

本轮结果不支持测试的固定模板、已知 PN15 序列复用或统一的最多 16 阶仿射线性反馈。发生器更长、按字改变反馈规则、其它字段内容或更复杂填充均尚无结论。
