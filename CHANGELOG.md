# Changelog

## [0.0.1] - 2026-11-21

### Purpose
- Publish a compact scientific snapshot of the StarlinkBeacon project for independent review.

### Changes
- Publish the interim manuscript, experiment methods and scripts, reports, run records, and selected licensed references and parity-check matrices.
- Document where to acquire externally hosted inputs and how to verify the public snapshot.

### Scientific record
- Preserve the scientific claims and limitations from source release v0.0.145 and the original evidence hashes. No additional decoding or RF acquisition took place for this release.

### Validation
- Verified 1,425 inventoried files, 524 run manifests and 390 Python sources with the working tree and staged index. The release guard accepted v0.0.1. All 13 tests in the documented data-independent subset passed.

### Limitations
- Full reproductions require the referenced capture files and historical artifacts where specified. Original run manifests, capture files and complete Git history remain in the source archive.
