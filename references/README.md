# 参考材料与来源

`qin/` 保存导入的 MATLAB 实现、序列和其自带许可/来源记录；`misaka_*` 保存公开说明快照与来源哈希；`Starlink_waterfall_v2.py` 是原样导入的参考脚本。第三方结论不能直接充作本地录波的解码结果。

参考文件的历史下载方式和原始内容不在本轮改写。部分历史下载代码使用过关闭 TLS 验证，保留用于审计；不把这种设置作为新的推荐方法。

外部 leo-tracker 快照的根 LICENSE 未找到，见 `../provenance/leo_input_snapshot.json`。不编造许可、不将文件重新声明为本项目原创。公开版保留来源记录和上游入口。

`visual_identity/` 是既有图表使用的 spacelibre 资源的字节一致快照，来源与哈希见 `../provenance/visual_assets.json`，权威版本为 https://github.com/spacelibres/vi 。没有创造新 logo 几何。
