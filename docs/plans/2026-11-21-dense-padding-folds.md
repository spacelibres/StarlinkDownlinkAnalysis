# E077 多填充码字的密集折叠关系

使用 E074 保存的前 1,024 位、条件补尾和实测后段。将 E036 中共享完整两级头部的档案块合并，再以种子 2026112177 对连通组做固定随机划分。受检格式均报告覆盖及失败，原始前缀和按 PN 假设调整的前缀分别计算。

假设系统位和后段在相同提升长度下由循环矩阵连接。在 128、256、512、1,024 位块内分别按模 1 或模 2 的等距位置求二进制奇偶。补尾假设下 1,024 位后的贡献为固定偏置。使用 Hadamard 变换搜索全部前缀折叠的二进制线性组合，偏置自由，不限制稀疏度。仅使用全可见折叠输入。训练同分的模型只有在后续候选预测完全一致时才可计分；否则保留未识别。按留出来源组等权计分。对照将校验折叠循环错位，或将系统特征替换成不同来源组的供体。

训练与留出分组中的 Code 5 原始字提供实测正对照，包括固定的实际循环长度和受检不相符长度。合成用例验证模 2 折叠、Hadamard 搜索和并列拒绝。若高阶关系未通过，报告能实际辨别的模型覆盖，区分假设受限与灵敏度不足。

追加已知 PN 区间的实测灵敏度。固定 E076 三重合并的掩码，使用前一独立 PN 注册窗口选中的五个末字，只测各末字保留的最后 512 位。分别统计 16 至 512 位的模 1、模 2 折叠可观察及正确数量。不用 PN 补足擦除。另对全部得分有效、对照有变异的高阶模型，同时记录按组错配与坐标错位的家族最大对照。
