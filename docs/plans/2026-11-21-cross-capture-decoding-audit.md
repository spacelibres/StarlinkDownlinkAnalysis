# E047 · 多录波解码链审计

- 对原始 WAV、两份 NPZ 和两份实测宽带录波的窄频窗，用相同归一化时延相关检查 1–4 个帧间隔与半帧对照。WAV 基于既有 CW 去漂并沿用整块分组，NPZ 从原 IQ 起算并逐样点去重，不用其解码元数据估计周期。宽带以真实 CI16/NPY 下变频和抗混叠降采样，分别投影到中心与下边缘作为同捕获配对对照。
- 用既有卷积码、CRC、填充约定和 Code 5 生成矩阵，对实际 28 个宽带头部锚按频窗计算 H1、H2 和首个 Code 5 字的观测秩。分别保留原 WAV 和每个 NPZ 的理想通带。秩是接收机可见坐标假设下的上界，不能核发窄带比特。
- 将物理节拍、同步、参考重复、头部、FEC 和字段归属放在同一证据表。保留峰值失败、重复输入及不能横向转移的结论。探索查看过相同数据的少数窗。
