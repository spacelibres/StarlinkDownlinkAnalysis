# E076 高阶三重近重复的交叉预测和位擦除

遍历秦档案中至少有三帧共享 H1/H2 的全部组。按 E070 的字长、星座和候选系统区取样。每个码字以三帧前 256 位的三次配对注册，同一对至少覆盖 90%，位差至多 2%。后续系统位和候选校验位都不参与注册。此次不拟合参数、不新增训练划分，逐三帧轮换留出，统计同捕获内的第三份观测。共享帧的多次匹配仍属同一原头部组。

按 E075 的槽级半径对照对四角 16QAM 幅度通道记擦除。分别比较两路均可见且一致、两路冲突、单路可见和无数据。用前两路合成的严格一致掩码预测第三路，另外单列由一条供体填补的擦除。以区段内循环错位作为控制。输出零冲突的范围、仍缺的位及三路相关的限制。保存合并后的完整判决和掩码，单帧输入可从已记录哈希的原档案复算。

另以固定 PN15 检验真值可用的子集。每路都必须在候选系统区停止前 1,536 至 1,024 位的前窗内满足覆盖及匹配门槛。之后才统计靠近停止位置的最后 512 位，避免以同一位置选入与评分。测量原单路和一致位的错误率以及擦除量。合成用例检验保留条件、冲突、单路填补和参与计数。

首轮只在一个头部组得到高阶三重重复。追加已知 Code 5 正对照，在全部头部组从 H1 取第一段码字，按同样 256 位门槛注册高阶结果之外的三重观测。对宽带历史数据已冻结的 Code 5 生成矩阵，比较各单路、三路奇数多数判决、去异议位后唯一补全的校验。去异议检验以历史 128 结构把 1,024 个校验坐标切成 8 块，种子 2026112176 固定分成相邻性保持的 4+4 块，两组互换拟合和验证，逐字要求解一致。记录原始、重建和仍未通过的坐标。

保留追加阶段的全可见运行。最终加入部分可见字，要求每路至少 90% BPSK 格点，再按至少两路可见且无异议的坐标执行同样的校验。同步保留强制判符号的单路和多数判决结果，用于量化直接硬判的代价。
