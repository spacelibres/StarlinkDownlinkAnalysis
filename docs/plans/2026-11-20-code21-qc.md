# E016 · Code 21 的循环块生成关系

- 使用原 480 MS/s IQ 和 E010 头部资源坐标，沿用 E015 基于导频的时间展开及已知 H1 前缀复增益。从 Code 21 的每个分配读出 4096 个 QPSK 资源每字。以 π/4 开始逆时针四个相位，采用论文整数标签 3、1、0、2，按高位在先串行化。
- 采用论文的 (8192,5120,512) 假设。在 GF(2)[x]/(x^512+1) 内求 10×6 个循环多项式，按奇数重量主元消元。模 x+1 满秩是本求解器的唯一性门。矩阵展开后抽验与二进制计算一致。
- 论文对应组为旧索引 −1、3 的先 7+13 字拟合，同帧其余字为拟合帧复核。其余完整帧全留作该划分的保留组。另固定种子 2026112115，前两帧为随机拟合组；在拟合组内只按 QPSK 星座至坐标轴的最小距离排序，取最大裕量的 20 字。按帧保留，不把同帧其余字称为保留组。
- 在同一位序下，从已冻结的 Code 9 矩阵提取 10×6 循环多项式。检验原指数零填充与指数乘四两种转移；用实际 Code 21 多项式模 x^128+1 对比 Code 9。保留字的错位、取反与重调制误差分别报告。
- 拟合失败保存原始硬判决与秩，不删除坏字。任何后续标号或解调修正另有依据和运行记录。
