# E012：从资源分配进入载荷编码关系

## 范围与依据

干净基线 v0.0.9；继续用户已授权的离线科研工作，不访问无线硬件、不发射、不修改两个旧目录、不推送。原始宽带 NPY 和 E010 的全部头部结果冻结。此捕获的参数已被旧研究和原论文使用，划出保留码字不等于全程未见数据。

原论文 arXiv:2610.29387v2 §II、V、VI-A 提供候选接收/编码模型；当前并未找到原生成矩阵文件，不能假装直接执行了公开解码器。旧脚本 68 的所谓 Code5 区间 10468–10923 实为 H2，不能继承其标签。

## 冻结实验设计

1. 新建 `experiments/E012/scripts/code5_core.py`，从 IQ 重新校正：Fs=480MHz，参考中点，频偏 48257.986 Hz、变化率 −1107.157 Hz/s；帧原点 639992，周期 640009.32，普通 slot 2112/CP64/FFT2048。这些值继承论文/旧研究，当前不以载荷奇偶误差优化。
2. 用固定 16 tap Lanczos 插值在分数网格采样。SSS 已有 MAT 1024 载波模板，逐载波估计信道，分负/正载波段高斯平滑 sigma=2（truncate=4）。每 slot 16 导频取交替 8 个拟合共同相位/线性斜率和标量幅度，另 8 个只作验证。不要用未知数据调整相位。
3. 第一头部后 r=228 开始，每份 H1 的 code5 数量 C 给出 C×2048；跳过 H2，再从条件分配中提取额外 code5 字段。2048 位分为前 1024 系统坐标、后 1024 校验坐标，候选标号 b=(Re z<0)。固定已知导频/PN 约定，不以保留组校验择极性。
4. 训练为旧 frame −1、1、2 的首段，6+5+3=14 字；不把后续字段加入训练。QC lifting Z=128，16 个连续块一起循环移位，得到 1792 条结构扩展方程。它们不是1792次采集。
5. GF(2) 消元直接求 U P=V：报告输入秩、矛盾方程、自由度；只有秩1024且一致时生成矩阵唯一于当前 QC/比特顺序模型。不得在有矛盾时删除码字或用自由参数拟合保留组。
6. 冻结 P 后检验剩余首段77字及后续同码号字段，逐字保存校验差异。预设 ±1 资源错位、校验位置排列、全字取反和每16校验位翻转一位。全字取反若仍通过，单独解释全一码字简并，不当作模型失败或将其隐藏。
7. 用同一已知校准将预测校验调制回 ±1，与原复数观测比较 NMSE；不另拟合目标字段增益/相位。系统位是观测输入，评价重点是未用于拟合的校验坐标。通过不等于传输真值 BER/身份认证或应用明文。
8. 预设未校正 CFO 的接收消融，保留其 EVM、硬判决和校验结果；失败不用于调参。若主模型失败，先保存提取结果、训练秩/矛盾，再按信号模型诊断，不选择能过CRC/校验的候选来粉饰。

## 先测后实现与里程碑

- 合成复数正弦验证分数插值精度及越界拒绝；已知频响/导频与独立保留导频扰动验证校准隔离。
- 已知二元线性映射验证恢复、秩亏不伪造矩阵、重复输入矛盾可检出；QC 移位与小型已知循环码前向模型对账。
- 使用隔离运行入口保存软符号、硬判决、P、逐字校验表及控制。原证据保持不变。
- 形成实质数值结果后才准备0.0.10，包含五段changelog、完整性/单元测试/索引/LFS检查、提交与注释标签。
- 本阶段最多声称候选系统/校验关系。稀疏完整 H、纠错性能、源字节语义和独立宽带捕获泛化仍需后续，长期目标 active。

## 首次运行后的幅度模型跟进

首轮训练秩1024、零矛盾，93/93码字通过，但单位幅度重调制 NMSE≈0.607。不能隐藏这个信号域缺口。新增已知 H1 前16位对应前48个编码符号的复数最小二乘增益：`g=Σ conj(a_known) z_known / Σ |a_known|²`。只用于另一个明确标注的幅度/相位尺度诊断，不改变原硬比特、生成矩阵、分组或主结果；原单位幅度误差完整保留。不用目标载荷拟合。追加合成真值检查和新运行，说明这是首轮触发的跟进，非独立验证。
