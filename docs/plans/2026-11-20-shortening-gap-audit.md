# E022 · 缩短码未知中段

- 固定 E021 的 189 个 Code 28 字和 E017 的七个 Code 37 字，读取保留的中段硬判决。只检查落在 256/384 位窗口中的坐标，排除最后的额外标号位。记录各组帧。
- 检查相同模板的复用。仅在拟合帧逐位选多数值，保留帧评价。独立记录每个窗口的位均值、重复数和两两汉明距离。
- 检查此前已验证的 PN15 序列是否能解释中段。训练时选择相位、方向及整体取反，冻结后检验五种定位坐标：每字重置、只在中段递增、按码字位数递增、按不含导频资源递增、按含导频载波递增。另外每字用前半段独立估计相位和方向，再预测后半段，允许任意字级种子。
- 以整段历史预测下一位，穷举全部 2^16 个不超过 16 阶的线性反馈掩码和常数项，固定训练候选，报告保留效果。99 次按字循环移动目标作为置换对照，保留原始历史。
- 正对照使用同样帧组和字数的合成 PN15，5% 独立位翻转，显式种子。合成输入与原录波结果分开。上述检验不涵盖任意伪随机发生器、密钥或字段语义。
