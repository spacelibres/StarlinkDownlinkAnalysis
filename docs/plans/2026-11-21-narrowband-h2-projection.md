# E024 窄带第二头部投影

1. 从 WAV 的继承时频模型和 NPZ 的逐窗元数据冻结通带载波。保留采样带宽内的载波中心，并复用非导频资源的序列。
2. 从 E010 和 E014 读取通过 CRC 的第二头部，按已知整帧位置建立理想擦除掩码。逐个检查完整卷积码和两种条件字段投影的 GF(2) 唯一性，并为真实参考头部构造可复核的 CRC 相容替代。
3. 按固定通带和相同头部几何比较同捕获里的互异已知头部。计算同一未知头部可被各接收位置重复观测时的理想联合上界，另列完整带宽对照。
4. 扫描工作模型允许的第二头部位置和块数，报告带宽内可见资源数。报告区分实际头部字串投影、频窗假设和理论替代候选。

这是一项确定性穷举，无跨帧拟合、随机采样或 RF 操作。
