# E018 · 公开 QC 图的多调制复现

- 逐行录入 Liu 等 v2 图 12 的 128、512、1024 三种循环移位，缺边为 −1。检查指向约定时，用 E013 的 Code 5 稀疏矩阵逐行集合对比。全矩阵来自论文，IQ 不参与矩阵求解。
- 将 512、1024 的校验方程分别改写为循环多项式方程，证明校验侧可逆并导出系统生成矩阵。验证正向重编码及原矩阵综合。保存多项式形式。
- 使用 E015 接收方法和 E010 分配，固定 Code 3 BPSK、Code 12/10 QPSK、Code 27 八点调制及 Code 39 16QAM 的映射。参数配置参考论文和已查看的探索结果，保留所有字。Code 27/39 各只有一字，不能按格式另划保留组。
- 对实际初始非零综合用固定归一化 min-sum 校正，保留零迭代与失败。检查全字取反和两种 ±1 资源错位。用 Code 5 公开移位表的零扩展和按比例放大作为有限的错误模型。
- 检查 Code 10 系统位各块的奇偶投影有无非零线性约束。有限观察上的约束不能确认发送系统始终限制输入空间。
