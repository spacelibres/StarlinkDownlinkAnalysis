# E059 共现时轴的循环前缀差分

沿用 radio-sdr 的离线范围及 writing-plans 和 test-driven-development 的实验流程。输入为原 250 MS/s IQ 和 E014、E043、E044 的归档坐标。按已检出的时轴分类为共现、只检出偏移时轴、主时轴强帧三个组。检测门槛有漏检可能。

1. 主时轴已定位样点用其时钟重采样，取循环前缀内部和相隔 2,048 个分析样点的符号尾部。按主时轴 CFO 去旋后相减，记录两份样点相关、能量变化以及遗留主时轴导频。错误间隔为 −47、+47 样点。
2. 在相同物理时间建立两条时轴的公开边缘导频模型。先收进两个采样点各自的模型，再按相同方式作差。比较偏移时轴导频在前缀和差分数据上的留出预测，并跑错一槽的 PN 对照。
3. 用固定种子 2026112159 把主时轴第 67–210 槽的连续 12 槽块均分，分别拟合及验证复增益。记录各窗模型条件数。H2 附近参与测量，但稀疏前缀样点不覆盖完整 H2，实验只检验相消与导频保留。
4. 合成测试检查本时轴两个 CP 样点上的模板严格相等，以及错轴的已知信号在作差后仍可被多个导频系数预测。核对独立复跑及所有失败对照。

首轮短前缀拟合的导频正对照不足。保留它并加入完整 FFT 校准：各连续 12 槽块只选块内第 3、6、9 槽附近的完整 OFDM 窗，只从校准块估计两条时轴的导频复增益，再预测留出块的前缀与差分。校准 FFT 必须完全位于各自的物理时间块。在每种方法中分别记录正确及错一槽导频。追加两个同源方法属于灵敏度诊断。
