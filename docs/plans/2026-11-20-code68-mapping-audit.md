# E023 · Code 68 边界和既有码迁移

- 固定 E010 的条件资源分配和四帧中的七个候选字。以 E021 采样网格校正为基础，用同帧 Code 28 的星座学习载波响应，再以交叉的奇偶载波估计 Code 68 的时隙增益。接收器不读取候选校验。对照仅导频标定和转移后的 16 点距离。
- 用帧末已知参考填充估计常量，从独立末尾区间估计，不用于选择局部位置。在预测终点 ±64 资源比较 16 点与常量两类误差，记录转折位置。
- 用每个已判决物理星座点的四位标号作 64 个二元未知数。冻结 Code 3 和 Code 21 的线性算子，利用全部校验构造齐次方程。比较每个点的四个坐标是否在整个零空间内被迫与另一点相同。若有任何碰撞，精确方程没有双射解。分别测试训练帧 5、9 与保留帧 1、13；加入合成正确标号、固定量级位误判的对照。
- 单独测试共享 Code 39 Gray 标号下的未知系统 QC 关系。固定 N=8192、Z=1024/2048，遍历能在五个拟合字中有冗余约束的系统块数，同时探查模 x^16+1。只有完整模型拟合通过才对保留帧报告外推。其他位序、擦除及非系统布局在有限检验范围之外。
