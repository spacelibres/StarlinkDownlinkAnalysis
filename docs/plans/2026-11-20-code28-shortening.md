# E019 · Code 28 的缩短关系

- 使用同一份 480 MS/s 经哈希固定的录波和 E010 头部。从四组帧按固定资源跨度 5,462 提取全部 Code 28 字，沿用已知前缀及导频接收校正。固定采用 E017 的八点标号，保留观测中的 16,386 个标号位。
- 检验论文的 16,384 位、9,216 系统位母码假设。母码输入前 256 位预置零，接收前 8,960 位填在之后，接收索引 9,216–16,383 为校验。原始的中间 256 位和末尾两个额外标号位保存并单列。
- 论文对应整帧划分为 1、5 和 9、13。另用种子 2026112019 分配前两个组拟合，余下两个组保留。各自只在训练帧按整个字的最小最近邻代价差排序，取前 20 字。每组独立求解 QC1024 生成矩阵，无可逆主元或矛盾则记为失败。完整保留所有训练帧和保留帧判决。
- 比较冻结生成关系的硬判决预测、错位、全字取反、用接收中段作母码输入、把虚拟零移至末尾。报告成功率和分组；不以同帧码字为独立采集。
- 若硬判决有非零综合，在冻结矩阵上转移 E017 的有限符号搜索，对每字枚举所有单符号替换，加上代价最小 256 个替换中的至多四符号组合。仅采用范围内唯一的核心解。保留所有失败及未知位原样掩码。另对原始零综合的词求母码省略段的可辨识秩。
