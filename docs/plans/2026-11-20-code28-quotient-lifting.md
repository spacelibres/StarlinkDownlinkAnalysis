# E020 · Code 28 重根商环逐阶估计

- 使用 E019 封存硬判决、资源坐标和整帧划分。以 t=x+1 变换每个长度 1,024 的块。对母码缩短关系 v(t)=u(t)P(t) 先拟合模 t，再逐阶扣除低阶系数的贡献。第 d 阶只枚举 512 种来自 u(0) 的线性组合。
- 固定求至 t^16，任何层都不使用保留组拟合。记录两种划分各列的最高分、次高分、并列数、冻结预测和整帧保留组的预测准确度。拟合后检查连续一致阶数。不把后续某阶偶然一致计作已识别低阶前缀。
- 对照分为完整校验块向量的帧内置换（99 次）、单位矩阵循环保真合成小码，以及 E016 已恢复的 Code 21 正对照。Code 21 的既有矩阵只用于事后验证求解器，拟合输入使用它的接收判决。明确低阶关系、整个编码和发送真值的区别。
