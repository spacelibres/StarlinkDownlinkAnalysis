# E050 · 从实测星座验证帧内分配顺序

- 从两份宽带 IQ 重取物理层软符号，用既有采集时钟、解析 PN、导频及首头部前缀校正。250 MS/s 分支再用第二头部前已通过校验的 Code 5 符号定载波增益。
- 在整帧运行冻结星座库的盲变点检验，然后与已冻结的 20 位头部布局、字长及次序对比。记录盲检、条件近邻复核和未命中，区分两者。相同星座之间的未知边界保留。
- 交换分配项而保持终点相同，对照顺序信息。用理想 WAV 与 NPZ 通带抽样同一实测网格，比较在窄带几何下可见的替代布局。频窗是已校正网格的理想掩码，不能当作重新接收。
- 保存每帧、每边界和每个替代布局的分数。探索时已观察到同一批原始符号，全部结果作为同捕获条件检验记录。

第一次盲检发现，跨真实跳变的短混合窗口可能短暂选择第三种星座。保留初始结果，加一项通用控制。从持续至少三个块的星座段取边界，允许中间隔至多三个不稳定块，再用相邻持续段的星座做精定位。
