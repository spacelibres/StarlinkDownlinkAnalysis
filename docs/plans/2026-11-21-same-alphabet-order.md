# E069 同星座分配内的顺序证据

只读使用 Qin 全档案缓存和旧 250 MS/s 实验。使用 radio-sdr、writing-plans 和 test-driven-development。沿用 E068 的资源单位和 E036 的 H2，取相邻且候选星座相同的连续描述符。比较所有内部排列，每个排列保持同一起点、末端和星座区间。使用 E068 的整组留出划分报告扩展结果。

1. 使用 E029/E030 冻结的 PN15 位序和放置规则、E051 的 128/32 符号门槛及其他归档格式已估的系统边界。对同星座区间内每个候选排列的最后字，都在头部指定的候选坐标检验固定 PN 停止。每种排列取得完全相同的测量机会。候选集合依赖 H2，PN 信号判据不使用排列优先级。
2. 每个候选按通过的末字标记数计分，用子集动态规划计算最优分数、并列排列数、所有最优解的可能位置。保存并列及原顺序非最优。对错一位 PN 和按 16 符号组打乱前窗重复同样的比较。
3. 以 E034 已配对的帧位置把 E051 原 IQ 候选与档案硬判的同一坐标比较，不把重叠录波计作独立实验。按 16QAM、交叉 32QAM 等及有无 PN 支持报告覆盖。
4. 用小集合穷举检查动态规划、可辨识位置及并列数；重复坏位和无填充对照。没有标记的边界保留，而非据此否定头部。
