# E038 · 用先行 Code 5 校准 MCS 6，并检验扩展记录

- 沿用 E036 档案组和 E037 的记录分段。仅处理已有 Ku 波段接收数据。从同帧取第一头部标示的 Code 5，屏蔽 `k=+511`，用 E013 的 H 枚举唯一擦除解，再以 E012 的 P 重编码，估计该载波的四分之一圈旋转。另跑固定的归一化 min-sum 分支，记录其他位变化、并列和不收敛。
- 相位只由前置 Code 5 确定。在 MCS 6 已知 PN 区间量化转移，并对所有边缘坐标保存判决、擦除和已知参考掩码。比较零旋转与错半圈。未知坐标上的输出留待外部校验。
- 在原 MCS 6 硬判逐字检查 `E` 后是否相邻 `C`，及 `E` 的最低位。固定 12 字节锚和停止标签后 17–20 字节的起始窗。保存错相位、随机错序字节、锚之外的实测位置以及未命中。
- 补充检验把锚窗口里的边缘位完全屏蔽，只用另外 95 位选择位置，再比较该位的原判、Code 5 相位转移判决和错半圈。记录搜索范围及是否有先前的精确锚。
- 独立复算冻结字段、Code 5 擦除唯一性和 MCS 6 评估。按档案段汇报结果，保留失败和范围限制。
