# E071 LEO 原档案的载波覆盖

用已知上下边缘导频作为坐标对照，先检验 1024 点 FFT 索引转为有符号载波的规则，再用原工程保存的配对录波清单计算 +511 的标称覆盖。登记调谐频率、样率、配置带宽、边缘余量、清单路径和指纹。保留未入原报告前五名的合格录波，避免把该报告的 PSS 选段当成全库。额外核对有独立高采样率 GLRT 报告的 0181。

本次是档案元数据全量计算，未拟合接收参数，无随机划分。将理想通带余量与真实可用性分开，保留边缘滤波、载波频偏、间断和缺失原始样本的限制。后续若能取得样点，先在连续区间内用导频验证 IF 与 IQ 正负号，再检验 +511 的样点覆盖和可用增益。
