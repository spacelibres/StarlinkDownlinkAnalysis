# E045 · 偏移帧 H2 起点与系统区重复

- 对 E044 归档复数软判用已验证的 H1 重编码定相，不用 H2 或 Code 5 观测调整相位。固定两组互补整帧和共现组。按 20 位布局由 H1 定位 H2，并保留原归档相位对照。
- 在预期起点穷举首字节 256 种编码。把一组的赢家固定到另一组，检查零偏移和前后各 1,000 资源。分别报告固定字节的定时秩和所有字节同时搜索的对照。
- 探索扫描见到 `3444` 与 `34CC` 候选。拆分后八个卷积三元组，用一半坐标给帧分支、另一半检验有符号差异，同时保留其它合法前缀。两个参考间的区别不能认证完整前缀或 H2 CRC。
- 对 H1 指向的四个 Code 5 候选字，按系统区及校验区比较跨组重复强度。在每个互补训练组以完整 128 资源块选择固定 PN15 支持区间，在另一组复验相位、位序及随机相位对照。另在训练组扫全部 32,767 个 PN15 相位，冻结峰后检查保留排名，并比较原字节位序与错递推方向。逐 128 资源块移除固定 PN15 方向后重新计算跨组相关。
- 保存分组、位序、对照、哈希、相位、软观测与失败结果。本实验复用同一份录波及探索时看过的样点。
