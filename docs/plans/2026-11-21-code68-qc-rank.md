# E033 · Code 68 准循环方程的可辨识性

- 用 E032 冻结的 6,144 位候选系统区和 E023 的七个观测字，保留原始硬判决。另建已知 PN15 区间替换和去 PN15 的候选输入。记录每处替换及复数星座代价。
- 对 256、512、1,024、2,048 位的循环块，在 GF(2)[t]/t^Z 上按最小次数对角化，令 t=x+1。分别量化拟合系统的秩、矛盾出现的最低次数、保留字可确定的投影和实际差异。每次留出一整帧。
- 允许未知但各字共享的仿射项。用训练组低裕量符号的次近星座点做有限替换，按 32 阶投影的一致性和星座距离选择，保留组不参与选择。
- 构造帧组同规模的已知准循环正对照。验证非单位主元、不可确定输出和少量模型外比特错误的后果。将仿真和实测的结论分开。
