# E063 前段 Code 5 到后段 Code 21 的边缘载波检验

离线使用 radio-sdr，并按 writing-plans 和 test-driven-development 固定候选和对照。只读取 E034 的软符号、冻结头部坐标、Code 5/21 矩阵和 E062 回执。源为同次录波，禁止把先后资源及两条前端记成独立采集。

1. 在两个软前端都对 6 个预定边缘载波擦除 Code 5 位，优先只用未擦除硬判作 GF(2) 唯一补全。无解时另记归一化 min-sum 的重编码结果和其他位改动。每帧每载波至少三个补全值且复相位集中度达到 0.6 时估计四分之一圈和连续相位。在 Code 5 字间做留一验证，记录前段校准能解释的极性。
2. 在原 H2 分配位置比较 Code 21 原判、只修正 +511 的冻结连续/四分之一圈、给 +511 套用 +510 的校准、给 +511 相位增加半圈等对照。计算实际收到的全部校验位误差，不在 Code 21 拟合校准相位。
3. 对全部 Code 21 字分别擦除 +511、+510、−512 的位。用 E062 三组训练坐标，从观测校验位恢复系统擦除。各组要求唯一且完全一致，并分别在未用于选择、且仍有原始观测的校验位上验证。擦除的校验位只能重编码补全，不能参与独立验证。列出与 E062 重叠和新增位置。
4. 用合成线性系统检查唯一解、遗漏行引起的欠秩以及未观测校验位不能被计成通过。用相位合成对照验证连续旋转与基于振幅数值的集中度。

首轮确认连续相位转移可以通过完整实测综合后，保留初始结果并追加两项可审计证据。保存通过连续相位的完整位串。取同前端的下一个留出帧所估的 +511 相位作固定错帧对照，不会把错帧的结果用作择优。与 E062 打包字和擦除字独立比较相同位置。
