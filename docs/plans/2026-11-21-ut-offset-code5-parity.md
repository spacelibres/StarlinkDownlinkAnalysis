# E046 · 偏移帧 Code 5 留出校验位

- 沿用 E044 的两个互补整帧组及共现组，使用 E045 的 H1 参考仅定相。从冻结的 E012 生成矩阵及 E013 校验矩阵读取 Code 5，记录输入哈希。
- 将每字后半的八个 128 位校验块随机分成两组。每次屏蔽其中一组，只用恰好跨一个屏蔽位置的校验行计算目标位外信息。接收尺度只从可见系统位与校验位估计。屏蔽数据仅用于计分。
- 帧组先验只取校准组系统位，固定 0、0.3、0.6、0.9 四个混合强度。另用偏移一个整块的错误先验、E045 的冻结 PN15 支持区、目标观测循环移位、校验列错位和真实强帧对照。比较相邻错位的共同列支持，并记录两模型实际共享的校验行数。
- 在完整软向量上分别尝试归一化最小和及阻尼和积译码，保留全部综合结果。只有零综合且冻结生成器回编码完全一致才进入码字候选。和积合成对照单列，不作为实测解码。
- 模型设计经过同一录波探索。记录共享样点、帧分组及失败。正留出相关只支持码结构，不认证单字、确切位边界或真实 BER。
