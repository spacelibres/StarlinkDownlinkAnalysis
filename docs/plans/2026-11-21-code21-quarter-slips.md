# E062 Code 21 的逐槽相位与留出校验

采用离线 radio-sdr、writing-plans 和 test-driven-development 流程。使用本地冻结的 Code 21 生成器、E034 的 H2 分配与 988–1000 档案切片。复用 5,120 个系统位、3,072 个校验位、不改字界。输入分别为整槽硬判、直接软符号和导频均衡软符号。同一接收窗口的不同处理不算不同码字。

1. 复现 E034 的固定全局相位。对每字按真实 OFDM 槽切片，分别检验整字统一四分之一圈及逐槽四分之一圈两类模型。利用线性生成器把相位变化造成的综合分解为每槽的异或，穷举离散候选。
2. 用六个 512 位校验块里的两个整块选相位，剩余四块检验。三个互斥训练块组各自产生选择。只有每组训练唯一、三组选出同一整字、训练与留出均零差异才算完整复验。并列选择保留为未决，CRC 不参与本实验。
3. 同样检验字起点 ±1 资源及各校验循环块内错配一位，并保留每个位置的原失败。检查同一 OFDM 槽被相邻字看到时，是否得出相容相位。不从单个合拍的字推断整帧、传输身份或应用含义。
4. 合成测试核对多个已知相位变化时的综合叠加，并检查训练校验相同但留出不一致时仍拒绝完整复验。

合成对照暴露了整 512 位分组的覆盖缺口。若某槽只含后部校验位，前部训练块对该槽的所有相位给出同样目标。首轮真实数据归档保留。修订方案将 3,072 位校验划分为 96 个连续 32 位组。每相邻三个整组在种子 2026112162 下各分给三个训练分支之一，余下 64 组作为该分支留出。只用中间校验布局确定分组，选择与零差异接受条件沿用首轮。

逐槽四分之一圈没有新增完整字后，补查少量符号错误。固定 E034 相位，对一个 QPSK 符号内的第一位、第二位或两位变化预计算综合。仅用训练综合索引候选，不用全综合择优。强验证要求三组同一唯一非零修正，每组在留出区还存在被纠正的综合位，并能零差异重编码。只触及局部校验位、不能跨三个划分判定的候选单列，不写入通过字。保留两种错位及校验块内错配。
