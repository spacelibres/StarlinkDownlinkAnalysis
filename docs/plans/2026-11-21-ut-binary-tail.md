# E025 · 250 MS/s 二元尾段验证

1. 校验 IQ 与 E024 复跑接收记录的哈希。沿用 PSS、SSS 和导频参数，只检查完整帧。使用同帧已重编码的 Code 5 字建立第二个接收标定。
2. 固定候选星座和末段搜索长度，用累计代价寻找进入 BPSK 的单次转折。先不读取后段分配字段。比较去 PN、保留 PN、常值假设与尺度敏感性。用合成 QAM/BPSK 转折验算索引和无尾拒绝。
3. 报告盲测端点与 F250 公布的条件位置差；逐帧记录可确认的位判决。初跑出现精确周期后，使用互补整帧划分验最短周期，比较正确与错误跨符号位移和保位值数量的模板排列。保留对照和未解语义。
4. 对原始样点、代码、边界及候选符号建账。完整复跑、验算后增加一个本地补丁版本。
