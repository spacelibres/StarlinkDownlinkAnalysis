# E072 用实测 IQ 检验 LEO 频带边缘

复用 E014 冻结的 250 MS/s CI16、宽带帧坐标和 Code 5 校验矩阵。擦除每个 Code 5 字的 +511 位后，精确恢复位值并核对其余校验。以原始 250 MS/s 及上边缘四根导频作对照。从 E071 的 0181 参数读取 +511 相对调谐中心的频率。按帧整组随机分校准和留出，种子 2026112172，开始前固定分组和各频偏/滤波候选。

1. 把原始 IQ 数字变频至拟定 25 MS/s 窗口，施加理想矩形、250 kHz 和 1 MHz 升余弦滚降，再十倍抽取。在窄带样点上用傅里叶插值回到整数评价网格，按冻结时钟取 OFDM 有效段。分别测残余频偏 −250、−100、0、+100、+250 kHz。加入数字滤波后完全移除的载波测试以及已知通带载波测试。
2. 测量留出帧在 +511 的复系数与原始 IQ 的相关、传递幅度、相对误差和 Code 5 位一致性。位符号相位只使用校准帧的原始宽带估计，窄带分支固定沿用。用上边缘导频结果监测通带中部质量。
3. 输出每帧、每档和每个数据坐标的观测与残差。该实验共享原宽带捕获与参考帧时序，区分数字限带灵敏度、真实 LEO 模拟前端响应和独立录波符号验证。

首轮跨帧固定相位在宽带原始参考只达到 26/40。保留首轮记录，追加条件检验。每个留出帧只用时间最早的两个 +511 Code 5 参考位估相，同帧其余位置只参加打分。宽带估相转移和各数字窄带分支独立估相分别统计，以同一分支的下一留出帧相位作错帧对照。这个追加检验与首轮共享捕获；估相用到宽带约束恢复的参考位。
