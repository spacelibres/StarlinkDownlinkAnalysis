# E060 载荷准循环常数投影的软判检验

采用 writing-plans、test-driven-development 和离线 radio-sdr 流程。使用 250 MS/s 已归档的 MCS 66/70 复数星座以及 E028 的整帧划分。实时接收和发射均无。

1. 在 E029 已接受的校准帧末字 PN15 区间，用完全位于区间内的 16QAM 符号校准距离尺度。对符号四位的异或从星座后验求值，保留符号内位依赖。符号间用乘积近似。用整帧留出的 PN15 区间校验 128、256、512、1024 位折叠的软值及硬判可靠性。
2. 对每个适用块长和系统/校验分界，把候选字投影到 GF(2) 的 x=1，穷举每个校验块至多三个系统块的仿射关系。两种前端分别使用相同冻结尺度和两组数据，分别拟合并检验，按块聚合留出分数。原始约定为串行 Gray。固定各训练结果后，做 199 个留出帧内整字错配，以全族最大值评价。样本源、字形、符号间独立假设与模型覆盖范围必须记录。
3. 用相同算法评估冻结 Code 5 系统矩阵在 128 位块的常数投影，使用真实软判、独立帧组与既有宽带码字。Code 5 的已知关系不参与目标关系拟合。另做自包含合成测试验证选定关系可以转移到留出组。
4. 保留训练挑中的所有候选、留出分数、控制和软值衰减，按结果分别说明候选关系及可辨识性。

首轮后根据已知 PN15 的保留段灵敏度加入 128 位目标折叠。使用分批穷举保持每个校验块三列的设计及原有分组。并给出四列及以上候选的联合软值上界，即每字绝对值最大的四个系统列软值乘各个校验列软值的绝对值。
