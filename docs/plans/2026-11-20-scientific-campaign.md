# 离线解码科学实验计划

本轮授权：现有 WAV 与两份 NPZ 快照的离线分析、合成对照、代码修复、结果记录、本地逐次版本提交；不连接 RF 设备，不发射，不推送远端。原始证据保持只读。

## 路线与判据

优先采用“接收模型验证 → 实测复跑 → 未知成分独立检验 → 编码可观测性”的顺序。直接枚举译码器可能把低 SNR/漏采样拟合成比特；只看谱形又不足以检验信息内容。因此两条分支都保留，但先验证接收前端。

- [x] 以独立回归测试复现并修复局部数组被目录迁移替换的问题；复跑原负对照，提交 0.0.4。
- [x] 在独立 runs 下运行基础完整性、已知导频、泄漏、相干投影、循环/同步与中心载波等关键脚本；每项记录退出码、哈希、条件和失败，不重写封存结果。
- [x] 新建 E008：两份 NPZ 与 WAV 的接收可观测性和未知结构审计。先锁定定义，再看结果；使用整个重复周期分组，不把样点当独立采集。
- [ ] 对 NPZ 的未知载波检验参考相位/周期来源，比较精确 PN、错位参考、已知导频泄漏空假设和整周期相位随机化。区分参考间的固定差异与新信息。
- [ ] 对 WAV 检验前缀强弱是否预测同帧独立的 SSS/数据质量、是否需要逐帧频偏/相位修正；后事件数据作为对照而非独立采集。
- [ ] 在冻结的卷积码/CRC 约定下计算观测矩阵秩与缺失资源；未知位保留擦除，只有足够观测、重编码一致与独立 CRC 共同支持时才报告消息。
- [ ] 更新当前证据边界、公式与来源索引、实验记录；每个通过验证的里程碑末位加一并配套完整 changelog/标签。

## 数据与实现

沿用 experiments/E001–E007；新增 E008 使用 scripts/results/figures/experiment.json/README.md。通过 tools/run_experiment.py 输出到 runs；本地新脚本应支持 import 而不执行大型实验。随机种子显式记录，参数选择与测试分开。工具/估计器先用合成已知输入和空假设检验。

## 结论级别

已知序列识别、相对符号候选、经验证未知位、CRC 消息、字段语义分别记录。公共论文/数据只作为带来源的参考或外部正对照，不计作用户录波的解码。采集地点/时区仍未知，不补造。不能保证有限窄带样本包含完整头部，也不通过拼接不同时刻或未校准接收机来制造完整消息。
