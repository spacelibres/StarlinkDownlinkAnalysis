# E078 Code 5 起始字的字节边界与短记录

探索时已看过两份宽带实测首字的系统区，采用 E073 的位扰码和字节内反序约定。冻结探索得到的几项预测。首字节 L 指向 `00 46 … … 00 30 70`，偏移 L+66 开始有四条 7 字节记录。记录的已观测候选结构为交替的 `40 3f` 和 `40 bf`、同对共享 16 位小端值、两对的值异或为 1，以及序位字节依次 0、32、64、96。模板、位置及值约束分别评分，不将任一字段命名为已证实的语义。

使用冻结生成矩阵，只保留原始 1,024 校验位逐位匹配的完整第一字。同时检查全 1,009 秦档案帧，记录格点擦除、校验失败、结构失败及跨录波重复。秦档案含 UT 捕获的部分帧，使用 E034 的对应关系或每个码字直接去重。检查错相位、错字节顺序、相邻首字节偏移和两个探索时可用的固定绝对偏移。

为 7 字节切片使用相邻码字的独立观测来源。当记录跨 128 字节边界时，需同一 H1 分配的下一完整 Code 5 字通过实测校验。未通过或未覆盖时只评价已确实可见的条目。归档各条记录的结构字段、观测位置和校验证据。

首轮另见反序标签及省去四条短记录的候选。固定原先观察到的 `36 0a` 前缀位置和新见的 `76 08` 变体，以同一十字节后续标记检验前移 28 字节的预测。反序序位的两个 16 位值按 A、B、B、A 排列，仍要求 A 与 B 只异或最低位。追加阶段同时盲恢复原首轮格点缺失的字，固定 E076 的两组互补校验块，仅由位格点和 Code 5 矩阵决定准入。每组必须满秩、互相预测，保留实际观测与重建数量。不以字节规则选择重建。
