# E061 Qin 档案硬判与原 IQ 的槽内调制边界

离线研究按 radio-sdr、writing-plans 和 test-driven-development 的方法执行。Qin 论文描述按 OFDM 槽选单一星座。预查在部分已配对帧发现硬判两侧半径相同，本实验冻结边界与量化判据后全样本复核。

1. 读取已通过双头部的 1,009 帧目录，统计每个格式的帧数、分配量和已归档频域/原 IQ 覆盖。利用既有字长及 CRC 后分配资源位置预报 16QAM 与交叉 32QAM 的槽内切换。距槽边至少 64 个资源的切换进入固定检验。
2. 对 117 个已归档硬判帧，用与公共单位峰值星座吻合的专有半径检查整个槽及预报切点两侧。公共半径保留未区分。不用该档案拟合未知位。固定记录前后最近的纯调制整槽作为对照。
3. 对 E034 的八个逐帧配对，从 250 MS/s 原 IQ 重取符号，在邻近的纯调制槽拟合每种星座的幅度。用未用过的混合槽寻找最大似然切换点，比较离开预报位置的候选、两个纯槽和同槽不切换假设。距离尺度固定 0.03 和 0.06。需两尺度都支持、两侧符号方向正确并定位至 16 个资源内，才计入稳定实测。相同录波的正对照不算独立传输。
4. 合成测试验证公共半径保留擦除、硬判统一星座无法提供切点、连续软观测能还原两种星座的切换。报告软硬两层和仍不适用的全部情况。

首轮之后，用本地范围缓存扩展至 1,009 个硬判帧。扩展入口仅允许从既有缓存读取，记录版本标记和所接触字节段哈希。检查 117 帧重叠的硬判统计逐项相等。全档案增加的是硬判处理的覆盖，原 IQ 物理校验仍限于成功配对且保存混合槽的帧。
