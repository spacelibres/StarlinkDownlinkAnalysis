# E044 · 偏移时轴的导频定时与共同首头部

- 固定 E043 时轴和同步峰，以没有 A 峰的 15 个 B 时隙为主样本。随机按完整时隙分 7/8 组，双向转移。另保留 13 个 A/B 共现时隙检查受干扰条件。
- 从校准组的两个频带的交错导频时间谱估计公共频偏和采样比例，无需 CRC 或数据符号。使用留出整帧和交错载波评估，并对比 E043 的循环前缀定标、错槽 PN 两种控制。用训练侧导频估计各帧复相位，检查另半导频和后段槽位。
- 将校准组和保留组分开后，分别对齐并平均首头部软判。用校准组的已知 48 资源前缀确定折叠极性，固定后应用于保留组。译码完成后再核算 CRC，额外重调制未参与前缀定相的 180 个编码资源。整组符号置乱和无 PN 是对照。
- 由 H1 的候选分配推算 H2。对两组各自及逐帧检查 H2。用 E013 冻结的 Code 5 校验矩阵测试软综合，保留近距离错位和循环错位对照。软综合若无法区分相邻错位，不确认为有效码字。
- 探索阶段看到了同一首头部与导频相位斜率。验证流程复用同一 50 ms RF，所有参数、分组、软判和失败对照归档。

首轮双向转移出现一个未通过头部格式门槛的方向。保留固定极性结果，另行用留出组的已知 48 资源前缀估计该组的单个相位，复跑相同译码与无 PN 对照。其余 180 资源和 CRC 均不参与相位估计。
