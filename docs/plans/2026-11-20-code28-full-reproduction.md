# E021 · Code 28 完整复现的接收诊断

- 依论文 §II-B 检查导频随时隙的跨带相位斜率。固定 50–289 时隙和 E012 的八根拟合导频，拟合每帧剩余漂移。相对 SSS 锚点调整 FFT 前采样网格，保留其他八根导频的误差。比较原接收器、仅重采样、仅交叉标定、重采样加交叉标定。
- 探索中发现几何残差随时隙和载波变化。跟进固定先按时隙、后按载波做复增益标定：时隙增益由相反奇偶载波确定，载波增益由相反奇偶时隙确定。仅用最近星座点，不读目标校验。明确这与论文的接收器有差别。同一帧中的码字与标定相关。
- 保持 E019 的帧组和坐标。两组独立求生成矩阵，先报告可靠的 20 字硬拟合。在有矛盾时，固定 300 次九字校准组子集，模 x^16+1 选择唯一多数一致模型。保持该模型，用训练组样本在 QC1024 下获得完整模型。完整训练一致程度须过半，不用保留组择矩阵。
- 只有两组矩阵一致才做保留检验、E019 的有限符号修正，以及省略段/未知段审计。比较与 E020 已冻结低阶关系的逐项一致。记录所有失败和搜索界限。
