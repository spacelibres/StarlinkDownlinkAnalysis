# E079 Code 5 帧序计数与短记录值对照

探索时在原宽带发现首字节偏移 L 加 421 位处存在与波形帧时隔逐一对应的数值。固定该位置、逐字 PN15、低位优先以及增量 +1，在旧 480 MS/s 与 UT 250 MS/s 的冻结采集时轴预测其他首字。短记录的两种排列单列低三位、去除低三位后的共同值，以及是否服从同一帧序关系。编码器保持冻结。

秦档案沿用 E077 合并同头部的 44 组及其随机划分。只用校准组 TOA 的 750 Hz 折叠分布估计主时轴相位。±0.01 周期确定主时轴候选。再从校准组已验字估计计数常数，冻结后评分留出组。作为对照使用紧邻的位位置、帧序倒向、档案条目顺序和固定绝对偏移。保留偏离主时轴的观测、最高变化位、邻近位和窗口覆盖。

候选已经在探索中查看过档案聚合，无统计盲测宣称。源帧时序先于字节解析，跨录波校验和绝对帧计数零点分开。归档每个计数值及各对照，另用独立算式复算原样点对应和位序。

追加主时轴之外的内容对应检验。从离轴 Code 5 的读值减去已经冻结的档案计数常数，直接定位主时轴帧号，仅以 TOA 查索引。随后比较两级头部及 E074 已独立冻结的高阶近重复证据。-16 至 +16 帧均按同样办法核对。相同内容位于不同 TOA 时，不据此决定传播或重复机制。

追加 LEO Tracker 频窗检验。逐字节核对原工程选段和本地快照，按 IQ 样点去重。使用原工程每窗频偏和 E071 的跨采样率目录建立观测矩阵。按已知首字边界、扰码和偏移 L 的有利假设，计算 14 位和 32 位读取窗口在 GF(2) 上的有效秩，验证可见校验位是否提供额外约束。清单只给标称带宽，仍需原始 IQ 复验。
