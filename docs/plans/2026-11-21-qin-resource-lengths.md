# E035 · 档案资源长度与 PN15 边界

- 用 E025 的冻结 60 位模板测量 E034 档案尾段。末 600 符号拟合循环相位和复增益，按投影符号累积匹配对数分数，最后用相位余数细化边界。每帧保存估计质量、错 PN 槽和同组成打乱对照。
- 长窗口失败时只用最后一个 60 位周期拟合，再校验前一个完整周期。短尾结果单独标记，并保留长窗口失败分数。
- 在头部条件分配中冻结旧字长，使用整档案段划分拟合 6、35、42、75、81 的新字长。仅在一个档案段出现的格式参加拟合，其他段按固定种子补至数量矩阵满秩。不根据保留帧改动字长。
- 使用 E030 的交叉 32QAM 标号和 E029 的 PN15，检验 75、81 的全部候选字。核对系统区候选右端、反相位与错字首对照。
