# E010：完整头部可用性与无 CRC 搜索的资源布局

长期目标保持：逐步学习并解析 Starlink 信号；本阶段不是最终载荷解码。

## 预先冻结的验证路径

1. 按所请求 FFT/资源是否完整落入采集范围判断可用性，不要求 PSS 和整帧都完整。检查旧帧索引 −1 的 slot2 头部；尾端索引 17 必须因样点不足拒绝。
2. 第一头部沿用 E009 已验证方法。20 位条件字段以 LSB 权重读出 code5 数量，第二头部资源序号固定为 `228 + quantity×2048`。不搜索三个位置来寻找 CRC。
3. 第二头部先用必有的前 228 个 BPSK 资源拟合相位；以先前公开的首字节 0x34 确定极性。首块输入第 8–10 位以权重 1/2/4 给出 N；只解该 N 个块，不遍历 2/3/4 找 CRC。第 12–15 位给出候选条目数 D。
4. CRC、重编码、旧存档和公开示例仅用于事后比较。对第一头部预测的位置做固定 −114/−1/+1/+114 资源错位对照，以及随机资源排列控制。保留格式未准入、失败和 CRC 偶合，分母不丢弃。
5. 分别解析 19/20 位条目模型，保持其条件性；不把布局自洽当作唯一格式证明。先完成头部链，再安排独立捕获与 payload 前向模型。
