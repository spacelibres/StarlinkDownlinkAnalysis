# E056 LEO Tracker 频偏分支检验

从外部原工程只读载入两份 IQ 选段和选择记录，核对四个输入哈希与项目快照，按 IQ 内容去重。复用原工程的 Qin 导频模板和 FrameClock 符号模型，记录源码哈希。

1. 以原工程的频偏和帧起点为坐标。比较原分支、正负两级符号率分支及正负一级子载波间隔对照，各中心允许同样的 ±400 Hz 网格修正。用 17 符号循环错位做模板对照。
2. 每帧在每个符号的前半段估计八个复增益，用后半段预测，再互换前后。得分为对留出样点相对零预测的平方误差改善率。检验留出帧时保留原来的分支及细频偏，允许利用该帧的一半样点拟合该帧的复增益。
3. 沿用 E055 的四段连续帧组，枚举六个两组校准、两组留出组合。在每个模型的校准组中选择细频偏，报告每组留出分数。保留两次同源重复，统计时去重。穷举无随机种子，合成测试的种子另行固定。
4. 记录单路结果与两段双路原报告的频偏差是否相容，保留所有对照。历史起始坐标用过整窗，同窗验证判断条件可重现性，不估计盲捕获率。
