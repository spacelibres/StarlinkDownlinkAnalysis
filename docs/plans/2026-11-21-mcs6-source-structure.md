# E037 · MCS 6 去扰字节与边缘载波

- 输入为 E036 的接收处理后星座和 PN15 模型，以及 E014 的 250 MS/s Code 5 已校验字。记录哈希，沿用 E036 十三个相邻档案帧为一组的固定划分。仅离线分析。
- 固定 MCS 6 系统区前 10,240 位、MSB 优先，检查偏移 2 处的三个固定字节。自字节 5 开始，依高半字节 `C` 读五字节，依 `E` 读两字节，遇其他值停止。主门槛为至少五条 C 记录，另计终止标签和 C 末尾低三位的一致性。在保留组、另一编码格式、错 PN 相位和错字节起点上复算。
- 从校准填充段中选择最大差异载波。该载波若存在帧内旋转，用绝对槽奇偶交叉估计和评价，比较其余载波、同载波未修正投影和错误四分之一圈。保留帧组用于固定候选载波的检验。全程保持资源位置，保留无法确定的判决。
- 仅当固定规则或载波发现通过留出复算时确认新结构。对表达式做独立复算，保留失败和无法外推的范围。
