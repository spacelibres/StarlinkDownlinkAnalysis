# E013：稀疏完整校验阵与软纠错

基线v0.0.10，继续已授权离线科研；不操作无线设备、不发射、不改旧工程、不推送。原始/已封存证据只读。长期目标仍是有依据地推进信号解析，而非只满足软件测试。

## 冻结方案

1. 输入只取 E012 主运行 `v010-code5-parity-02` 的 P、观测符号、硬比特和已知前缀尺度；矩阵字节哈希必须为 d82157accb735e9c96c5fb3181136ea10969f97e51ee5fb516a4f78f5ec4f01c。搜索阶段不得读取码字以选择H。
2. 对 h=[a,b] 要求 a=P b。枚举1/2/3个parity支点；QC128下固定最小块中的一个支点偏移为0，使有限搜索覆盖该支点重量的循环轨道。完整1024位 XOR/bit_count 保留总重量≤6的关系。若P可逆，再在systematic支点同样枚举，由P逆求b。无64位投影捷径或碰撞候选充数。
3. 对候选支持在所有128循环位移中作规范化，按重量/字典顺序固定排序。逐轨道加入能增加GF2秩的独立行，目标1024行。不根据接收数据/译码成功择图。
4. 验证 G=[I|P]与H正交、rank(H)=1024、rank(Hp)=1024；从Hp Q=Hu重算Q并核对Q转置=P。保存全部seed、搜索计数、选中图、每行/列重量和秩。只有这些门同时满足才称同一码空间的稀疏完整表示，不证明唯一发送实现、girth或最小距离。
5. 软译码采用同步(flooding) normalized min-sum，eta=0.8，最多60次；LLR正号偏向0。无消息裁剪，以减少隐藏参数。先检查初始综合，已为码字则0次退出，不能把这种情况算为纠错能力。
6. 实际93字用E012已知前缀尺度y=z/g及假定复噪声尺度0.02，LLR=4Re(y)/0.02。报告原综合、译码综合、硬判决改动、是否匹配既有接收参考、重编码及信号域误差。噪声尺度未独立标定，且无裁剪min-sum对全局正缩放齐次，不能把多尺度重复算独立验证。
7. 人工软符号翻转分别为1/4/16位，每字固定随机位置、原置信度不变；全部93字保留，比较译码与原接收参考，不能只看综合。此处是人工注入，不声称真实空口纠正了这些错误。
8. 合成AWGN用冻结P编码新的随机系统位，各sigma=0.4/0.6/0.8/1.0各16字，真实噪声LLR=2y/sigma²。记录原错误、残余错误、失败及合法但错误码字，种子2026112013。64个模拟字不是新RF，不能据此报告通用BER曲线/容量结论。
9. 新建E013的核心/审计脚本、实验记录、测试、运行和报告；补充Gallager原始来源、归一化min-sum原论文及作者GitHub实现阅读等级。既有来源不冒充已执行依赖。

## 先测后实现与里程碑门

- 已知小型循环线性码检验：搜索输出正交、稀疏且张成完整对偶空间，Hp逆重构前向生成关系。
- Hamming小码验证弱单错纠正及LLR正缩放不改变结果；另以全一码字验证合法综合不等于既定零码字真值。
- 初始源码缺失先见失败，再实现。若H不满秩，保存缺口并停止解码门，不补稠密行后称全部稀疏。
