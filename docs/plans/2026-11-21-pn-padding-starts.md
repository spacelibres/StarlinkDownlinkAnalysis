# E070 PN15 填充位置与起点对齐

使用 radio-sdr、writing-plans 和 test-driven-development。只读分析 Qin 的全档案硬判。保留 E068 的整组划分、H2 已证实的资源坐标和此前 16QAM／交叉 32QAM 的冻结标号及 PN15。对每个可检验标签的所有完整候选字，明确记录在分配内的序号。

1. 冻结每类系统区的右端。对右端两侧各 512 位计算短窗匹配。只认相应星座的精确点，其他点记为擦除，前后各需要至少 90% 可见。已知 PN 的前窗匹配至少 0.85，后窗至多 0.68，下降至少 0.20。错一位 PN 与前窗置乱使用同样阈值。按末字与非末字单列样本、合格数和擦除。统计所检强填充，较短 PN 的分布保持未决。
2. 对通过的字，在右端之前用匹配率 0.97 对随机 0.5 的相对对数似然，估计 PN 起点。擦除贡献为零。起点取在至少 512 位之前。距起始不足 128 位的整段或近整段填充分开，避免零偏移偏置。
3. 比较不限制起点及 2、4、8、16、32、64 位对齐。给各整除类内部的有效起点等权，积分起点似然，避免将最大似然点的几位自然延伸当成确知边界。每种步长的格点余数仅由 E068 校准档案组决定，以留出档案组平均对数似然核验。输出逐格式、逐组和对照结果，跨度未知时保留多个可能解释。
4. 用合成带擦除的匹配样本检查一致性规则、积分归一性、训练留出分离。另行手算末字统计和测得的格点证据。

档案给出固定的 8 位格点后，追加原 IQ 软符号对照。复用 E028 和 E030 留存的符号，不在原 IQ 重新选格点。分别测最近点全保留、平方距离差小于 0.01 时擦除两种接收路径。验证 8 位零余数、比较 8 位其他余数和 16 位零余数，区分不同字长的可见性。原 IQ 与部分档案帧重合，按对应坐标保留比较。
