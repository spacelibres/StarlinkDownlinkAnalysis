# E032 · 两份宽带录波的 PN15 转移

- 以 250 MS/s 录波冻结的 PN15、字节位序和相位预测旧录波六种格式的完整硬判字。保存每字预测以及同一搜索的三个错误模型。用已知系统区长度的格式检验截点。
- 用旧录波 Code 68 的保存复数样本比较 PN15 点概率和均匀未知标签概率。保留最大连续区间以及第 6,144 位前后等长的匹配率、重调制误差和区间端点。边界证据和编码存在性分别报告。
- 对旧录波 Code 21 和 28，应用 15 阶递推残差与 24 位循环差分。整帧随机划分仅用于拟合残余模板和转移。保留不反转字节和错误抽头的对照。
- 对比旧及新非零模式、同捕获 60 位模板的最短周期及循环汉明距离。保留比较的位坐标和适用范围。
