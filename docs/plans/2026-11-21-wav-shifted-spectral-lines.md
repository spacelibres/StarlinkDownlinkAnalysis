# E040 · 窄带 WAV 中偏移的 750 Hz 谱线

- 只读原始 WAV、E001 的细线频漂、E005 的帧周期和整块划分，以及 E006 的细线相位。以历史 250 MS/s 宽带帧时刻和公开论文作为周期外部参照。
- 用互不重叠的 0.2 秒 Hann 窗分别算两侧谱：在 750 Hz 候选网格上扫描模周期余量。在校准块确定全局偏移，在保留块检验。还用同一块的另一侧估计局部偏移来预测目标频带，与零偏移、相反偏移、错周期、整块置换和事件后对照比较。
- 用另一侧给出的频偏按候选帧周期复数折叠。在整块校准上固定每侧复数谱形，比较保留和事件后复现情况。对保留块进行整帧相位原点移位。单列原坐标和细线相位参考。
- 固定主线轨迹后，检验公开文献约 44 kHz 整倍间隔的有限伴线模型。用独立合成的两侧周期谱线和 44 kHz 音调作正对照。
- 存档全部分块复数观测和指标。图表使用 spacelibre 资产和科研数据，不修改源 WAV。
