# E053 MCS 85 计数候选和公开帧格式检验

- 沿用 E052 的录波、档案、整帧分组、记录位置和距离映射。一个路径上每个记录均须有独立检出的下一窗口，且相邻长度必须精确吻合三种模式之一。标签硬判与该长度对应标签最多差两个位。路径中遇到缺口即断开。相邻同标签配对可以跳过中间其他标签。构造路径时不使用零基偏移 6–7 的计数候选字段。
- 从原始复符号和冻结交叉 32QAM 标号，列举这两字节的 65,536 种取值。对受约束符号的其余标号位求和并保留同一符号内的位相关。按候选符号误差的指数权重计算两记录的差分得分，采用固定尺度 0.03 和 0.06，未标定为后验概率。比较大端、交换字节和逐字节反转比特。检查正向与反向 1–4、零步长、按路径所有记录递增以及仅低字节回绕模型。保留原硬判、失败配对和推断值。
- 对 E052 有精确后继的完整记录，在冻结的起点邻域内查原字节及逐字节位反序两种表示。按 IPv4/IPv6 的字节长度、IPv4 首部校验和、EtherType 及 Ethernet CRC32 做有限对照。只接受规范明确和坐标一致的匹配。长 CRC 仅测未纠正硬判，不据此排除链路层校验。使用合成报文验证检测代码。
- 分别报告原 IQ 校准帧和留出帧，以及含重叠的 Qin 段 247 和其余档案段。多个配对共享字节和帧，统计按实测帧汇总。保持旧记录与所有未通过证据。仍为离线处理，不新增 RF 采集。

第一次运行在验证 Qin 的同版本硬判时发现，按标号重排序会改变量化符号的等距判决。保留原运行，用 E052 的星座点顺序复算硬判，只在软求和时按标号排序。两点等距的软权重相同。
