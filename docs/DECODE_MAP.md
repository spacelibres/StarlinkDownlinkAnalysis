# Starlink 录波解码证据总表

最终目标是解释现有录波中可辨识的波形、帧、控制字段、编码和内容。不同录波覆盖的频率、时段和功率不同。证据从原样点或冻结复数估计出发，经过同步、资源定位、软判、字段或码字校验，再讨论语义或来源。文中码字校验、模板匹配和真实载荷语义分别保留各自证据。

## LEO Tracker 与宽带结果的交叉入口

从 [LEO 原工程输入与复验入口](../reports/E143/2026-11-21-LEO原工程检测器重放.md) 可直接定位接收算法、可运行的样点、回归语料和原生 25 MS/s 捕获。窄带实验优先核对原工程检测器的获取结果，再在相同样点上评价协议候选。频窗覆盖、捕获成功以及字段验算各自需要证据。

先按来源核对输入及可复算层级。原工程的连续录波路径、选段 IQ、导频矩阵和位导出分别见 [E099 接入记录](../experiments/E099/README.md)。每项窄带结论应标明所用层级，并保留该录波内的阴性对照。

新字段在冻结坐标后核对 LEO 原工程的通带、已有导出和可用样点。具备观测条件时用实收材料复验。需要连续 IQ 或位导出时，在对应字段中登记缺项。软件限带的宽带结果单独记录来源。原工程输入及对应的复验入口见 [E106](../reports/E106/2026-11-21-LEO上边缘残余相位.md)。

研究从 LEO 的波形和协议假设双向展开。已有原始 IQ 用于复验同步和相位，位导出可直接检验冻结坐标和候选关系。高阶编码项目还要核查实收校验坐标，并在原生窄带条目注明观察或缺项。下边缘早期符号的 DS9 双路判决现可用，目标三位仍缺完整共识。对绝对时钟，已有原生 25 MS/s 的优先候选是 `0181` 的 `stream-0/RX0`，当前本机证据为频偏回执。[E129](../experiments/E129/README.md) · [E107](../experiments/E107/README.md)

[E090 WAV 终止分量](../experiments/E090/README.md)使用逐周期相干模板，确认约 13.635 秒时主要消失的是两侧周期分量，匹配功率下降约 17–19 dB。移动细线也下降，固定接收频段基本稳定。点估计聚集在约三毫秒内，单事件的条件区间仍不足以确认同帧关断。

[E112 WAV 重捕获](../experiments/E112/README.md)在同一事件前后搜索循环字相位、整帧时延及残余频偏。事件前两种频点划分在四窗均选相位 8。事件后十窗的留出误差均未降低，且两侧分别评分也无正收益。半幅参考注入的六个分支均恢复设定参数，结果限于冻结的四载波重复族和当前频率时轴。

[E113 位置 34](../experiments/E113/README.md)用其它三根载波对齐后，+2 载波的模 15 槽类 5 以接近零的相干贡献解释得更好。在三种平滑信道模型中约 93%–95% 的留出分支选择零振幅，原来的符号擦除保留。

[E114 逐帧相对判决](../experiments/E114/README.md)发现位置 34 存在可观测的同相逐帧变化，因而较弱的长时相干均值包含帧间相消。5,117 帧中保留 2,630 个受参考相位约束的相对符号，2,487 个仍擦除。位置 42、50 能跨频点预测位置 34。结果只下推到该录波和相位约定。

[E116 整字与三位置对比](../experiments/E116/README.md)表明，逐帧改变 60 位参考字的循环相位，在 43 个窗的四种分支中均优于只翻转三个位置。负频侧选择的相位在 1,258 个三位置已判帧上预测对 1,147 个，固定正号预测对 712 个，错帧最多对 409 个。原始 WAV 的多数共同变化可由整字移位解释，LEO 跨接收机复验仍受 E115 的观测覆盖限制。

[E117 粗起点和相位碰撞](../experiments/E117/README.md)在宽带档案中量化了同相位的多分配终点。原 WAV 中相位 0、8、16 的正侧谐波支持前 50 个数据槽内已有重复结构，共 12 个互补分支。背景注入能区分大区段，不能可靠复原精确槽号。尚未验证原 WAV 的分配字段。

[E055 LEO Tracker 原工程复核](../experiments/E055/README.md)直接核查外部数据、采样计数和生成脚本。两份 NPZ 包含 10 个唯一原始 IQ 窗，其他测轨、校准和位置文件有各自证据。约 76.153 秒的双路 IQ 支持冻结相对频漂在整帧留出中的弱优势，说明频漂归因须保留接收机分量。

[E056 LEO Tracker 频偏分支](../experiments/E056/README.md)复用原工程导频模型。10 个唯一 IQ 窗的留出样点均支持原频偏分支，优于符号率整数偏移、子载波间隔和错位模板对照。此结论用于固定窄带解调的频率坐标，尚无新的载荷位。

[E089 分数样点定时](../experiments/E089/README.md)在同符号同样点上区分了两种接收机模型。共享跨帧导频通道时，十窗的分数定时胜过整数舍入与反向舍入。允许逐帧逐载波复增益时，三种定时的留出预测和 60 位模板判相均等价。提高导频预测后，非导频增量仍无一致变化。

[E057 双路逐符号检验](../experiments/E057/README.md)由原工程时轴直接对齐两段双路 IQ。36.727 秒的共同非导频仅有 527，四条路径未通过。同段自由估计的八根已知导频也未通过双路正对照。76.153 秒仅有少数已知导频给出依赖边缘保护量的转移，无共同非导频坐标。

[E058 头部第三路验证](../experiments/E058/README.md)在 Qin 档案的 1,009 组控制头中以两路卷积输出选择极性并独立预测第三路，三个分支均逐位复现。250 MS/s 偏移时轴 H2 保留未解；窄带的 H1 前缀投影秩单窗最多为 3，已知前缀之外为零。

[E085 高阶校验](../experiments/E085/README.md)将 MCS 66 的已验证约束扩展为五条基校验、2,560 个独立二进制约束。原始 IQ 解调中，新增校验命中率约 91.5%，仍保留码字擦除与未解内容。

[E088 部分软译码](../experiments/E088/README.md)用已知 PN 比较四族和五族的纠错收益。五族降低档案留出错位，也纠正了三个原始 IQ 对应 PN 区的全部可见错误。双侧独立译码后的近重复分歧上升，未知位正确性仍无验证。

[E059 双时轴差分](../experiments/E059/README.md)从 250 MS/s 原 IQ 量化 13 个共现时隙中主时轴循环前缀的复制成分。偏移导频在有些差分样点内保留，但正确间隔未对错间隔给出稳定的导频收益，稀疏差分无法恢复完整 H2。

[E060 高阶载荷软折叠](../experiments/E060/README.md)从实测观测复现 Code 5 的八个已知常数投影关系。MCS 66/70 的 14 个稀疏折叠配置未通过，已知 PN15 表明 512 位以上的折叠置信度很低。128 位分支仍有可观测量，密集关系保留未解。

[E061 槽内调制对照](../experiments/E061/README.md)在五处确实配对到原 IQ 的槽内边界恢复了 16QAM 到交叉 32QAM 的切换，对应硬判档案槽只保留同一星座。全档案的 745 个候选槽未保留预报的双星座切换。用硬判档案研究高阶编码时要保留这些坐标的量化歧义。

[E062 Code 21 纠正](../experiments/E062/README.md)在 Qin 软符号的 58 个留出字中，用分散校验组选择并验证单符号修正，使唯一通过位置由 13 增至 16。三个新增字各有一个在 +511 上的系统位变动。逐槽旋转未增加通过字。

[E063 边缘相位转移](../experiments/E063/README.md)用前段 Code 5 在同帧预测后段 Code 21 的 +511 相位。固定相位转移和留出擦除重建均通过同一组 43/58 个位置，比 E062 增加 27 个，重叠位串逐位一致。LEO Tracker 现有 2.5 MS/s 选段可作下边缘时频对照。旧报告中的 4.33–5.02 MHz 使用了循环 FFT 索引。物理频率距离与另一个采样率的覆盖见 [E071](../experiments/E071/README.md)。

[E064 LEO 导频相位](../experiments/E064/README.md)使用原工程八根下边缘导频检验局部相位。与最近两根外推相比，端点独立估相有收益。改用其余七根导频的加权线性参考后，独立估相未能在任一窗的整带上同时通过两种保护量，仅在少数窗显示单载波收益。结论只涉及已知导频。

[E065 LEO 非导频模板](../experiments/E065/README.md)将分析移回原时域样点。宽带冻结字在 4/10 个短窗通过置乱对照，约 76.153 秒一对互补频窗支持同模板相位双向转移。按模 60 资源映射两频窗可覆盖全部位置，但每载波允许独立复增益，且字本身由宽带提供。此处证据用于验证周期模板与配对，不能当作盲解完整新字。

[E066 LEO 无参考估计](../experiments/E066/README.md)在不载入宽带字的程序中学习 60 位形状，用互换的保留帧和保留符号块检验。76.153 秒窗的四种盲估计对齐后一致保留 42 个位置。后续对照宽带时其中 39 个相符。四个频组的极性仍不可区分，严格取样路径的第一路保留误差未降低。

[E067 全档案尾段模式](../experiments/E067/README.md)确认 1,004 个合格相位全部由头部分配的逐字取整预测，包括 887 个未进入 E035 的档案帧。另一个 480 MS/s 捕获中，末四槽的同载波比较支持 12 帧采用常量尾段。周期相位因此只用于已经验证周期模板的捕获。

[E068 H2 布局](../experiments/E068/README.md)把每种候选的资源宽度作为独立未知整数，用实测尾段相位排除 15 个受检拆分。20 位、12 位小端数量的模型独立重估 19 个资源宽度，并吻合 502 个留出相位。H1 的单位和数量缩放，以及 H2 恒零的标签最高位用途，仍存在歧义。

[E069 同星座顺序](../experiments/E069/README.md)利用冻结 PN15 的停止位置，在星座区间及总长度相同的排列中区分描述符顺序。1,536 个区段中 1,493 个原顺序唯一胜出，43 个并列。证据说明分配位置与可预测填充相关，完整编码与业务语义仍待验证。

[E070 末字与字节边界](../experiments/E070/README.md)用前后 512 位窗筛出 2,487 个强 PN 停止，全部位于分配末字。10 种格式在校准侧选出字节零余数，并得到留出支持。旧 250 MS/s 软符号复验同一格点，短填充、绝对逐字起点和协议归属保留未解。

[E072 上边缘投影](../experiments/E072/README.md)把 250 MS/s 实测数据限带到 E071 的观测窗口。零额外频偏时，不同滤波的 +511 幅度转移为 0.905、0.501 和 0.069，四根内侧导频均约为 0.997。宽带擦除参考支持帧内校相。真实 LEO 归档的通带响应仍待以原样点测量。

[E073 填充与纠错](../experiments/E073/README.md)在两份宽带的 91 个原始精确码字中证实，固定 PN15 区间置零会改变与实测相符的校验位。35 个区间抵达系统区边界，56 个止于内部。Code 5/9/21 也排除了对同一线性码的整字固定 PN15 异或。高阶未识别编码及区间的上层含义仍待验证。

[E074 高阶重复与分组](../experiments/E074/README.md)在近全 PN 末字检出 MCS 57、66 各一对后段超过 99.6% 相同的近邻。原档案分块把这两对分到训练和留出两侧。追加扫描给出 675 个近重复配对位置，排除近邻后没有得到新矩阵或可转移的线性关系。

[E075 幅度位擦除](../experiments/E075/README.md)定位 E074 的 13 个千位级差异。各异常槽的作者量化分别为 4QAM 和 16QAM，擦除 4QAM 一侧的两条幅度位通道后，原差异从 13,621 降到 610 位。四个软符号槽重判的 256 个留出幅度位有 247 个与另一帧硬判吻合，待独立校验矩阵验证。

[E076 三重重复](../experiments/E076/README.md)用前 256 位注册 62 个高阶三重观测。两路共同判决仍有相关差异，62 个合并字均保留擦除。已知 Code 5 的 1,316 个组合通过擦除检验，按内容去重为五个字，其中一个未见原始单路精确校验，两处校验位由矩阵补全。

[E077 高阶密集折叠](../experiments/E077/README.md)将共享两级头部的档案块合并后做随机留出，穷举短前缀的全部折叠线性关系。Code 5 找回全部 24 个模 1 和模 2 输出系数，高阶的最强结果未通过跨组对照。已知 PN 末段中，512 位折叠在三重合并后仍无完整观测。

[E078 Code 5 系统字节](../experiments/E078/README.md)用原始校验或擦除恢复接受 530 个档案首字。首字节指向同一类内部标记，四条 7 字节记录或省去 28 字节的变体均可按相对位置检验。原始及补全的位有独立掩码，变量字段语义仍未确定。

[E079 帧计数与 LEO 频窗](../experiments/E079/README.md)在两份宽带原 IQ 和 Qin 档案中验证每个 750 Hz 周期递增一的 Code 5 字段。10 个本地 LEO 短窗的计数约束秩均为零。25 MS/s 标称频窗分上、下边缘给出可验证布局；能否解出取决于归档实际内容、时钟、频偏和接收滤波。相对计数、接收样点时轴和绝对发射时间分别保留。

[E080 首字恢复](../experiments/E080/README.md)仅用档案星座和冻结校验补齐 479 个字，使 1,009 帧均有首字可比较。冻结计数关系在主时轴留出组命中 422/422，校准组 569/570。16 个较早的离轴条目与计数预测的后续条目首字相同。精确载荷重复可用于约束后续分配的联合解调，物理来源仍待跨捕获验证。

[E091 内部目录](../experiments/E091/README.md)复原了 Code 5 系统字节的 24 位 CRC 和首条记录跨字边界。CRC 在两份原始宽带和 429 个档案留出首字中逐字节一致。首条记录的 135／163 字节跨度精确预测了 1,009 帧的下一标记。

[E092 时变量与可辨识性](../experiments/E092/README.md)从首条记录的六个高精度位段及一个较弱位段预测相对时序。档案的 17 个离轴条目和异常 956 同时支持内容计数时轴。目录 CRC24 未提高现有理想频窗的线性可辨识秩。

[E081 高阶增益校正](../experiments/E081/README.md)用已验证 Code 5 的实收位估计逐帧增益，12 种高阶分配增加约 4,330 万个格点判决。冻结 PN 停止留出增加 233 字，错相对照无新增。四组额外重复帧支持 180 个高阶码字配对，适合进一步约束擦除与纠错；应用层字段仍待复验。

[E082 MCS 66 稀疏关系](../experiments/E082/README.md)在候选校验区识别两族三项异或，512 位旋转的新增坐标在留出近全 PN 末字命中约 95%–96%。第二族也在原始 IQ 的未拟合末字命中 472/487。非末字对照约为 50%，后续需恢复系统区参与项以验证通用纠错关系。

[E083 MCS 66 部分校验矩阵](../experiments/E083/README.md)把两族三项关系扩展为各含 11 个系统位和 3 个校验位的齐次关系。秩 1,024 的矩阵以原始 IQ 重解和档案非末字复验，并在已知 PN 内验证了 352/381 个真实单擦除候选。该格式的其余校验行、完整译码性能和载荷字段仍待测量。

[E084 MCS 66 扩展校验](../experiments/E084/README.md)恢复两条新的 14 项基校验，矩阵秩达到 2,048。两组新校验均通过实收非末字和原始 IQ 验证，条件 PN15 产生的等价解在非末字上失效。单擦除提议增至 19,869 个，新增可检验 PN 位有 410/445 一致。其余校验关系仍待恢复。

[E049 跨录波验证](../experiments/E049/README.md)显示，117 个档案帧中筛到的二元尾段在经验参考下分为 30 类，统一到解析 PN 后落入同一个 60 位循环族。该族分别通过 WAV 两边带的相位选择和 NPZ 的留一载波预测。没有将观察到的序列族数等同于不同发射源数。

[E050 帧内分配检验](../experiments/E050/README.md)将宽带 H2 中的分配顺序与星座观测相互核对。跨星座的内部边界匹配 21/22，且原顺序在 70 个同终点、有区别的交换中全部胜出。同星座之间的分配仍须从编码、其他标记或额外观测验证。

[E051 填充停止点检验](../experiments/E051/README.md)在九个完整 250 MS/s 强帧里用冻结 PN15 进一步定位 19/25 个同星座内部边界。停止点反推的码字末端与 H2 预测逐资源相符。六个 MCS 66 到 70 的边界未检出，五位交叉星座的部分候选会因长后窗混入后续低匹配区而重叠。

[E052 系统区记录](../experiments/E052/README.md)发现 MCS 85 去扰后的两个字节能预测三个跨码字记录间距，留出帧命中 67/71，Qin 档案的非重叠段支持其中 1,524 字节的对应关系。记录完整性和字段的协议归属仍待验证。

[E053 计数候选](../experiments/E053/README.md)用软判验证 MCS 85 记录的另一对字节在同标签序列中通常递增。原 IQ 留出对的正向得分胜于反向 67/68，Qin 非重叠段为 38/39。现有样本无法确定高字节的回绕规则，所测明文网络封装没有得到确认。

## E047 同方法实测复验

归一化时延相关采用

$$r[d]=\frac{|\sum_n x^*[n]x[n+d]|}{\sqrt{\sum_n|x[n]|^2\sum_n|x[n+d]|^2}}.$$

在 $1,2,3,4$ 个标称 750 Hz 帧间隔和四个半整数对照处各查 ±64 样点，窗口内无需帧起点。原 WAV 用 E001 的 CW 轨迹去漂，取中心两侧 320.25–1,049.25 kHz。NPZ 按原采样率取 100–1,150 kHz。两份宽带各按完整 10 ms 窗，从实测 IQ 分别移频、抗混叠降采样再取同带宽。中心匹配 WAV 的频率约定，边缘针对 NPZ 的名义载波范围。这是频窗控制，实际接收机滤波、中心误差和捕获强度不同。[公开 OFDM 帧参数](https://arxiv.org/html/2210.11578#S7) · [公开帧体与边缘导频](https://arxiv.org/html/2602.02627#S7)

| 视图 | 1 帧延迟的峰在最近样点 | 1 帧处中位相关 | 4 帧处中位相关 |
|---|---:|---:|---:|
| WAV 留出，事件内 | 33/33 | 0.0869 | 0.0813 |
| WAV 事件后 | 0/9 | 0.00157 | 0.00262 |
| 两份 NPZ 去重 | 10/10 | 0.0331 | 0.0237 |
| 250 MS/s → 中心 | 0/5 | 0.00539 | 0.0136 |
| 250 MS/s → 下边缘 | 5/5 | 0.0243 | 0.4497 |
| 480 MS/s → 中心 | 1/2 | 0.0782 | 0.3804 |
| 480 MS/s → 下边缘 | 2/2 | 0.5735 | 0.4412 |

33 个 WAV 留出块和 10 个唯一 NPZ 窗的 1 帧峰均超过全部半整数帧对照。250 MS/s 的边缘投影在 1 帧时延虽然找到精确峰，五个窗均有更强的半整数对照；4 帧延迟在 4/5 窗超过半整数对照。旧宽带中心在 2 帧处的中位相关为 0.413。峰值取决于帧是否占用、重复内容及频窗，单条相关幅度不足以判断信号同一性。这些窗口由原录波切分，不能算作独立捕获。

## H1、H2 与 FEC 的可见坐标

对共 28 个宽带双头部，用冻结卷积码和 CRC 逐字段计算理想通带观测秩。H1/H2 假设前缀及填充均已知，CRC 随描述符变化重算。首个 Code 5 字用静态生成矩阵的可见行。这里暂时允许完美定时、无噪声、已知相位和精确频窗；实际接收只能获得更弱的证据。[宽带头部及资源布局](https://arxiv.org/html/2610.29387v2#S4)

| 条件通带 | H1 描述符秩 | H2 描述符秩 | 首个 Code 5 字秩 |
|---|---:|---:|---:|
| WAV 中心 | 0/20 | 0、3 或 6 | 12/1024 |
| DSX01-S05 的单窗 | 0/20 | 0 | 4–6/1024 |
| paired_RX 的单窗 | 0/20 | 0 | 4–6/1024 |

H1、H2 和 Code 5 当前限制由不同步骤造成。窄带可继续读出物理时序、局部符号和重复模式；全带头部及 FEC 应在宽带上推进。若把现有频窗套进同一个全带译码器，缺失的输入坐标会使许多合法解给出同样预测，即使 SNR 提升也不能仅凭这些坐标唯一选出完整字段。

## 分工

- 原 WAV 同时检查帧间变化、15 槽重复的擦除位置和频带内其他成分。把固定模板从观测中扣除后，优先辨别哪些变动能够预测独立时块。
- 两份 NPZ 使用复验的帧间隔，定位实际可见的边缘导频、槽内信息及参考依赖。仅在样点、时钟和来源有确证时尝试合并观察。
- 两份宽带与公开频域档案继续做整帧资源划分、不同调制编码、帧间变化及字段语义。原时轴和偏移时轴保留独立结果。单一弱码的失败仅影响对应分支。
