# E008 方法、公式与来源

这些公式用于本轮可执行检验，不是对所有公开编码体制的无边界枚举。以输入带宽与可观测资源决定是否有条件进入下一步。

## 已知导频与未知载波分离

每个符号的窄带观测写成 `y_s = P_s h + U_s a_s + n_s`。已知导频的增益 h 跨该帧共享，未知载波 a_s 逐符号自由。以 `Q_s = I − U_s U_s⁺` 消去未知载波，使用拟合周期 C 求解：

`ĥ = (Σ_C P_sᴴ Q_s P_s)⁺ Σ_C P_sᴴ Q_s y_s`。

频偏仅按拟合周期的投影残差选择，保留周期误差 `Σ_H |Qy−QPĥ|² / Σ_H |Qy|²` 检查预测。这不是已在同一数据上拟合的星座 EVM，更不是未知比特 BER。

保留样点与拟合样点不相交且 CFO 冻结时，白复数样点噪声的单位方差传播为 `Cov(â_s)/σ² = U_s⁺(U_s⁺)ᴴ + K_s G⁺ K_sᴴ`，其中 `K_s=U_s⁺P_s`、`G=Σ_C P_sᴴQ_sP_s`。这是灵敏度模型，未计有色噪声、滤波瞬态和频偏估计误差。严格边缘舍弃会恶化设计矩阵，阴性结果必须结合方差变化解释。

## 重复结构

解析 PN 与经验参考分别去旋转后，按完整周期分组。拟合周期均值 A 与保留周期均值 B 都移除每帧的类别平均，检查 `Re⟨A,B⟩`，避免常复数信号被当作未知重复码字。

相位随机化对每个保留周期的所有帧/类别共同施加一个相位；各窗口、载波、参考共用这些控制，按最大统计量校正。它依赖残余空假设的旋转对称性，不提供分布无关保证。第一秩剔除的共享类别方向只在拟合组训练。

## 前缀内部相位

后事件噪声协方差 R 经特征值下限处理得到 `W = R⁻¹ᐟ²`。白化模板 p、s 构造单位向量 `u=p/||p||`，`v=(s−u uᴴs)/||s−u uᴴs||`。方向在该噪声模型下正交。比较接收投影 `(uᴴx)(vᴴx)*` 与精确联合模板所预测的相位，减去噪声拟合块的互积偏差。仍须比较错误 SSS 模板和后事件区。

## 编码可观测性

冻结的约束长度 7、码率 1/3、六个终止零和 CRC 约定依据 [Liu 等的论文](https://arxiv.org/html/2610.29387v2)及其[当前公开说明](https://github.com/misaka666/Starlink-Downlink-Analysis)，不是本轮从用户录波独立识别出的编码器。

线性编码矩阵 G 逐个基向量生成；CRC 初始化是仿射常数。理想无误码时，加入已观察位、CRC 与额外已知前缀后的自由维度为 `n − rank_GF(2)([G_observed; C_CRC; K_prefix])`。正自由维度说明同一观测对应多个候选消息；Viterbi 的一条最优路径不能消除这些信息缺口。

PN 与导频采用项目中有来源哈希的公开常量，解析约定还通过全部 8 个已知边缘导频验证。经验模板由外部样本共识得到，其与解析 PN 的差异不能自动算作本地新信息。原始瀑布图项目的 [WAV 说明](https://github.com/lixb123/starlink_beacon_iq)只说明 IQ 显示与可选 LNB 参数，不提供已验证的消息解码。
